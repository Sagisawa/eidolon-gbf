# Facts & Sources Template (`characters/facts/{character_id}.md` & `.sources.md`)

Fact files provide grounded, factual knowledge retrieved via BM25 during conversation turns. They MUST be factual, dense, and anchored in official GBF canon.

Target volume: **150 ~ 250 lines** of high-density facts.

---

## 1. Fact File Structure (`characters/facts/{character_id}.md`)

```markdown
# 事实集：{官方日文名}（{中文译名} / {英文名}）

## 基础身份与身体档案
- **姓名**：{官方日文名}（{日文读音平假名} / {英文名}）
- **种族**：{人类 / 牛族 / 狐耳族 / 矮人族 / 星晶兽}
- **属性与武器得意**：{火/水/土/风/光/暗}属性，得意武器为{剑/刀/短剑/枪/斧/杖/铳/格斗/弓/乐器}
- **阵营所属**：{グランサイファー / 十二神将 / 十天衆 / 四騎士 / 組織 等}
- **外貌特征**：{体型特征、发色发型、眼眸、角/兽耳特征、标志性服饰与随身配饰}

## 核心机制与标志性特征

- **标志性奥义**：{奥义日文原名}（{中文译名}）——{奥义演出与效果描述}
- **标志性技能组**：
  - 1技能：{日文原名}（{简要机制}）
  - 2技能：{日文原名}（{简要机制}）
  - 3技能：{日文原名}（{简要机制}）
  - 4技能/特殊技：{日文原名}（{简要机制}）

- **业余爱好与习惯**：{拼图、练剑、缝纫、睡懒觉、收集小饰品等}
- **与骑空团其他伙伴的日常**：

  - 船上的值日与打工：{是否负责厨房、甲板警戒、或者在谢洛卡特处兼职}
```

## 2. Citation File Structure (`characters/facts/{character_id}.sources.md`)

```markdown
# 事实来源引证：{官方日文名}

本文档记录 `characters/facts/{character_id}.md` 中各项事实的官方出处。

## 游戏内原作剧情
- 《碧蓝幻想》角色命运之扉（Fate Episodes）：
  - SSR 初始版招募剧本及上限解放剧本
  - SSR 最终上限解放（五星）剧本
  - 泳装 / 情人节 / 最终形态剧本
- 剧情活动（Story Events）：
  - 《{活动日文名}》（{年份}年{月份}月）

## 历年节日特番语音（Seasonal Voice Lines）
- 2015年～2024年 情人节、白色情人节、新年、万圣节、圣诞节、团长生日特别对话记录。

## 官方音乐与设定集
- 官方单曲 CD：《{角色歌名}》（{编号}，{发售年份}）
- 官方设定画集：《GRANBLUE FANTASY GRAPHIC ARCHIVE》第 {X} 卷
- 公式 Radio / 官方生放送节目信息（ぐらぶるTVちゃんねるっ！）
```
