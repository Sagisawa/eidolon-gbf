# Granblue Fantasy Factions & Canonical Terminology

This document defines the canonical factions, honorifics, and vocabulary for authoring characters in `eidolon-gbf`.

---

## 1. Core Terminology Alignment (Anti-Pollution Dictionary)

Under NO circumstance may modern idol agency terminology appear in system prompts, character sheets, facts, or world definitions.

| 碧蓝幻想（GBF 规范） | 闪耀色彩 / 现代艺能（严禁出现） | 说明与语境 |
| :--- | :--- | :--- |
| **骑空团 / グランサイファー騎空団** | 事务所 / 283 事务所 / 经纪公司 | 角色生活的集体是翱翔在全空的骑空团 |
| **团长 / 団長 / 団長ちゃん / 団长っち** | 制作人 / プロデューサー / P | 用户的唯一身份是骑空团团长（特指姬塔/格兰） |
| **同伴 / 伙伴 / 仲間 / 団員** | 偶像 / アイドル / 艺人 | 船员之间是并肩作战、共同生活的伙伴关系 |
| **格兰赛法号（Grandcypher）** | 事务所大楼 / 练习室 | 大家的移动据点是飞空艇，甲板与船舱是日常场景 |
| **空之世界 / 全空 / 浮空岛** | 现实都市 / 现代社会 | 奇幻世界观：四大种族、星之民、星晶兽、浮空群岛 |
| **角色歌 / 空之节庆舞台** | 偶像单曲 / 握手会 / 偶像Live | 即使角色有角色歌（如维卡拉、水仙等），也是空之世界的节庆音乐与舞台 |
| **奥义 / 武器 / 战技** | 舞蹈 / 歌唱力 / 视觉表现 | 角色在战斗中具备武艺、魔法或守护神力量 |

## 2. Sky Realm Races (四大种族与星晶兽)

Every GBF character belongs to one of these races:

1. **人类（ヒューマン / Human）**:
   - 平均体型，适应力最强，数量最多。
   - 代表角色：卡塔莉娜、拉卡姆、伊欧、兰斯洛特、珀西瓦尔。
2. **牛族（ドラフ / Draph）**:
   - 特征为头顶长角，男性体型极其魁梧庞大，女性娇小玲珑且身材极具丰满曲线。
   - 代表角色：娜露梅（ナルメア）、巴萨拉卡（バザラガ）、阿纳斯塔西亚。
3. **狐耳/兽耳族（エルーン / Erune）**:
   - 特征为头顶长有兽耳（犬、狐、鼠等），服装传统上往往露背以彰显灵敏与神性。
   - 代表角色：维卡拉（ビカラ）、塞塔（ゼタ）、尤斯提斯（ユーステス）、安妮拉（アニラ）。
4. **矮人/豆丁族（ハーヴィン / Harvin）**:
   - 外表如同永远长不大的孩童，身高约 90cm，但常具备极高的心智、商人嗅觉或魔法天赋。
   - 代表角色：谢洛卡特（シェロカルテ）、卡露瓦、芬芙（フュンフ）、夏洛特（シャルロッテ）。
5. **星晶兽 / 天使（星晶獣 / 天司）**:
   - 星之民创造的高维存在，拥有神级权能。
   - 代表角色：露莉亚（苍之少女）、圣德芬（サンダルフォン）、路西法、诺亚（ノア）。

## 3. Major Factions in `world.json` (`units`)

When registering a character in `characters/world.json`, assign them to their canonical faction:

### `グランサイファー`（Grandcypher Core Crew）
- **Reading**: `ぐらんさいふぁー`
- **Description**: 格兰赛法号核心船员与常驻伙伴。
- **Key Members**:
  - `ルリア`（蒼の少女）
  - `ビィ`（相棒 / 小红龙）
  - `カタリナ`（騎士 / 守护者）
  - `ラカム`（操舵士）
  - `イオ`（魔導士）
  - `オイゲン`（歴戦の兵士）
  - `ロゼッタ`（魔導士）
  - `シェロカルテ`（よろず屋）
  - `ナルメア`（常驻剑客大姐姐）
  - `サンダルフォン`（天司长兼船上咖啡师）

### `十二神将`（Twelve Divine Generals）
- **Reading**: `じゅうにしんしょう`
- **Description**: 守护空之世界特定方位的十二位岁神使者，皆为狐耳族（エルーン）少女。
- **Key Members**:

  - `アンチラ`（申神·猴）
  - `マギラ`（酉神·鸡）
  - `ヴァジラ`（戌神·狗）
  - `クビラ`（亥神·猪）
  - `ビカラ`（子神·鼠，奇迹维卡）
  - `シャトラ`（丑神·牛）
  - `シンダラ`（寅神·双子虎）
  - `マコラ`（卯神·兔）
  - `ハイラ`（辰神·龙）
  - `ペイラ`（巳神·蛇）

### `十天衆`（The Eternals）
- **Reading**: `じゅってんしゅう`
- **Description**: 全空全武器领域的至高十人，剑圣与武艺顶点的传说。
- **Key Members**:
  - `ウーノ`（一·枪）
  - `ソーン`（二·弓）
  - `サラーサ`（三·斧）

- **Reading**: `よんきし`
- **Description**: 费德兰特王国的白龙与黑龙骑士团核心将领。

## 4. Captain Honorifics (各角色对团长的专属称呼)

GBF 极其重视角色对团长的第一人称与第二人称称呼，**绝对不能写错**：

| 称呼方式 | 适用角色类型与性格 | 典型代表 |
| :--- | :--- | :--- |
| **団長ちゃん**（Dancho-chan） | 宠溺、撒娇、视团长为宝贝弟妹的温柔姐姐 | 娜露梅（ナルメア） |
| **団長っち**（Dancho-cchi） | 超级阳光元气辣妹/偶像状态（戴耳） | 奇迹维卡（ビッキー / 维卡拉） |
| **団長さん**（Dancho-san） | 礼貌温顺、内向社恐（摘耳）、或普通敬称 | 维卡拉本体、露莉亚、卡塔莉娜 |
| **団長殿**（Dancho-dono） | 武士道、古风、庄重、尊敬主君 | 狗神将（ヴァジラ）、齐格飞、尤达尔拉哈 |
| **団長**（Dancho） | 亲近但平等尊重的同伴 | 兰斯洛特、塞塔、巴萨拉卡 |
| **お前 / あんた** | 傲娇、不羁、独狼性格或高维观察者 | 圣德芬（初期）、卡西乌斯、贝阿朵莉切 |
| **きみ**（Kimi） | 神秘、宠溺或长辈从容视角 | 希耶提（シエテ）、罗洁塔（ロゼッタ） |
