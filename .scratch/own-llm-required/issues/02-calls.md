# 02: 通话

**What to build:** 要求打开后，通话按 01 的同一条规则判断。拨号前的预检（ICE 服务器那一步）和发起通话本身，遇到没带 LLM 自带密钥的都回 403；预检在花钱之前就拦下，发起通话被拒绝时运行记录记作「被拒绝」，不计入限额。通话层显示原因，按钮是「去设置自带密钥」，和限额设成 0、自带密钥出错时一样。只带了 LLM 的通话放行，语音合成和语音识别用部署者的，照常计入每小时通话次数；三项全自带的照旧不计入。要求的开关改动不影响进行中的通话。

详见 `.scratch/own-llm-required/spec.md`。
