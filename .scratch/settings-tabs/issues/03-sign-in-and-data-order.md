# 03: 「登录与数据」重新排序，危险操作隔开

**What to build:** 「登录与数据」这一组从上到下排成四节：

1. 登录方式：只放绑定和解绑。
2. 后台入口：只有管理者看得到。
3. 退出登录：单独一节，放「退出登录」和「退出所有设备」。
4. 删除我的全部数据：排在最后，节里只用一句话说明；完整的后果挪进确认框，在按下确认前看到。

退出和删除的行为都不变。设计见 spec「各组的内容和顺序」，以及「文案减法」里删除全部数据那一条。
