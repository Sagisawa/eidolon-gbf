# 03: 「登录与数据」重新排序，危险操作隔开

**What to build:** 「登录与数据」这一组从上到下排成四节：

1. 登录方式：只放绑定和解绑。
2. 后台入口：只有管理者看得到。
3. 退出登录：单独一节，放「退出登录」和「退出所有设备」。
4. 删除我的全部数据：排在最后，节里只用一句话说明；完整的后果挪进确认框，在按下确认前看到。

退出和删除的行为都不变。设计见 spec「各组的内容和顺序」，以及「文案减法」里删除全部数据那一条。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 「登录与数据」从上到下依次是：登录方式、后台入口（只有管理者看得到）、退出登录、删除我的全部数据。
- [ ] 登录方式一节只有已绑定的方式、解绑和绑定按钮。只有一种登录方式时，解绑照旧禁用，并提示为什么不能解绑。
- [ ] 退出登录单独一节，节标题「退出登录」，里面是「退出登录」「退出所有设备」两个按钮。它是一个新组件，退出的逻辑和「退出所有设备」的确认框都从登录方式那节整体搬过来。
- [ ] 退出的行为不变：
  - 没取到用户之前，两个按钮都禁用；
  - 退出后，这个浏览器里这位用户的自带密钥被清掉；
  - 「退出所有设备」先弹确认框，文案不变，写明其他设备上的自带密钥要自己去删。
- [ ] 删除我的全部数据一节只留一句说明，意思是「彻底删除你在这里的所有数据，无法恢复」。
- [ ] 点「删除我的全部数据」后，确认框里显示原来那段完整的后果，措辞一个字不改：删掉什么、浏览器里的自带密钥清掉、备份最多 30 天后清除、运行记录不再关联、所有设备退出、再登录是全新的用户。
- [ ] 删除的行为不变：确认后删除数据，并回到首页。
- [ ] 文案改在设置页的文案里：删除那一节的一句说明和确认框里的完整后果，分成两个键。
- [ ] 前端单测和 shadcn 纪律检查都通过。
