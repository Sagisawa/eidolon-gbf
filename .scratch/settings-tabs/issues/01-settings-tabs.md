# 01: 设置页分标签

**What to build:** 设置页顶上加一排四个标签：档案、通话、自带密钥、登录与数据。一次只显示一组，各节按 spec「各组的内容和顺序」归到四组里。

- 当前标签记在地址里：刷新、分享地址都停在原来那一组；写错的标签落到档案。
- 切换不往浏览器历史里加记录，按返回直接回对话。
- 切走再切回来，没保存的档案和填到一半的表单都还在。
- 往下翻时标签栏吸在页首下面。
- 通话结束页的「去设置自带密钥」直接打开自带密钥那一组。
- 只有一节的标签页（通话、自带密钥）不再重复写和标签同名的节标题。
- 「关于 Eidolon-SC」移到标签外面，哪个标签下都看得到。
- DESIGN.md 一次写完整条「设置页」规则，连同 02、03 要做的部分一起写（几项决定都已经定了，免得两张票同时改同一段）。

这一票不动各节内部：「登录与数据」暂时按现有的几节排进去，退出登录仍在登录方式那节里，由 03 拆开重排；自带密钥的长说明照旧，由 02 收进 ⓘ。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 用户看到四个等宽、撑满一栏的标签，下划线样式，选中态是中性色，浅色、深色模式下都看得清。手机 320px 宽也是一行放下，不用横着滑。
- [ ] 不带标签参数进设置页（从对话列表菜单、后台的「返回设置」、记忆页返回）时，打开档案。
- [ ] 地址里带合法的标签，就打开那一组；带空的或不认识的标签，打开档案，不出现空白页。
- [ ] 点标签切换时，地址里的标签跟着变，其他参数保留；不新增历史记录，页面不跳回顶部。
- [ ] 刷新页面后停在原来那个标签上。
- [ ] 档案里改了称呼不保存，切到通话再切回来：改动和「尚未保存」都还在，也没有再闪一下「正在读取…」。
- [ ] 在自带密钥那一组往下翻，标签栏吸在页首下面，下面的内容不透上来。
- [ ] 通话因限额或自带密钥出错结束，点「去设置自带密钥」，打开的是自带密钥那一组。
- [ ] 通话、自带密钥两组没有节标题（自带密钥读取失败时显示的那一支也没有）；档案、登录与数据里的各节照旧有标题。读屏在去掉标题的面板里，照样读得出它属于哪个标签。
- [ ] 「关于 Eidolon-SC」在四个标签下都显示在内容最后，跟着内容滚动。
- [ ] 管理者在「登录与数据」里看得到后台入口，普通用户看不到。
- [ ] 第四个标签叫「登录与数据」，不叫「账号」（GLOSSARY 避免这个说法）。
- [ ] 「当前标签」这条规则（从地址参数读出标签、给标签生成地址）是一个纯逻辑模块，页面只调用它。单测覆盖：
  - 缺省、空值、不认识的值都落到档案；
  - 四个合法值原样返回；
  - 生成地址时只改标签参数，其他参数保留；
  - 原地址里没有标签参数时，也能生成正确的地址。

  写法参照现有那批纯逻辑测试。
- [ ] 读地址参数的写法符合这一版 Next 的要求，构建不报错。动手前先读 Next 自带的文档。
- [ ] DESIGN.md 版式一章新增「设置页」一条，写明：
  - 四个标签和地址参数；
  - 下划线样式、等宽撑满、吸顶；
  - 只有一节的标签页不写节标题；
  - 危险操作放在「登录与数据」最底下，删除全部数据在最后；
  - 「关于」在标签外面；
  - 长说明收进 ⓘ Popover（悬停或点开），不用 Tooltip。
- [ ] 前端单测和 shadcn 纪律检查都通过。
