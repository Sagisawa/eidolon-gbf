# 02: 自带密钥的说明收进 ⓘ

**What to build:** 自带密钥那一节开头原来是一段九句话的说明，现在外面只留最要紧的两句：

- 填了自己的 API key，费用由你承担；
- 密钥只保存在这台设备的这个浏览器里，换设备、换浏览器或清除浏览器数据后要重新填写。

句末一个 ⓘ，其余说明收在它弹出的浮层里。浮层在电脑上鼠标移上去就打开，手机上点一下打开，键盘也能操作。收进去的说明一句不少，措辞沿用 PR #62 和隐私说明对齐过的说法。设计见 spec「文案减法」里自带密钥那几条。

**Blocked by:** None (can start immediately)
