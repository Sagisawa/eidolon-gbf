# 03: 唱片与歌曲：导入，并常驻「她的歌」

**What to build:** 导入命令把闪耀色彩的唱片和歌曲也抓进资料文件；每位角色在每个回合都知道自己的个人曲和所在组合的歌，以及它们收在哪张唱片、什么时候发售。背景见 `../spec.md`，术语见 `CONTEXT.md` 的「歌曲」「唱片」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 导入命令从 Lantis 的闪耀色彩站点取唱片（发售列表和各张唱片的页面），包括已经公布、还没发售的；每张唱片有名称、发售日、品番和按顺序的曲目。imas-db 补齐 Lantis 缺少的部分，官方有的字段以官方为准，冲突列进导入报告。
- [ ] 从曲目行「曲名 / 角色 (CV.声优)」解析出演唱者，按角色名或「声优 → 偶像」对应到偶像名单；特别组合唱的歌拆到具体偶像，另记特别组合名；对应不上的演唱者列进导入报告，这一项不写入。
- [ ] 歌曲条目有曲名、演唱者、收录它的唱片；不收歌词和作词作曲编曲；每一条带来源。
- [ ] 常驻部分多出「她的歌」：演唱者正好是她一个人的歌，和演唱者正好是她所在组合全体成员的歌，每首附唱片名和发售日；不列别人的歌。
- [ ] 测试：假站点导入覆盖曲目行解析、特别组合拆分、未发售唱片照样收录、对应不上的演唱者进报告、官方与 imas-db 冲突以官方为准；对话回合的提示里只有她的歌、没有声优名字。
- [ ] 跑一次真实导入，看过 diff 后提交资料文件。
