# 04: 演出与出演者：导入，并常驻「她上过的演出」

**What to build:** 导入命令把闪耀色彩的演出和逐日出演者抓进资料文件；每位角色在每个回合都知道自己站上过（和即将站上）哪些舞台。她的声优实际出演的演出日才算她上过。背景见 `../spec.md`，术语见 `CONTEXT.md` 的「演出」「声优」，理由见 ADR-0008。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 从偶像大师官方门户的 CMS API 取演出列表：先取 token，再按 `LIVE-EVENT` 分类列出，在本地按品牌 `SHINYCOLORS` 筛选（请求里按品牌过滤会返回 0 条）；包括单独公演、合办演出和已经公布、还没举办的场次。
- [ ] 从 wikiwiki 的「ライブイベント情報」取每个演出日的出演者，通过「声优 → 偶像」对应到偶像名单；其他品牌的出演者不写入；对应不上的列进导入报告。
- [ ] 缺席（脚注里的「出演見合わせ」）只采用附了官方新闻链接的，从那个演出日的出演者里去掉；没附链接的不采用，列进导入报告。
- [ ] 演出条目有名称、会场、每个演出日的日期和闪耀色彩这边的出演偶像；每一条带来源。
- [ ] 常驻部分多出「她上过的演出」：她出演的每个演出日的演出名、日期、会场，包括还没举办的；声优缺席的日子不算，只有其他组合出演的演出不算。
- [ ] 测试：假站点导入覆盖按品牌筛选、合办演出只留闪耀色彩的出演者、有官方链接的缺席生效、没链接的缺席不生效并进报告、未来场次照样收录；对话回合的提示里只有她出演的演出日、缺席的日子不在里面、没有声优名字。
- [ ] 跑一次真实导入，看过 diff 后提交资料文件。
