# 03: 设置页填生日

**What to build:** 用户在设置页「档案」标签时区的下面，看到「生日」字段：一个月份下拉框加一个日期下拉框，配上说明「生日当天，角色会为你送上祝福。只记月和日。」日期的选项跟着月份变，2 月可以选到 29 日；换月份后，原来选的日期超出范围就清掉。可以选「不填」清空生日。只选了月份没选日期时不能保存，并提示补上日期。改了没保存时照旧显示「尚未保存」，切到别的标签再切回来改动还在。

写之前先读 frontend/AGENTS.md 的「shadcn 纪律」，视觉规范以 DESIGN.md 为准，下拉框用现有的 shadcn Select。见 spec「Implementation Decisions」的设置页和文案两条。

**Blocked by:** 01（档案能存生日）

**Status:** ready-for-agent

- [x] 「档案」标签里，时区下面有「生日」字段：月、日两个下拉框，读屏分别读出「月」和「日」，配上说明文字。
- [x] 月、日的选项都有「不填」；选 4 月时日期最多到 30 日，2 月最多到 29 日，1 月最多到 31 日。
- [x] 选了 31 日再改成 4 月，日期被清空，需要重选。
- [x] 只选了月没选日时，保存会被挡下，并提示补上日期；两个都选「不填」可以保存，表示清空生日。
- [x] 打开设置页时，下拉框显示已保存的生日；保存后刷新页面仍然一样；改动后「尚未保存」的出现和消失与其他几项一致。
- [x] 「这个月有几天」，以及档案草稿和接口里的档案之间的转换（生日为空、只有月、完整），都有 vitest 测试。
