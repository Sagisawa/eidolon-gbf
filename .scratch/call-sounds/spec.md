# 通话音效：铃声、接通音、挂断音，以及电话质感

Status: ready-for-agent

术语以 `CONTEXT.md` 为准：「铃声」「接通音」「挂断音」「电话质感」四个词条在 2026-09-28 的 grilling 中定下。拆成两张 ticket，彼此独立，可以按任意顺序完成。

## Problem Statement

现在的通话是无声的：点下开始通话后只看到「拨打中」，接通和结束都没有声音提示；角色的声音像录音棚里录的一样干净，没有真实通话那种隔着听筒的感觉。

## Solution

- **01 音效**：拨号时循环播放铃声，接通时播放接通音，结束时播放挂断音，效果和微信语音通话一样。三个音效都没有开关。
- **02 电话质感**：设置页新增一个开关（默认关闭），打开后角色的声音会限制在电话频段，并加上轻微压缩。

## 两张 ticket 共同的约定

- 音效和电话质感互不影响：电话质感只处理角色的声音。
- 「只看文字」仍然只静音角色的声音，不影响音效。
- 后端不改。

## Out of scope

- 音效的音量设置和开关。
- 底噪、线路杂音、模拟丢包。
- 在通话层里切换电话质感。
