# 04: 照片进数据包

**What to build:** 用户导出时勾了「对话」，还能勾挂在它下面的「照片」。数据包里多一个 `photos/` 文件夹，每张发出来了的照片是一个普通的 webp，解压就能看。导入后，对话里她发过的照片照常显示、点开能放大，没发出去的照样显示成没发出去的说明。不勾照片时她那条回复上就没有照片，数据包小得多。见 `../spec.md` 的「数据包的格式」里讲照片的那几条。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 导出：她的回复带照片时，`messages` 里那条带 `photo`（`id`、`tag`、`status`、`reason`、两个时间）；`ready` 的照片在 `photos/<id>.webp` 里原样放一份，一张一张从库里读，不一次读完
- [ ] 导出时还在生成的照片，按 `failed`、原因 `timeout` 导出
- [ ] `include` 里没有 `conversations` 时 `photos` 不起作用；没勾照片时，照片那一项整个不带
- [ ] 导入：照片换新 id，挂到新的消息 id 上；`ready` 的照片文件必须能当 webp 解开（尺寸不查），否则整包 `broken`；`ready` 却缺文件的、或者有文件却没有对应照片的，同样 `broken`
- [ ] 结果里 `photos` 是这次真正新加的张数
- [ ] 前端：「照片」缩进挂在「对话」下面，不勾对话时照片既不能勾、也显示成没勾（导出和导入两边一样）
- [ ] 格式说明文档补上照片
- [ ] 后端测试（走对外接口）：A 上用现有的照片测试替身造一张发出来了的、一张没发出去的、一张还在生成的，导出后解开 zip 能读到那张 webp，还在生成的那张是 `timeout`；导入 B 后，照片接口能读到图、状态和原因一致；不勾照片时 B 的那条回复上没有照片；照片文件解不开、缺文件、多文件都回 422 且什么也没写进去；B 上的照片别的用户读不到
- [ ] 受影响的测试和类型检查通过（`scripts/affected-tests.sh`），CI 绿
