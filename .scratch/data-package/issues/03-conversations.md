# 03: 对话进数据包

**What to build:** 用户导出时能勾「对话」，数据包里带上和每位角色的每段对话：消息（原样，包括语气提示、好感度变化标签、`hurt` / `out_of_line`）、对话事件、对话标题、通话的统计记录，附上角色名。导入后对话按原来的时间插进去：在这个部署上新聊的仍是当前对话，导入的进历史对话；还没聊过的，导入的最后一段就是当前对话，可以接着聊；被她结束的仍是已结束。统计接着算。同一段对话导入两次只留一份；新部署上没有的角色，和她的对话整段跳过，并在结果里告诉用户。见 `../spec.md` 导入接口里的「对话」一节。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 导出：`data.json` 带 `conversations`，每段有包内 ID、`character_id`、`character_name`、`created_at`、`title`，`messages` 按原来的先后排，`events` 和 `calls` 照原样。所有字段原样导出
- [ ] 记忆的 `conversation` 接上：勾了对话时，指向包内对话 ID；没勾时是 `null`
- [ ] 导入：角色不在这个部署的角色配置里的，整段跳过（连同通话记录），记进结果的 `skipped`（带包里的角色名和跳过的段数）
- [ ] 导入去重：同一位用户、同一位角色、开始时间相同的对话已经存在，就整段跳过、不做逐条合并；包里的记忆引用它时，改成引用已有的那段
- [ ] 其余的换新对话 id，消息按原来的先后插入，对话事件和通话记录照原样挂上；当前对话不另定规则，照旧取最新开的那个
- [ ] 送礼事件里的礼物不在这个部署的礼物表里的，这一条事件跳过，不算进结果
- [ ] 导入的记忆的 `conversation` 对应到新对话 id；对话被跳过（角色不在）的存成空
- [ ] 好感度、抽奖次数、重置卡、礼物背包都不碰
- [ ] 结果里 `conversations` 是这次真正新加的段数；前端结果那句话带上跳过的角色和段数
- [ ] 前端「对话」勾选框能用（两边），导入成功后刷新对话列表的数据
- [ ] 格式说明文档补上 `conversations`
- [ ] 后端测试（走对外接口）：A 上造几段对话（一段被她结束、一段带送礼事件和接通了的通话、一段起了标题），导出后导入 B，B 的对话列表、当前对话和历史对话的先后、已结束、标题、对话记录（含送礼事件和她挂断的记录、好感度变化标签）、统计里的回合、通话和认识多久都和 A 一致；B 上的好感度是信任、背包和抽奖次数为零；B 上已经和她聊过的，B 的那段仍是当前对话；导入同一份两次，第二次什么也没多；两个有重叠的包先后导入，重叠的那段只有一份；角色不在 B 的被跳过并出现在 `skipped`；礼物不在礼物表的送礼事件被跳过，之后的回合照常；导入后在成了当前对话的那段里照常能发回合；记忆上的对话引用在删掉那段历史对话后照常变空
- [ ] 受影响的测试和类型检查通过（`scripts/affected-tests.sh`），CI 绿
