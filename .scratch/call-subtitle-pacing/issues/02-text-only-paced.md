# 02: 「只看文字」的回复按估算节奏换段

**What to build:** 开着「只看文字」时，她的回复一段接一段出现在台词卡上，每段停留的时间大约是她念这段要的时间，而不是几秒内全部放完（GLOSSARY「只看文字」）。

- 没有合成声音的回复（开始时「只看文字」开着），第一段一到达就显示，之后的段按 01 的估算节奏换：每段停留 max(1.5 秒, 字数 ÷ 5 字/秒)，下一段的显示时刻 = max(到达时刻, 当前段开始显示的时刻 + 当前段的停留时间)。
- 中途关掉「只看文字」的回复，本来就没有声音，仍按估算节奏放完；下一条回复起跟着声音走（01）。
- 立绘的「正在说哪段」跟台词卡走：台词卡换到哪段，立绘就换成那段的情绪。现在「只看文字」时，立绘在某段第一个字到达时就切换，这一点要改掉。立绘照旧不动嘴。
- 浅色的上一段是台词卡刚刚显示过的那段，可以跨回复；不是被跳过的、用户从没见过的段。
- 新回复的第一段一到达，台词卡就直接换到新回复，旧回复没放完的段放弃。
- 用户打断后（新一轮开始），台词卡停在当时那段，等新回复的第一段。

「开口」的判断时机不变：第一段一到达就显示，所以补充和打断的规则不受影响。

详见 `.scratch/call-subtitle-pacing/spec.md`。

**实现说明：**

- 估算节奏的判断在 `lib/linePacing.ts`：没有声音的回复不等 `done`，第一段一到就显示，下一段到了、当前段也停够了就换；中途关掉「只看文字」不影响，回复按开始时的模式走到底。
- 「只看文字」的回复，台词卡在用户的话开启新回合（`user` 事件）时停住，等新回复的第一段到了再换；只是开口不停（见下面「代码审查后的修改」）。
- 立绘不再在「只看文字」时看字幕到达换段：`standDirection.ts` 去掉了按 `delta` 换段的规则和 `shownReply`，「只看文字」和兜底补放都走同一个 `line-shown` 事件。原来测这条旧规则的两处（`standDirection.test.ts` 一条、`liveConversation.test.ts`「her emotions」一组）改写或并进台词卡的测试。

## Comments

**代码审查后的修改**（2026-10-11）：

- 「只看文字」时用户开口不再让台词卡停住。原来收到 `user-started-speaking` 就停，可要是只是一声咳嗽、什么也没识别出来，后端不开新回合，台词卡就卡在那段，剩下的段再也放不出来。现在没有声音的回复不看打断，一直按估算节奏放，直到用户的话开启新回合（新回复开始）。没开口过的段反正不会多出来：回复被打断后记下的段只到完整的那几段，台词卡只放到那里。由测试「stays where it was in text only once the user's words start a new turn…」守着。
- 立绘收下晚到情绪的宽松规则，原来看此刻「只看文字」开没开，改成看她正在说的段是不是台词卡按估算节奏换上的（`saying.paced`）。中途关掉「只看文字」的回复，台词卡换过去后才判出的情绪不再被丢掉；有声音的回复中途打开「只看文字」，也不再错用宽松规则。
- `linePacing.ts`：`nextUnsaid` 改名 `nextVoiced`，返回类型起名 `NextLine`。
