# 01: 让角色像真人一样一次只说一两句

**What to build:** 改回复格式说明，让扮演角色的模型平时只回一两句，讲事情时分几次讲。背景见 `../spec.md`，术语见 `CONTEXT.md` 的「回合」。

**Status:** resolved

## 规则

- 只改 `backend/src/eidolon/reply_format.py` 的 `FORMAT_INSTRUCTIONS`。人设文件和 `characters.toml` 不改。
- 说明里要讲清楚 spec 的五条：平时 1–2 段一句口语；讲事情最多约 4 段、到自然停顿处停；不必每次以提问收尾；一次问几件事就每件简短回应；口吻以人设为准。
- 现有的语气提示例子本身不能示范长回复。
- 回忆剧情那一轮（工具结果附着 `engine.py` 的 `LAST_ROUND_NOTE`）也要确认仍然输出正常的 `<ja>`/`<zh>`、长度符合讲事情的要求。`LAST_ROUND_NOTE` 不改。

## 验收

- [x] 用真实的对话模型，对 2–3 个口吻差异大的角色，各跑一组固定输入（闲聊、问候、问近况、要求讲一段事情、一次问多件事，以及回忆剧情那一轮），统计每个回复的段数和日语字数，把输出贴在 Comments 里。标准：闲聊类段数中位数不超过 2，讲事情类不超过约 4 段，看不出「每次都提问」的模式；口吻仍可辨认；`<ja>`/`<zh>` 和语气提示没被写坏。
- [x] 现有测试照常通过。
- [x] **人耳验收（需要人）**：打一通电话，听角色的回话长度像不像真人。
