# 应用导航

Status: ready-for-agent

术语以 `GLOSSARY.md` 为准，特别是「对话」「对话列表」「通话」「通话层」「记忆」「自带密钥」「制作人档案」「公告」「后台」「管理者」。「导航栏」（电脑）和「dock」（手机）是界面布局的词，写进 `DESIGN.md` 的 Layout，不进词汇表。这里的决定全部来自 `.scratch/affinity-and-gifts/` 里已关闭的票：「原型：应用导航外壳」（12）、「原型：像手机设置那样的一级、二级设置页面」（13）、「拍板：应用导航规格里剩下的细节」（16）、「拍板：三份规格的实现顺序和分支衔接」（19），以及「原型：礼物页」（14）里和导航有关的部分（通话条的放法、没开放时的礼物页）。后面的票推翻前面的以后面为准：16 推翻了「拍板：好感度变化由谁判断」（03）里「导航里的『礼物』入口一起隐藏」那半句；19 又规定导航先上线时没有「礼物」这一项。原型分支是 `prototype/app-navigation`（提交 `0f6eb6d`，`?variant=D` 是定稿）和 `prototype/settings-hierarchy`（提交 `0148d46`，`?sv=D` 是定稿），只作参考，以票的结论为准。

## Problem Statement

应用里现在没有统一的导航。登录后进对话列表，去别处要靠列表页首右边的几个键：GitHub、公告铃铛、「…」菜单（记忆、设置）。设置是另一张整页，左上角一个返回键回列表；记忆又是一张整页，只能从「…」菜单或设置的「档案」标签进去。接下来要加的礼物页更没地方放。

通话被绑在对话页上：离开她的对话页就挂断，哪怕只是去设置看一眼通话音质、或者回列表找另一个人。接下来的礼物要求「通话中从别处送礼，下一个通话回合她回应」，在同一个标签页里做不到。

设置页是一栏四个标签（档案、通话、自带密钥、登录与数据），「关于」挂在标签外面，记忆不在里面。标签一多就挤，而且看不出每一类现在是什么状态，要点进去才知道。

## Solution

对话、设置（礼物上线后还有礼物）放进同一个**导航外壳**，三页共用一条导航：

- **电脑**：最左边一条 72px 的**导航栏**，图标在上、字在下，从上到下是对话、（礼物、）设置，最底下是 GitHub 键。导航栏右边是这一页的内容：对话是现在的对话列表加对话，设置是一级列表加二级内容。
- **手机**：底部一条 **dock**，同样几项。进了她的对话页 dock 也在，任何输入框拿到焦点（键盘弹起）时藏起来；通话层盖住它。在二级页面上再点当前那一项，回到这一项的第一级。
- **页首的东西**：公告铃铛留在对话列表页首；「…」菜单拿掉（设置进了导航，记忆进了设置）；GitHub 在电脑上进导航栏底部，设置的「关于」里两种屏宽都有一行；列表底部的免责声明搬进「关于」。

**通话属于外壳，不属于对话页。** 通话中在对话、设置（以后还有礼物）之间换页不挂断，在不是她对话页的外壳页面上，通话收起成一条横在最顶上的**通话条**，点了就在当前页打开通话层，不跳回她的对话页；通话结束时通话条随之消失。她自己的对话页保留现有的、页首下面那条通话条。同一时间只和一位角色说话：打开另一位角色的对话前先问，确认了才挂断再打开。真的离开外壳（后台、`/about`、隐私政策、使用条款）时同样先问。退出登录和删除全部数据有自己的确认，确认了就挂断。

**设置改成像手机设置那样的一级、二级页面。** 一级六项分四组：档案、记忆／通话、自带密钥／登录与数据／关于；每行名字下面一行当前值的摘要。二级就是现在各标签的内容，没有三级。网址按路径（`/settings/profile`），旧的 `/settings?tab=…` 和 `/memories` 跳过去，不认识的回到 `/settings`。记忆成了设置的二级页，留在外壳里，去记忆不再挂断通话。档案没保存的修改在设置各类别之间切换时留着，一级列表上写「有修改未保存」。

**礼物这一项先不上。** 导航先上线时导航栏和 dock 只有对话、设置两项；「礼物」在礼物分支里加，从那时起一直留着（没开放时点进去是「礼物暂时没有开放」）。

整块在一个 `feat/app-navigation` 分支上做，分三张票：通话进外壳 → 导航栏和 dock → 设置分级。

## User Stories

### 导航外壳：电脑

1. 作为用电脑的用户，我想要屏幕最左边始终有一条导航栏，列着对话和设置，以便随时知道应用里有哪些地方、一下就能过去。
2. 作为用电脑的用户，我想要导航栏每一项都是图标在上、字在下，以便不用猜图标的意思。
3. 作为用电脑的用户，我想要当前所在的那一项有一层中性的底色、字更深更粗，以便一眼看出自己在哪。
4. 作为用电脑的用户，我想要导航栏的宽度固定、不能收起，以便它不会被我误收起来、也不用学怎么展开。
5. 作为用电脑的用户，我想要在对话这一页仍然有可以拖宽的对话列表，夹在导航栏和对话之间，以便我照旧按自己的习惯调列表宽窄。
6. 作为用电脑的用户，我想要列表拖到的宽度照旧记在这台设备上，以便加了导航栏以后不用重新调。
7. 作为用电脑的用户，我想要导航栏最底下有一个 GitHub 键、在新标签页打开仓库，以便想看源码时找得到，又不打断我正在做的事。
8. 作为用电脑的用户，我想要从对话切到设置、再切回对话时，列表还是我刚才的样子（隐藏、置顶、选中的人），以便换页不丢我整理好的东西。
9. 作为用电脑的用户，我想要在对话页里点导航栏的「对话」能回到没选人的列表，以便和从别处回来时一样。
10. 作为用电脑的用户，我想要角色和对话摘要在整个外壳里只载入一次，以便切到设置再回来不用重新等列表。

### 导航外壳：手机

11. 作为用手机的用户，我想要屏幕底部有一条 dock，列着对话和设置，以便单手就能在几处之间切换。
12. 作为用手机的用户，我想要 dock 的每一项也是图标在上、字在下，当前项有底色，以便和电脑上一致、一眼看出自己在哪。
13. 作为用手机的用户，我想要 dock 是实底、上沿一条细线、给系统手势条留出位置，以便它不会和页面内容或系统横条叠在一起。
14. 作为用手机的用户，我想要进了她的对话页 dock 仍然在输入栏下面，以便不用先退回列表就能去设置。
15. 作为用手机的用户，我想要点任何输入框（对话的输入栏、列表的搜索框、设置里的文字框）弹出键盘时 dock 藏起来、收起键盘后再出现，以便打字时屏幕上留给内容的地方够多。
16. 作为用手机的用户，我想要在她的对话页或设置的二级页面上再点 dock 里当前那一项时，回到这一项的第一级（对话列表、设置列表），以便像常见的手机应用那样一下回到顶层。
17. 作为用手机的用户，我想要通话层展开时盖住 dock，以便通话时整屏都是她，不会误点到别处。
18. 作为用手机的用户，我想要打开应用的第一眼就是单栏加 dock，不先闪一下电脑的布局，以便页面不跳。
19. 作为用手机的用户，我想要设置的一级列表和二级页面上 dock 都在，以便在设置里看完直接回对话。
20. 作为用手机的用户，我想要 dock 上每一项的触控区域足够大，以便不会点错。

### 页首和免责声明

21. 作为用户，我想要公告铃铛仍然在对话列表页首、两种屏宽一样，以便我照旧在老地方看公告、看到未读的点。
22. 作为用户，我想要对话列表页首只剩「对话」标题和铃铛，以便页首干净，不再有一个装着两个链接的「…」菜单。
23. 作为用户，我想要记忆从设置里进，以便关于我的东西（档案、记忆）都在同一处。
24. 作为用户，我想要在设置的「关于」里找到 GitHub 仓库（两种屏宽都有），以便手机上也能打开它，电脑上也多一个找得到的地方。
25. 作为用户，我想要「非官方粉丝作品，与版权方无关；角色由 AI 扮演。」这句声明在设置的「关于」里一直找得到，以便清楚这是什么样的网站。
26. 作为用户，我想要对话列表底部不再压着一行声明，以便列表能多露出一行。
27. 作为管理者，我想要后台入口照旧在「登录与数据」里，以便我不用重新找。

### 通话：在外壳里换页

28. 作为正在通话的用户，我想要从对话切到设置时通话照常进行，以便边打电话边调设置。
29. 作为正在通话的用户，我想要在手机上从她的对话页返回列表时不挂断，以便我能顺手看看别人的最后一句。
30. 作为正在通话的用户，我想要在不是她对话页的外壳页面最顶上看到一条通话条，写着她的名字和通话状态，以便时刻知道电话还连着、是和谁。
31. 作为正在通话的用户，我想要通话条用她的颜色，以便和她对话页上的通话条一眼认出是同一个东西。
32. 作为正在通话的用户，我想要点通话条就在当前页打开通话层、不跳回她的对话页，以便收起通话层后还在刚才的页面上接着做事。
33. 作为在设置页上打开通话层的用户，我想要收起后回到设置的同一个位置、通话条还在顶上，以便来回切换不丢地方。
34. 作为正在呼叫、还没接通的用户，我想要通话条上的状态和对话列表那一行一样写「正在呼叫…」，接通后写「通话中 mm:ss」，以便两处看到的是同一句话。
35. 作为在别的页面上、通话结束了的用户，我想要通话条随之消失，以便页面上不留一条已经没用的条。
36. 作为在别的页面上、通话因故结束（没接通、断线、到上限）的用户，我想要照现在的规则看到结束卡，在当前页打开，以便知道为什么断了、要不要重拨。
37. 作为正在通话的用户，我想要通话条横在导航栏右边整块的最顶上、在第二栏和页首之上，以便它不会挤进某一栏里显得像那一栏的东西。
38. 作为正在通话、用手机的用户，我想要通话条在页首之上、不贴着 dock，以便不会把它和 dock 误点混。
39. 作为正在通话、用电脑的用户，我想要在没选人的对话列表页上也看到顶上的通话条，以便关掉了对话栏也找得回通话。
40. 作为正在通话的用户，我想要在她自己的对话页上照旧是页首下面那条收起的通话条、页首电话键照旧是「回到通话」，外壳顶上不再多一条，以便同一个页面上不出现两条一样的条。
41. 作为正在通话的用户，我想要换页时她的声音不中断，以便她说到一半的话我照样听得完。
42. 作为正在通话的用户，我想要在别的页面上时，通话里说的话照样记进对话，回到她的对话页就能看到，以便一句都不漏。
43. 作为正在通话的用户，我想要对话列表里她那一行照旧显示「通话中 mm:ss」，以便在列表上也看得出在和谁通话。
44. 作为正在通话的用户，我想要从设置回到她的对话页时，通话层和刚才离开时一样（收着就收着），以便回来不用重新找位置。

### 通话：换一位角色

45. 作为正在通话的用户，我想要打开另一位角色的对话前先被问一句，以便不会因为手滑点错一行就挂了电话。
46. 作为正在通话的用户，我想要确认框写明会挂断和谁的通话，以便知道后果。
47. 作为正在通话的用户，我想要确认后先挂断、再打开她的对话，以便同一时间只和一位角色说话。
48. 作为正在通话的用户，我想要点「留在这里」后什么都不变，以便我反悔时通话照常。
49. 作为正在通话的用户，我想要在列表上点正在通话的那位角色时不被问，以便回到她身边不需要确认。
50. 作为正在通话的用户，我想要按 Esc 或点确认框外面等于「留在这里」，以便误操作不会挂断。
51. 作为不在通话中的用户，我想要换角色、换页时不被问任何事，以便平时操作没有多余的步骤。

### 通话：离开外壳

52. 作为正在通话的用户，我想要从设置去后台时先被问，以便知道去了后台通话就会挂断。
53. 作为正在通话的用户，我想要从「关于」去「关于 Eidolon-SC」、隐私政策、使用条款时先被问，以便我决定是挂了再看还是之后再看。
54. 作为正在通话的用户，我想要这几种离开都用同一个确认框，标题「会挂断和{name}的通话」、说明「离开这里，正在进行的通话就会挂断。」，以便每次看到的都是同一个意思。
55. 作为正在通话的用户，我想要确认框里「挂断并离开」是挂断红，以便一眼看出这是会挂电话的那个键。
56. 作为用户，我想要「关于 Eidolon-SC」、隐私政策、使用条款照常在本页打开，以便和以前一样，不多开标签页。
57. 作为正在通话的用户，我想要从「关于」打开 GitHub 仓库时不被问，以便它在新标签页打开、通话不受影响。
58. 作为正在通话的用户，我想要点「退出登录」只看到退出登录自己的确认，确认了就挂断并退出，以便不用连点两个确认框。
59. 作为正在通话的用户，我想要点「删除我的全部数据」只看到删除自己的确认，确认了就挂断并删除，以便不用连点两个确认框。
60. 作为正在通话的用户，我想要关掉这个页面就挂断，以便电话不会在我看不到的地方继续。

### 设置：一级

61. 作为用户，我想要设置的一级列出六项：档案、记忆、通话、自带密钥、登录与数据、关于，以便一眼看到能设置什么。
62. 作为用户，我想要六项分成四组（档案、记忆／通话、自带密钥／登录与数据／关于），组与组之间一条分隔线，以便相近的东西挨在一起。
63. 作为用户，我想要每一项前面有自己的图标，以便扫一眼就找到。
64. 作为用户，我想要每一项名字下面一行写着它现在的值，以便不点进去就知道现在是什么设置。
65. 作为用户，我想要「档案」下面写我的称呼和时区（没填称呼时写「按各自的习惯」，自动时区写「自动（{检测到的时区}）」），以便知道角色现在怎么叫我、按哪个时区算今天。
66. 作为用户，我想要「记忆」下面写有几条，一条都没有时写「还没有记忆」，以便知道她们记了多少关于我的事。
67. 作为用户，我想要「通话」下面写通话音质和电话质感开没开，以便知道下一通电话会是什么声音。
68. 作为用户，我想要「自带密钥」下面写我填了哪几项，一项都没填时写「全部用部署者的服务」，以便知道哪些费用算在我自己头上。
69. 作为用户，我想要「登录与数据」下面写我已经绑定的登录方式，以便知道能用哪几种方式登录。
70. 作为用户，我想要摘要太长时截成一行，以便列表整齐。
71. 作为用户，我想要在二级页面改了值以后，一级列表上的摘要马上跟着变，以便它不会显示旧的值。
72. 作为改了档案还没保存的用户，我想要一级列表上「档案」那行的摘要变成「有修改未保存」，以便我切到别的类别后也记得还没保存。
73. 作为用户，我想要摘要还没读到时那一行只显示名字，以便不会看到一闪而过的错误值。

### 设置：电脑

74. 作为用电脑的用户，我想要点导航栏的「设置」后，导航栏右边是一栏一级列表、再右边是选中那一类的内容，以便不用来回进出就能看遍所有设置。
75. 作为用电脑的用户，我想要一级列表顶上是「设置」大标题，选中的那一行铺中性底色、不带箭头，以便和对话列表的选中样子一致。
76. 作为用电脑的用户，我想要右边的内容页首写着类别名，内容仍然是居中、最宽 640px 的一栏，以便表单和文字不铺满整屏。
77. 作为用电脑的用户，我想要只打开 `/settings` 时右边直接显示档案、网址不变，以便右边不是空的。

### 设置：手机

78. 作为用手机的用户，我想要 `/settings` 是一级列表、每行末尾一个 ›，以便知道点进去还有一页。
79. 作为用手机的用户，我想要点一行进到二级页面，页首有返回键回到一级，以便像系统设置那样一层层走。
80. 作为用手机的用户，我想要按浏览器的返回也能从二级回到一级，以便手势返回照常好用。

### 设置：各类别

81. 作为用户，我想要「档案」二级仍是一张表单、一个「保存档案」键，以便和以前一样一次保存。
82. 作为用户，我想要「档案」页里不再重复写「制作人档案」节标题，也不再有通往记忆的一节，以便页面不啰嗦。
83. 作为用户，我想要「记忆」成了设置里的一页，「清空」在页首末端，以便管理记忆时不用离开设置。
84. 作为正在通话的用户，我想要去记忆不再挂断通话，以便边打电话边看她们记了我什么。
85. 作为用户，我想要「通话」二级和以前一样，以便不用重新熟悉。

## Implementation Decisions

### 路由和外壳

- 对话、设置（礼物上线后还有礼物）放进同一个路由组（原型里叫 `(nav)`），共用一个 layout，就是**导航外壳**：电脑上的导航栏、手机上的 dock、外壳顶上的通话条、通话层，以及对话目录。网址不变：`/conversations`、`/conversation/[characterId]`、`/settings`（及其下的类别路径），礼物上线后 `/gifts`。
- 对话这一块原来的双栏 layout（可拖宽的列表加对话）留在外壳里面，作为对话页的第二栏和内容。
- 外壳外面的页面：后台、`/about`、隐私政策、使用条款、登录、同意条款。登录和同意条款通话中到不了。
- 首屏不闪：导航栏和 dock 都只靠 CSS 断点分宽窄（导航栏窄屏隐藏、dock 宽屏隐藏），不等脚本判断屏宽；手机首屏（不跑脚本）直接是单栏加 dock。沿用现在双栏外壳水合前按 CSS 排版的做法。
- 各页现在各自占满视口；放进外壳后改成占满外壳给它的那一块。

### 外壳持有的东西

- **对话目录（DirectoryProvider）** 从对话这一块提到外壳这一层：登录的用户、角色、和每位最新一次对话的摘要、这台设备上的隐藏和置顶、通话的快照、离开前的确认，整个外壳只载入一次，设置页（以后还有礼物页）也拿得到。现在「进设置再回来时外壳重新挂载、登录的用户重新载入」的说法不再成立。
- **通话提到外壳**。现在对话页自己建一份对话的实时状态（LiveConversation，管着这段对话的记录、文字回合、通话和通话层），离开对话页就丢掉它，通话随之挂断。改成：
  - 有通话在进行时，这份实时状态、她的声音（CharacterVoice 和放声音的元素）、电话本身的声音（铃声、接通音、挂断音）、通话层、切换麦克风的面板都由外壳持有，换页时不卸下。
  - 对话页打开时，如果正在通话的就是这位角色，用外壳里那一份，不另建；回到她的对话页时，记录、通话层收没收起都和离开时一样。
  - 通话层在哪一页都能打开：在别的外壳页面上点通话条，通话层就在当前页展开，不跳回她的对话页。手机上照旧铺满整屏、盖住 dock；电脑上盖住导航栏右边的整块（在对话页上盖住对话栏的同一个做法，换成盖住当前页）。收起后还在原来的页面上。
  - 通话在通话层收着时结束，不论在哪一页，都照现在收起时结束的做法：通话条随之消失；因故结束（没接通、断线、到上限等）时通话层照现在的规则自己展开、显示结束卡，在当前页展开。
  - 不在通话中时，离开她的对话页和现在一样。
  - LiveConversation 本身的状态机（拨号、接通、结束、收起、展开）不因为这次改动变样；变的是谁持有它、它活多久。
- 「离开前确认」（对话目录的 leave）改成按去处判断，不再是「离开对话页就问」。规则：

  | 去处 | 不在通话中 | 通话中 |
  | --- | --- | --- |
  | 外壳里换页：对话列表、她自己的对话、设置各类别（以后还有礼物） | 直接去 | 直接去，不挂断 |
  | 打开另一位角色的对话（包括以后礼物页「去对话」去的是另一位） | 直接去 | 先问，确认后挂断再打开 |
  | 离开外壳：后台、`/about`、隐私政策、使用条款 | 直接去 | 先问，确认后挂断再离开 |
  | 退出登录、删除我的全部数据 | 各自的确认 | 只有各自的确认，确认了就挂断 |
  | 新标签页打开的链接（GitHub 仓库、公告里的链接） | 直接打开 | 直接打开，不挂断 |
  | 关掉页面 | — | 挂断 |

  挂断都算用户自己挂断（GLOSSARY「通话」）。

### 通话条

- **在哪出现**：通话中（呼叫中或已接通）、通话层收着、而且当前页面不是她的对话页时：设置、礼物（礼物上线后）、手机上的对话列表、电脑上没选中对话的 `/conversations`。
- **放在哪**：两种屏宽都在外壳最顶上，横跨导航栏右边的整块，在第二栏和页首之上。手机上在页首之上，不贴 dock。导航栏和 dock 不被它压缩。
- **样子**：40px 高（沿用现有的通话条高度 token），她的 `call.deep` 底、白字，她的颜色用现有的注入方式给这一条；左边白色小圆点（呼叫中闪烁），接着她的名字和通话状态，右端「回到通话 ›」。通话状态的文字沿用对话列表那一行的：呼叫中「正在呼叫…」，接通后「通话中 mm:ss」。整条是一个按钮，点了在当前页打开通话层。可以复用对话页上现有的通话条组件，多带上她的名字。
- **她自己的对话页上不出现这一条**：她的对话页保留现有的那条，通话层收起后在页首下面，页首电话键「回到通话」也照旧；外壳顶上不再加。
- 通话结束时通话条随之消失（见上「外壳持有的东西」）。
- 通话层展开时，底下的外壳（导航栏、dock、通话条、页面）都 `inert`，和现在通话层盖住对话栏时一样。手机上通话层盖住 dock。

### 确认框

- 沿用对话目录里现有的那一个 `AlertDialog`，中性色加挂断红，不在她的子树里：
  - 标题照旧「会挂断和{name}的通话」。
  - 说明改成「离开这里，正在进行的通话就会挂断。」（现在是「离开这个对话，正在进行的通话就会挂断。」）。
  - 按钮照旧「留在这里」（取消）、「挂断并离开」（`destructive`，挂断红）。
- 换一位角色、离开外壳都用这一个框。Esc、点框外等于「留在这里」。

### 电脑导航栏

- 最左一条 72px，右边一条 `border-r` 细线，不能收起。不用已装的 shadcn `Sidebar`（那是后台的页框，带字窄栏用不上它的展开、收起）。
- 从上到下：对话、设置（礼物上线后：对话、礼物、设置）。每项图标在上、字在下：当前项的图标外面铺一层中性 `bg-muted` 圆角底，字用 foreground 加 medium；其余图标和字都是 muted，悬停时图标底 `bg-muted/60`。
- 最底下是 GitHub 仓库的 ghost 图标键，新标签页打开，读屏名字「GitHub」。
- 当前项按网址判断：`/conversations` 和 `/conversation/…` 是对话，`/settings…` 是设置，`/gifts` 是礼物。当前项标 `aria-current="page"`，整条是一个带名字的 `nav`。
- 点当前项：在这一项的二级页面上（她的对话页、设置的二级页面）点，回到这一项的第一级（`/conversations`、`/settings`）；已经在第一级时不动。和 dock 同一条规则。
- 第二栏跟着切换：对话是现在的对话列表（仍可在 240–480px 之间拖宽，记在设备上）；设置是 320px 的一级列表（见下）。

### 手机 dock

- 底部一条，项目和顺序同导航栏（先上线时对话、设置两项；礼物上线后对话、礼物、设置三项）。图标在上、字在下，当前项的样子同导航栏。实底，上沿一条 `border-t`，底部留出 safe-area。触控目标不小于 44px。
- 进了她的对话页也在，在输入栏下面。
- 任何页面上任何输入框拿到焦点（键盘弹起）时藏起来，失去焦点后回来：对话的输入栏、列表的搜索框、设置里的文字框都算。判断照原型：拿到焦点的是 textarea、不是勾选框的 input 或可编辑元素。
- 通话层展开时被盖住。
- 设置的一级、二级页面上都在。
- 在二级页面上（她的对话页、设置的二级页面）再点当前那一项，回到这一项的第一级（对话列表、设置列表）。

### 页首的东西搬到哪

- **对话列表页首**：最后只剩左边「对话」大标题和右边公告铃铛，两种屏宽一样。「…」菜单（记忆、设置）拿掉，GitHub 键也拿掉。铃铛、未读点、公告弹窗都不变；公告不进导航栏、dock，也不进设置。
- **GitHub**：电脑在导航栏底部；设置「关于」里有一行「GitHub 仓库」，两种屏宽都有。
- **免责声明**：对话列表底部那一行拿掉，搬进设置「关于」最下面，Meta 字号，文字「非官方粉丝作品，与版权方无关；角色由 AI 扮演。」。落地页首屏和页脚、登录页页脚上的照旧；应用里只留「关于」这一处。「已隐藏 n 位」那一行成了列表的最后一行。
- **分两步搬**：第 2 张票拿掉「…」菜单，电脑上的 GitHub 移进导航栏（电脑列表页首不再有 GitHub 键）；手机列表页首的 GitHub 键和列表底部的免责声明先不动。第 3 张票有了「关于」以后再把它们搬进去，列表页首从此两种屏宽都只剩标题和铃铛。
- **后台入口**：照旧在「登录与数据」里，只有管理者看得到。

### 设置：电脑和手机的版式

- **电脑**：导航栏右边第二栏 320px，`border-r`；顶上「设置」大标题（List title），下面一级列表。当前项铺 `bg-muted`，不显示 ›。右栏页首是类别名（没有返回键），内容沿用现有页面骨架（PageShell）的 640px 一栏、居中。只打开 `/settings` 时右栏显示档案、一级里档案是当前项，网址不变。
- **手机**：`/settings` 是一级列表，每行末尾 ›；`/settings/<类别>` 是二级页面，页首左边返回键回到 `/settings`，接着类别名。dock 在一级、二级都在。
- 两种屏宽同一套路由，只靠 CSS 断点决定手机上露哪一级，首屏不闪。

### 设置：二级

二级就是现在各标签的内容，没有三级：

- **档案**：制作人档案表单，仍是一张表单一个「保存档案」键。页首已经是「档案」，表单不再写「制作人档案」节标题；原来档案里通往记忆的那一节去掉。
- **记忆**：现在的记忆页整页搬进来（只能删、不能改，删除一条和清空都要确认），「清空」在二级页首的末端。记忆页的主体抽出来，页首交给设置的二级页首。
- **通话**：照旧。
- **自带密钥**：一页三项，不拆成每项服务一页。
- **登录与数据**：登录方式、后台（只有管理者）、退出登录、删除我的全部数据，顺序照旧。

## Testing Decisions

- **好的测试只看外部行为**：给定一个网址和「有没有在通话、和谁」，得到哪个导航项是当前项、通话条出不出、去某处会不会先问、会不会挂断；给定旧网址，得到新路径；给定当前值，得到一级列表上的那一句摘要。不测组件怎么拆、谁调用了谁，也不断言样式类名。
- **测试接缝**只有两个，都是前端纯模块、用 vitest：
  1. **外壳的去处规则**（新的纯模块，不依赖 React）：输入网址和正在进行的通话（哪位角色，或者没有），回答当前导航项、是不是在外壳里、要不要显示外壳顶上的通话条、再点当前项回到哪一级、去某个网址时通话是留着、先问再挂断还是直接走。外壳 layout、导航栏、dock、确认框都只照它的回答做，所以测它就测到了票 1、票 2 的全部判断。写法照现有的对话列表、列表偏好那类纯模块测试。
  2. **设置类别模块**（把现有的「设置标签」模块和它的测试改写过来，接缝已有）：类别清单和分组、路径和类别互转、`/settings?tab=…` 和 `/memories` 换成新路径、不认识的 `?tab=` 和 `/settings/<xxx>` 换成 `/settings`、`settingsHref` 给路径、各类摘要（包括「还没有记忆」「全部用部署者的服务」「有修改未保存」）。「有修改未保存」用现有档案草稿模型的判断，草稿模型的测试照旧。
- **LiveConversation 不新加接缝**：它的状态机不变，现有的那组用假端口驱动的测试照旧通过。如果提到外壳时要改它的接口，就在同一组测试里加，不另起。
- **后端**只改绑定登录方式的回跳地址：现有那组绑定登录方式的 HTTP 测试里，断言的回跳地址跟着改成 `/settings/sign-in?…`，不加新测试。
- **组件不写测试**，仓库里本来就没有组件测试。外壳、导航栏、dock、通话条、设置页的行为在本地构建版上用 Playwright 跑一遍验收，不写进测试代码：
  - 电脑和手机两种宽度，手机首屏（不跑脚本）是单栏加 dock；
  - 通话中切到设置、手机上回列表都不挂断，顶上出现通话条，点了在当前页打开通话层、收起后还在原页，她的声音不断；她自己的对话页上只有页首下面那条；
  - 通话在设置页上结束时通话条消失，因故结束时结束卡在当前页出现；
  - 通话中打开另一位角色、去后台、去 `/about` 都弹出同一个确认框，「留在这里」不挂，「挂断并离开」挂；
  - 通话中退出登录只有一个确认框；
  - 手机上点对话输入栏、搜索框、设置里的文字框 dock 都藏起；在她的对话页、设置二级页再点 dock 当前项回到第一级；
  - 设置六项和摘要，改通话音质后摘要马上变，改档案不保存时显示「有修改未保存」、切类别再回来草稿还在；
  - `/settings?tab=own-keys`、`/memories` 跳到新路径，`/settings?tab=xxx`、`/settings/xxx` 回到 `/settings`，按返回不回旧网址；
  - 绑定一种登录方式后回到 `/settings/sign-in` 并看到提示；后台「返回设置」到 `/settings/sign-in`。
- 每张票做完跑一遍现有的前端测试和纪律检查脚本。

## Out of Scope

- 可以收起的导航栏、shadcn `Sidebar` 做导航（比较过，不用）。
- 只有图标、不带字的导航栏（比较过，不用）。
- 公告进导航栏、dock 或设置一级（铃铛只留在对话列表页首）。
- 设置的三级页面，或者自带密钥拆成每项服务一页、每项改了就存（比较过，不用）。
- 礼物页的内容和「礼物」这一项本身：归礼物规格，在 `feat/gifts` 分支加。
- 「礼物」项在好感度和礼物关闭时隐藏（03 里那半句已被 16 推翻）。
- 好感度相关的界面（页首心形标识、变化胶囊、冷却、她挂断）：归好感度规格，在新外壳上做。
- 在对话列表里显示好感度（地图上用户明确不要）。
- 离开设置时为没保存的档案弹框提示，或者把档案以外的类别里填到一半的东西留住。
- 同时和多位角色通话，或者跨浏览器标签页保持通话。
- 后台、`/about`、隐私政策、使用条款放进外壳，或者改成新标签页打开。
- 后台自己的页框和侧栏（除了「返回设置」改去 `/settings/sign-in`，不动）。
- 隐私政策、使用条款、落地页、README 的文字和截图：这块不改，README 截图在礼物分支最后一张票里统一重拍。

## Further Notes

- **为什么要写 ADR**：「通话属于外壳」改了一个用户能感觉到、而且以后不好改回去的边界（换页不挂断），礼物的「通话中从别处送礼」也建在它上面。其他界面上的决定进 `DESIGN.md`，不另写 ADR。
- **和另外两块的衔接**（19）：顺序是导航 → 好感度 → 礼物，各自从 main 开分支，前一块合进 main 后再开下一块。好感度要改对话页页首、变化胶囊、通话层里她挂断，和本块第 1 张票改的是同一批文件，所以不同时做，好感度直接在新外壳上做。好感度先上线时所有送礼入口都藏着，礼物分支加上「礼物」项和这些入口。
- **术语**：导航栏和 dock 只进 `DESIGN.md`；词汇表的「对话列表」避免说「侧栏」，导航栏也不叫侧栏。
