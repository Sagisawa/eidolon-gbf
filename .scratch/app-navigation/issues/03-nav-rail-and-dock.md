# 03: 导航栏和 dock

**What to build:** 电脑上最左边一条 72px 的导航栏（对话、设置，GitHub 在最底下），手机上底部一条 dock（对话、设置），用户在任何外壳页面上都能一下切到对话或设置。手机上输入框拿到焦点（键盘弹起）时 dock 藏起来；在二级页面上再点当前那一项回到这一项的第一级。对话列表页首拿掉「…」菜单，电脑上的 GitHub 键移进导航栏；手机列表页首的 GitHub 键和列表底部的免责声明这张票先不动（等第 04 张票有了「关于」再搬）。见规格「电脑导航栏」「手机 dock」「页首的东西搬到哪」。
