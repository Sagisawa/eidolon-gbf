# 02: 通话属于外壳

**What to build:** 通话不再跟着对话页的生命周期，改由导航外壳持有：通话中切到设置、手机上回到对话列表都不挂断，她的声音不断；在不是她对话页的外壳页面上，最顶上出现一条带她名字的通话条，点了就在当前页打开通话层。同一时间只和一位角色说话：打开另一位角色的对话、离开外壳（后台、`/about`、隐私政策、使用条款）先问再挂断。导航还是老样子（列表页首的 GitHub、铃铛、「…」菜单都在，设置还是四个标签，记忆还在外壳外面、去记忆照旧要确认）。见规格「外壳持有的东西」「通话条」「确认框」，以及测试接缝「外壳的去处规则」。

**Blocked by:** 01（外壳路由组和对话目录上提）

**Status:** ready-for-agent

- [ ] 有通话在进行时，对话的实时状态、她的声音、电话本身的声音（铃声、接通音、挂断音）、通话层、切换麦克风的面板都由外壳持有，换页时不卸下；回到她的对话页时用外壳里那一份，记录和通话层收没收起都和离开时一样
- [ ] 通话中从她的对话页切到设置、手机上回到对话列表、电脑上回到没选中对话的 `/conversations`，通话都不挂断
- [ ] 这些页面最顶上出现通话条：横跨外壳整宽、在页首之上，40px，她的 `call.deep` 底，白色小圆点（呼叫中闪烁）、她的名字、和对话列表那一行相同的通话状态文字（「正在呼叫…」「通话中 mm:ss」）、右端「回到通话 ›」；她自己的对话页上不出这一条，保留现有页首下面那条
- [ ] 点通话条，通话层在当前页展开（手机铺满整屏，电脑盖住内容区），收起后还在原来的页面；通话层展开时底下的外壳都 `inert`
- [ ] 通话在通话层收着时结束，通话条随之消失；因故结束（没接通、断线、到上限等）时通话层照现在的规则在当前页展开、显示结束卡
- [ ] 新的「外壳去处规则」纯模块（不依赖 React）有 vitest：给定网址和正在通话的角色（或没有），回答当前在不在外壳里、要不要显示外壳顶上的通话条、去某个网址时通话是留着、先问再挂断还是直接走
- [ ] 确认框按去处判断：打开另一位角色的对话、去后台、去 `/about`、隐私政策、使用条款时先问；退出登录、删除我的全部数据只有各自的确认，确认了就挂断；新标签页打开的链接不问不挂
- [ ] 确认框说明改成「离开这里，正在进行的通话就会挂断。」，标题和按钮照旧
- [ ] 对话的实时状态的状态机不变，现有用假端口驱动的那组测试照旧通过（改了接口就在同一组里补）
- [ ] 新 ADR「通话属于外壳、不属于对话页」
- [ ] `GLOSSARY.md`「通话」「通话层」按规格「分支和三张票」第 1 条里的措辞改写
- [ ] `DESIGN.md` 的 Call layer（外壳顶上的通话条、通话层在别的页面上展开时盖住哪里）和 Overlays（确认框的新说明，用在换角色和离开外壳）跟着改
- [ ] 本地构建版上用 Playwright 验收：通话中切设置、手机回列表不挂断、通话条出现、点了在当前页打开通话层、她的声音不断；通话中打开另一位角色、去后台、去 `/about` 都弹同一个确认框，「留在这里」不挂、「挂断并离开」挂；通话中退出登录只有一个确认框
