# 05: 设置一级的摘要和没保存的档案草稿

**What to build:** 设置一级的每一行名字下面多一行当前值摘要，用户不点进去就知道每一类现在是什么样，在二级里改了值摘要马上跟着变。档案没保存的草稿提到设置的 layout，在设置各类别之间切换时留着（离开设置就丢，不弹框）；有改动没保存时，一级「档案」那行的摘要换成「有修改未保存」。见规格「设置：一级」的摘要部分和「设置：没保存的档案草稿」。

**Blocked by:** 04（设置按路径分成一级、二级）

**Status:** ready-for-agent

- [ ] 每行名字下面一行 subtitle 字号 muted 的摘要，单行截断；还没读到值时只显示名字
- [ ] 各类摘要：档案「称呼 · 时区」（称呼没填写「按各自的习惯」，时区自动时「自动（{检测到的时区}）」）；记忆「n 条」或「还没有记忆」；通话「通话音质 · 电话质感开／关」；自带密钥「全部用部署者的服务」或「已填 LLM、语音合成」这样按 LLM、语音合成、语音识别的顺序列出；登录与数据是已绑定的登录方式用「、」连；关于没有摘要
- [ ] 摘要跟着变，不用换页：档案保存后、记忆删除或清空后、通话偏好改了、自带密钥填了或删了
- [ ] 档案草稿（现有的档案草稿模型）提到设置的 layout：改了档案没保存，切到别的类别再回来，草稿还在；离开设置就丢，不弹框
- [ ] 有改动没保存时一级「档案」那行的摘要整句换成「有修改未保存」，档案页里照旧有「尚未保存」
- [ ] 各类摘要的写法放进「设置类别」模块并有 vitest（包括「还没有记忆」「全部用部署者的服务」「有修改未保存」）；「有修改未保存」用现有档案草稿模型的判断，草稿模型的测试照旧
- [ ] `DESIGN.md`「设置页」补上一级摘要的样子
- [ ] 本地构建版上用 Playwright 验收：六项摘要、改通话音质后摘要马上变、改档案不保存时显示「有修改未保存」、切类别再回来草稿还在
