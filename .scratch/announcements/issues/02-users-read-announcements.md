# 02: 用户看公告

**What to build:** 用户在对话列表页首能看到公告。

- **铃铛键**：在 GitHub 键和更多菜单之间。
  - 样式是 ghost `icon-lg`，图标用 Lucide `Bell`。
  - 有未读公告时，右上角一个 6px 的 `bg-foreground` 圆点。
  - 读屏名字是「公告」，有未读时是「公告，有未读」。
- **公告弹窗**：点铃铛打开，两种屏宽都用居中的 `Dialog`。
  - 标题是「公告」，没有右上角的 ✕。
  - 列出最近 20 条公告，从新到旧。每条先是一行 muted 小字的发布日期（按设备时区，只写日期），未读的那条日期后面带 secondary Badge「新」；下面是用 01 的 Markdown 正文组件渲染的正文；条与条之间用 `Separator` 隔开。
  - 没有公告时显示 `Empty`「还没有公告」。
  - 底部两个键：
    - 「关闭」（ghost）：只收起弹窗，点还在。按 Esc 或点弹窗外面，效果相同。
    - 「已读」（default）：把当前列表里所有公告标为读过，然后收起弹窗，点消失。没有未读时禁用。
- **已读状态**：存在这台设备上，键名是 `eidolon.announcementsRead.<userId>`，同一台设备上的不同用户分开。从没点过「已读」时，所有公告都算未读。
- **拉取时机**：对话列表加载时拉一次，切回这个标签页时再拉一次。拉取失败时不报错，保持上一次的状态。

详见 `.scratch/announcements/spec.md`。

## Comments

### 实现说明（2026-10-12）

- `lib/announcements.ts` 加了已读、未读的部分：`readUpTo` / `keepReadUpTo`（键 `eidolon.announcementsRead.<userId>`，存的是 JSON 字符串形式的发布时间；读不到、不是时间都当作没读过；另在模块里按用户记一份，存不进去时这次页面里照样算数，两份取较晚的那个）、`unread`（按时间比较，不按字符串）、`newestPublished`（「已读」要存的值）。测试在 `announcements.test.ts`。
- 铃铛和弹窗是 `components/conversations/Announcements.tsx`，放在 `ConversationList` 页首 GitHub 键和更多菜单之间；`userId` 从 `useDirectory().account` 来，账号还没载入时不显示点。已读时间点每次渲染现读，点「已读」后收起弹窗的那次渲染就读到新的，不另存一份状态。
- 弹窗：`Dialog`（`sm:max-w-md`，不显示 ✕），列表 `max-h-[70dvh]` 滚动；日期用对话列表的 `fullDate` 写法（年/月/日，设备时区）；底栏在调用处加 `flex-row justify-end`，窄屏也是右对齐的一行，不像默认那样竖排。
- 图标 Lucide `Bell` 导出为 `AnnouncementsBellIcon`。文案在 `copy.conversationList`。
- DESIGN.md：「Conversation list」页首改成三个键并加了「公告铃铛」一条；「Overlays」加了「公告弹窗」；「Icons」写明公告的两个图标走现有规则。
- 本地用构建版跑过：有未读时铃铛带点、读屏名字「公告，有未读」；弹窗内容和排序、「新」标记、列表、链接、行内代码正常；Esc 收起、点保留；「已读」后点消失、localStorage 存的是最新那条的发布时间；再发布一条后触发 `visibilitychange`，点重新出现，只有新的那条带「新」；全部读过时「已读」禁用；没有公告时是「还没有公告」；390px 窄屏页首和弹窗都正常。

#### 人工验证清单

- 宽屏和窄屏的对话列表页首依次是「对话」、GitHub、铃铛、「…」。
- 管理者在后台发布一条公告，用户切走再切回对话列表标签页，铃铛出现点（不用刷新）。
- 点开弹窗：最新的在上，每条有发布日期，没读过的带「新」；正文里的链接在新标签页打开，通话不断。
- 「关闭」、Esc、点弹窗外面都只收起，点还在；「已读」后点消失，再打开时「已读」不可点、没有「新」。
- 修改那条已发布的公告（只改错字），用户切回标签页，点不会重新出现；撤回后再发布，点重新出现。
- 用另一个账号在同一个浏览器登录，已读状态和前一个账号分开。
- 隐私模式（或禁用存储）下铃铛照样能用，点「已读」后点消失，刷新后又是未读。
- 读屏软件读铃铛：没有未读时「公告」，有未读时「公告，有未读」。
- 深色、浅色模式下弹窗和点都清楚。
