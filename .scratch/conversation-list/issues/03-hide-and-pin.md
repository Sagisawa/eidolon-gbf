# 03: 隐藏、置顶和筛选面板

**What to build:** 用户可以在这台设备上隐藏和置顶角色（GLOSSARY.md「对话列表」「隐藏 / 置顶」）：

- **行菜单**：电脑上右键、手机上长按一行，或者用键盘的菜单键，弹出「置顶 / 取消置顶」「在列表中隐藏 / 在列表中显示」。
- **筛选面板**：搜索框右边加一个筛选按钮，打开按组合分组的勾选清单，可以整组或单人隐藏，右上角有「全部显示」。宽屏用 Popover，窄屏用 Drawer。
- **置顶**：置顶的排在最前面，她们之间按最近往来排，时间旁边有个小图钉。
- **隐藏**：
  - 隐藏的人照样能搜到；
  - 正打开着的人和正在通话的人始终留在列表里；
  - 有人被隐藏时，筛选图标上有个不显眼的小点，列表底部有一行「已隐藏 n 位」；
  - 全部隐藏时，列表显示空状态。

规则见 spec「隐藏和置顶（前端）」。

**Blocked by:** 01（多语言搜索）、02（按最近往来排序）
