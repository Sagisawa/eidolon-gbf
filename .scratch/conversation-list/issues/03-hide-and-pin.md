# 03: 隐藏、置顶和筛选面板

**What to build:** 用户可以在这台设备上隐藏和置顶角色（GLOSSARY.md「对话列表」「隐藏 / 置顶」）：

- **行菜单**：电脑上右键、手机上长按一行，或者用键盘的菜单键，弹出「置顶 / 取消置顶」「在列表中隐藏 / 在列表中显示」。
- **筛选面板**：搜索框右边加一个筛选按钮，打开按组合分组的勾选清单，可以整组或单人隐藏，右上角有「全部显示」。宽屏用 Popover，窄屏用 Drawer。
- **置顶**：置顶的排在最前面，她们之间按最近往来排，时间旁边有个小图钉。
- **隐藏**：
  - 隐藏的人照样能搜到；
  - 正打开着的人和正在通话的人始终留在列表里；
  - 有人被隐藏时，筛选图标上有个不显眼的小点，列表底部有一行「已隐藏 n 位」；
  - 全部隐藏时，列表显示空状态。

规则见 spec「隐藏和置顶（前端）」。

## 人工验证清单（实现后补充到 Comments）

- 电脑宽度和 375px 宽度，浅色和深色各看一遍：右键、长按菜单，筛选 Popover 和 Drawer，三态勾选，小点，图钉，「已隐藏 n 位」，全部隐藏的空状态。
- 置顶两位，分别和她们聊一句，确认置顶区里也按最近往来排。
- 隐藏一位置顶的人，确认置顶被取消；在搜索结果里把一位隐藏的人置顶，确认她恢复显示。
- 通话中隐藏她，确认那一行留着；离开对话后，她消失。
- 换账号登录，确认两个账号的隐藏和置顶互不影响。
