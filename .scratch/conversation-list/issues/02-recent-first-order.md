# 02: 按最近往来排序

**What to build:** 对话列表里，最近有过往来的角色排在上面，开了新对话也算往来；从没聊过的排在最后，按原作的偶像顺序。发出一句话、回复记下之后，或者开了新对话之后，她那一行马上到最上面，直接跳过去，不做动画。搜索结果用同一套排序。规则见 spec「排序（前端，纯逻辑）」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 对话列表逻辑模块新增一个纯逻辑的列表编排函数，放在 `previewOf`、`dayOf` 旁边：输入角色和每位角色的最新对话摘要，给出按显示顺序排好的角色。列表组件只渲染它的结果。
- [ ] 「最近往来时间」就是这一行显示的时间：最新一次对话的最后一句的时间，对话还没有话时取开对话的时间。
- [ ] 有这个时间的角色按时间从新到旧排，时间相同的按接口给的顺序；没有的排在后面，保持接口给的顺序（原作的偶像顺序）。
- [ ] 单测至少覆盖：
  - 几位聊过的按最近排；
  - 开了新对话、还没说话的，按开对话的时间算；
  - 没聊过的在后面、保持原顺序；
  - 时间相同时按原顺序；
  - 一位都没聊过时就是原顺序；
  - 摘要里有配置中已经不存在的角色时，不出错，也不多出一行。
- [ ] 在列表里发一句话，回复记下后她那一行到最上面；开新对话后同样如此；通话中每记下一个回合也是。列表不做位移动画。
- [ ] 搜索时，结果也按同样的顺序排。
- [ ] 列表不按组合分段，仍是一整列。
- [ ] 这一票不改搜索规则。01 并行在改列表组件里过滤的那一行，合并时只保留两边各自的改动。
- [ ] 前端单测和 shadcn 纪律检查都通过。

## 人工验证清单（实现后补充到 Comments）

- 和排在后面的一位角色聊一句，回到列表，她在最上面。
- 开一个新对话，她到最上面，那一行显示「新的对话，还没有说话」。
- 没聊过的几位排在最后，按官方顺序。
