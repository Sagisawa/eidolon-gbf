# 09: 第 3、4 幕：她说日语，你看字幕；她打来电话

**What to build:** 第 3 幕用排版演示「日语原文竖排在上，中文字幕像被光扫过一样出现」。第 4 幕模拟一次来电：全屏是她，屏幕振动、发光；访客点或长按「接听」才响起铃声和接通音，滚动经过时只有画面在响。背景见 `../spec.md` 的八幕描述和「交互状态」，术语见 `GLOSSARY.md` 的「通话」「铃声」「接通音」。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 落地页模型的画面描述扩展到第 3、4 幕（幕内进度、字幕扫光的进度、来电的光脉冲）；交互 reducer 增加接听：没接听就不出声，接听后的声音也遵守声音开关。都有测试。
- [ ] 第 3 幕：日语竖排，保留口癖和语气词；字幕被光扫出来，不用打字机效果。演示用的台词由 agent 写，不引用剧情原文，在本波验收时交用户审。
- [ ] 第 4 幕：铃声在视觉上用振动和光的脉冲表现；电脑上点「接听」、手机上长按「接听」（按压时长驱动一圈色光收束）才出声。铃声和接通音复用应用现有的通话提示音。
- [ ] 「减少动态效果」档：字幕直接完整显示，来电画面静止，接听仍然能出声。「不支持 WebGL」档：两幕都用静态版式。
- [ ] 两幕的文案由 agent 起草，在本波验收时交用户审。
