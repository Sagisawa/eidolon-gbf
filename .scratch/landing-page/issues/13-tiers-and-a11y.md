# 13: 全站降级与无障碍：每一档、每一种设备都能完整读完并登录

**What to build:** 把三个档位、键盘和读屏、手机真机这几件事贯穿整个八幕检查一遍，补上缺口。开了「减少动态效果」的人看到定格的光谱和完成态的各幕；浏览器不支持 WebGL 或开了省流量的人看到 CSS/SVG 画的静态光；用键盘和读屏器的人能聚焦每位偶像、听她的招呼、读完全部说明并登录。背景见 `../spec.md` 的「分档」和用户故事 66–73。

**Blocked by:** 09, 10, 11

**Status:** ready-for-agent

- [ ] 静态版式下，左侧幕名轨也随滚动更新（原型里还不会）。
- [ ] 「减少动态效果」档：从头到尾没有惯性横滚和滚动驱动的动画；立绘只显示静帧，不再用头像代替（原型里是用头像代替的）。
- [ ] 「不支持 WebGL」档：静态光里补上棱镜出口附近的连续色散（原型里没有）。
- [ ] 运行中掉帧时自动降档，并且不会来回切换；在一台中端手机上实测。
- [ ] 键盘：Tab 顺序合理，可以聚焦每道光，Enter 播放招呼，可以按组合跳转，能打开登录面板；焦点始终看得见。
- [ ] 读屏：名字、招呼、各幕说明都能读到；纯装饰的 canvas 不打扰读屏。
- [ ] 原生滚动的能力都正常：键盘翻页、页内查找、浏览器后退回到原位置。
- [ ] 手机真机（至少一台 iOS、一台 Android）走完八幕，不卡、不烫，横屏也能用。
