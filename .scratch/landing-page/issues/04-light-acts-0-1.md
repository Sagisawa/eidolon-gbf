# 04: 光与第 0、1 幕：白光射进棱镜，散成 28 道印象色

**What to build:** 访客打开页面看到一束白光，它随鼠标或手指改变角度；往下滚，白光射进棱镜，按色相散成彩虹，离开棱镜后收拢成 28 条官方色带。这一张把落地页模型的「画面描述」和档位、Lenis、OGL 光层接起来。背景见 `../spec.md` 的「前端：落地页模型」「前端：渲染层」，原型拍板的做法见原型分支（光的几何与插值、着色器与色散采样、OGL 的两个坑、分档、弹簧、首屏前定档的脚本）。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 落地页模型新增「画面描述」：输入滚动进度、视口和档位，输出当前幕和幕内进度、白光与 28 道光的位置、宽度、颜色、强度，以及色散强度。第 1 幕是色相顺序，色散只在转场时出现，随滚动速度变大。
- [ ] 落地页模型新增档位 reducer：首屏前根据 `(hover:none)`、`prefers-reduced-motion`、`saveData` 和 WebGL 是否可用定初始档；运行中按帧时只降不升。每档决定 DPR 上限、色散采样次数（5、3、1）和焦散开关。
- [ ] 模型测试覆盖：第 0、1 幕边界上的画面描述；同屏满强度的光不超过上限；分光后只出现 28 种官方色；档位只降不升；「减少动态效果」档在任何进度下都是完成态。
- [ ] 原生滚动加 Lenis（`lerp≈0.1`，触屏不做平滑），不接管滚轮。新增依赖只有 `lenis` 和 `ogl`，只在落地页加载。
- [ ] OGL 全屏 canvas 在首屏内容画出来之后、浏览器空闲时动态加载；着色器分批预编译。每道光是白芯加印象色光晕；不做全屏 bloom；交叠用 `max` 或 screen。
- [ ] 首屏的 CSS 白光和 OGL 的白光无缝衔接，标题始终可见。
- [ ] 「减少动态效果」档：着色器只渲染一帧定格的画面后停下。「不支持 WebGL」或省流量档：不加载 canvas，用 CSS/SVG 画出第 0、1 幕的静态光。
- [ ] 验收脚本：落地页自身的首屏 JS 压缩后不超过 50 KB（不含框架基线），手机 4G 下 LCP 不超过 2.5 秒；两个降级档各截一张图。
