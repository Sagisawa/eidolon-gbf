# 15: 竖屏手机上光谱的立绘被屏幕边缘裁掉

**What to build:** 用户在 14 号票人工验收时发现：手机竖屏的第 2 幕里，聚焦某些偶像时立绘被摆到靠近屏幕侧边，一部分出了屏幕，看不全。改成立绘始终完整落在她那个组合的一屏里（不压幕名轨）。背景见 `05-act-2-spectrum.md`。

**Blocked by:** 05

**Status:** ready-for-human

## 原因

`LightStage.tsx` 的 `standX` 把立绘摆在她名牌外侧「空间大的一边」，中线 = 名牌横坐标 ± (立绘宽 / 2 + 24px)，没有夹到屏幕里。电脑上立绘宽 `min(50vw, 66vh)`，放得下；竖屏（`max-aspect-ratio: 10/11`）立绘宽 74vw，名牌两侧都放不下，就出屏。

按 390px 宽的手机算（幕名轨 36px，`slotX` 两边留 6vw）：

| 组合人数 | 第几位 | 名牌 x | 立绘左右边 | 出屏 |
| --- | --- | --- | --- | --- |
| 3 | 1 | 111 | 135 – 423 | 右边 33px |
| 3 | 2 | 213 | 237 – 525 | 右边 135px（近一半） |
| 3 | 3 | 315 | 3 – 291 | 左边压住幕名轨 |
| 4 | 2 | 175 | 199 – 487 | 右边 97px |
| 4 | 3 | 251 | −61 – 227 | 左边 61px，再压幕名轨 |

所以「有时候」：取决于她在组合里第几位，组合中间的人最严重。

## 做法

- [x] 立绘的横向位置挪进落地页模型（`model/scene.ts`，和 `slotX` 放一起）成纯函数：先按现在的规则放在空间大的一边，再夹到 `[这一屏左边 + 幕名轨宽, 这一屏右边]` 里；立绘比这段还宽时在这段里居中。模型测试覆盖：电脑上和现在摆位一致（不回归）；竖屏手机上每个组合的每一位都不出屏、不压幕名轨。
- [x] `LightStage.tsx` 的 `placeStand`、`placeGreeting` 改用这个函数；字幕原来就有夹紧，跟着新的立绘中线走即可。
- [x] 夹紧后竖屏的立绘会和她自己的名牌重叠：~~她的名牌仍在立绘之上（05 号票定下的层级，不改）~~ 用户看过后改了：竖屏上立绘也压在她的名牌上面（见下方评论），其他人的名牌在立绘下面。
- [x] 前端用 `next build` + `next start` 起服务，竖屏手机视口（390×844、360×780）逐个组合逐位聚焦截图，确认立绘完整；电脑视口抽几位对比改前截图，摆位不变。
- [x] 静止版式（定格档）手机上也抽查一遍：它的立绘按 `data-side` 用 CSS 摆（`left/right: 60%`），按算的没出屏，截图确认。

## Comments

2026-10-10 实现：

- 模型的 `standX(vp, 她在光谱里的位置, 立绘宽)`（`model/scene.ts`），`LightStage.tsx` 的立绘和字幕都用它。和上面写的区间有一处不同：浏览器实测发现组合停留时轨道会从组合起点往左漂 0.08 屏（`trackTarget`，390 宽约 31px），立绘在轨道里跟着走，漂到头时贴左放的立绘会压进幕名轨。所以左边界是「这一屏左边 + 幕名轨宽 + 0.08 屏」，漂移量和 `trackTarget` 共用常量 `TRACK_DRIFT`。最后一个组合只漂 0.04，也按 0.08 让，多让一点无妨。
- 模型测试 3 条：电脑 1440×900 摆位和改前一致（期望值按旧算法手算）；竖屏 390 宽每个组合的每一位、漂到头时都不出屏、不压幕名轨；立绘比可用宽度还宽时居中。前端 vitest 46 个文件 531 条全过，typecheck、纪律检查通过。
- 浏览器实测（构建版，探测脚本逐个组合逐位聚焦，量立绘框）：竖屏 390×844、360×780 全部 28 位在停留开头和漂到头时都在屏内、不压幕名轨（修复前 390 宽灯织的立绘框在 199–487，现在 101–390）；电脑 1440×900 全部 28 位在屏内，位置和改前一致；定格档手机 390、360 逐位抽查，立绘框都在屏内（这一档的 CSS 没改）。
- 已知边界，没改：立绘在轨道离停稳位置 0.15 屏以内就可以出现（`standOk`），刚推入、弹簧还没走到位的那一下，立绘可能短暂露出边，正好是它淡入的时候；不常见的电脑比例（1280×1024、1024×768）有几位的立绘位置会变，那几位原来就出屏或漂到头时压幕名轨，算一起修好。

2026-10-10 用户看过后改了层级：竖屏上她的名字有时直接盖在立绘的脸上，不好看，改成立绘压在她的名牌上面（`landing.css` 竖屏那段 `max-aspect-ratio: 10/11` 里把聚焦名牌的 z-index 降回 1）。只改竖屏：电脑上立绘站在名牌旁边、不盖脸，05 号票原型里定的「她的名牌在立绘之上」照旧；定格档的立绘只盖到她名牌的边，也没改。构建版截图确认：手机上灯织的脸不再被名字盖住，电脑上结华的摆位和层级不变。
