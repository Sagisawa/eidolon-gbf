# 08: 点击听招呼：点一位偶像，听她说一句话，看到字幕

**What to build:** 访客在第 2 幕点一位偶像（或者用键盘聚焦后按 Enter），就能听到她的招呼，同时看到日语原文和中文字幕。第一次点击就直接出声，不需要先找开关；之后角落出现常驻的声音开关，关掉以后点偶像只显示字幕。同一时间只播一句，页面从不自动出声。背景见 `../spec.md` 的「交互状态」和「招呼」。

**Blocked by:** 05, 06

**Status:** done

- [x] 落地页模型的交互 reducer：聚焦和点击偶像；招呼要不要出声（第一次点击就出声并出现开关；开关关掉后只显示字幕；同时只播一句，点另一位时上一句停下）。都有 reducer 测试。
- [x] 音频在点击时才加载；加载失败或存储桶已下线时只显示字幕，不报错。
- [x] 没有招呼的角色点了也有反应，只是没有字幕和声音（不出现空的字幕框）。
- [x] 字幕显示的是去掉语气提示的日语原文和中文字幕，都是真文本，读屏器能读到。
- [x] 不放背景音乐，不做悬停音效；滚动和聚焦都不会发声。
