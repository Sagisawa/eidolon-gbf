# 02: 光谱名单：28 位偶像按官方顺序和组合出现在落地页上

**What to build:** 访客在落地页上看到全部偶像的竖排日文名，按官方偶像编号排列，按组合分段，每段开头有组合名。这一张先用纯 DOM 排出来，不带光效，但名单的数据、排序和颜色已经是最终版。背景见 `../spec.md` 的「后端：角色列表」和「前端：落地页模型」的「名单准备」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `GET /api/characters` 按偶像编号升序返回；没有编号的角色排在后面，保持配置里的顺序。
- [ ] 每个角色带 `idol_id` 和 `unit`（组合名，取自世界设定，查不到为空），并给出组合的官方顺序，形式由实现决定。
- [ ] 后端测试覆盖：排序、没有编号的情况、`unit` 和组合顺序。
- [ ] 前端新建落地页模型模块，不依赖 DOM。先实现「名单准备」：输入角色列表，输出排好序、按组合分段的光谱。新增一位填了编号的角色时，它自动排进正确位置。
- [ ] 每位偶像有一组颜色：官方色本身（不改）、极深的同色相底色、按感知亮度反向补偿的光晕色和光晕宽度、能在官方色上读清的文字色。插值在 OKLab 里做。光晕补偿照搬原型拍板过的算法（原型分支的颜色模块）。
- [ ] 颜色契约测试比照现有印象色的对比度测试：官方色不变；光晕在黑底上的可见度有下限，灯织的 `#144384` 也达标；文字色在官方色上的对比度达标。
- [ ] 落地页上用 DOM 排出 28 个竖排名字和组合名，都是真文本。
