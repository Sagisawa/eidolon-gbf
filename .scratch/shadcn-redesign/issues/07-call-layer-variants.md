# 07: 通话层的其他状态与立绘衔接

Type: prototype
Blocked by: 03
Status: resolved

## Question

「LINE 风格视觉原型」定下的通话层是：放大并模糊的头像做底，台词放在毛玻璃卡片里，控制键收进一条毛玻璃底栏。现行 `DESIGN.md` 里通话层还有几种情况，要在新风格下重新定样子：(1) 角色有背景图时，用背景图还是模糊头像做底；(2) 有 Spine 立绘时，手机上的「大立绘」和电脑上的「半身 ADV 对话框」怎么和毛玻璃台词卡、底栏放在一起；(3) 正在呼叫、拨打中按钮置灰、通话结束页、「只看文字」开启后的样子；(4) 通话层收起后，页首的「通话便利贴」在没有手帐隐喻后变成什么；(5) 展开和收起的动效。用丢弃式原型做，至少用一位有立绘的角色，手机和电脑两种宽度都要做。

收尾时补上 `DESIGN.md` 的 Call layer 一节里标着「待定稿后补」的各项，并决定原来的 Line-State Rule 和 `imageColor.ts` 里 `note`/`noteRule` 两对颜色的去留。如果便利贴有了新名字、而且会出现在界面文案里，就看看 `GLOSSARY.md` 要不要收这个词。

## Answer

原型在丢弃式分支 `prototype/call-layer`（提交 67b5ef7）的 `frontend/src/app/prototype/call/`。立绘用生产代码的 `Stand` 加线上 CDN 素材。构建时加 `NEXT_PUBLIC_PROTOTYPE=1`，打开 `/prototype/call?variant=A` 就是定稿方案；B「ADV 对话框 · 小窗」和 C「上下分区 · 改页首」是供比较的方案。用户 2026-10-09 拍板：**全部取 A**。细节已写进 `DESIGN.md` 的 Call layer 一节，这里只记要点：

1. **背景图**：保留这个功能，图片清晰铺满（不模糊），压上和模糊头像同一层渐变。目前 `characters/backgrounds/` 是空的，没有角色配背景图。
2. **立绘（A「立绘做底」）**：立绘铺在底图上，不再显示大头像；名字和状态行缩进头部中间；毛玻璃台词卡和底栏的位置和没有立绘时一样，压在衣服上，底部 50% 压暗。手机上立绘占下方 80%、取景到膝、从下方升起；电脑上铺满头部以下、取景到腰、原地淡入。上一版的「半身 ADV 对话框」不再使用。
3. **各状态**：呼叫中是「正在呼叫」加三个闪烁的点，静音和切换麦克风置灰，没有立绘时头像外有波纹。结束页的结束卡放在台词卡的位置，同样是毛玻璃；底栏消失，立绘变淡。「只看文字」开启后胶囊变成白底，上一句台词淡淡地留在当前这句上面。原型里呼叫中「只看文字」被置灰、台词卡写着「接通后她会先开口」，这两处都是原型的随手处理，不进规格：这次只换视觉，「只看文字」照常可切换，台词卡接通前不出现。
4. **收起后**：通话便利贴换成**通话条**，在对话页首下面，40px 高，底色是她的 `call.deep`，白字写「通话中 mm:ss」或「正在呼叫…」，右端是「回到通话 ›」。「通话条」只是设计用语，不出现在界面文案里，所以 `GLOSSARY.md` 不收。
5. **动效**：通话层从对话栏底部整张滑上来，收起时滑下去。时长和曲线沿用 410ms 和 `cubic-bezier(0.24, 1, 0.4, 1)`。

收尾决定：

- **Line-State Rule 删掉**：状态只用文字加图标表达，原型里切换条上的「线形（旧）」方案没有被选中。
- **`imageColor.ts` 删掉 `note`/`noteRule`**，连同对比度契约里的这两对。另外 `paper`、`paperMuted`、`call.top`、`call.glow`、`call.rule` 在定稿的新界面里也都用不上，一起删掉；她的通话颜色只留 `call.deep`。白字 ≥ 7 的契约继续管着它，通话条也在这条契约里。
