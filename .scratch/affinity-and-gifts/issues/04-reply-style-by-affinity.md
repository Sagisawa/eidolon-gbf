# 04: 拍板：不同好感度下她怎么说话

Type: grilling
Status: resolved
Blocked by: 01

## Question

- 提示词怎么写：每一档写一段通用的态度描述，所有角色共用？还是每位角色在人设里各写一段（人工校对，工作量是角色数 × 档数）？或者通用描述加上「按你自己的性格表现」？
- 她知不知道「好感度」这个数：提示词里只描述关系状态（「你现在有点生制作人的气」），不出现数值和档名。她会不会自己提起「我现在不想理你」这类话，跌破冷却线那一回合她说什么。
- 和原作关系的边界：好感度低时的冷淡不能变成否认一起走过的正式经历，也不能违背人设的硬性规则。高好感度时最亲近能到什么程度（比如不越过原作中偶像和制作人的界限）。
- 好感度怎么影响通话：语气提示和情绪会不会跟着变（低好感时更容易是「生气」「难过」）？
- 好感度变化以后，这一段对话里之前的回复和现在的态度不一致，要不要处理。

「好感度的数值模型」已定：五档从低到高是冷淡、疏远、信任、亲近、亲密，正常值在信任；冷却解除时仍是冷淡。每一档的态度按这五档来写。

「好感度变化由谁判断」已定：这回合的回复按变化之前的档位说话；判出加分或减分时，提示词里附一句她对这句话的感受（如「他这句话让你有点不舒服」）。这句话怎么措辞、和档位描述怎么配合，在这里定。没配判断模型时没有好感度，提示词也不带档位。

## Answer

2026-10-12 的 grilling 定下：

- **写在哪**：五档里除「信任」外，每档写一段通用的态度描述，所有角色共用，末尾跟一句「按你自己的性格和口吻表现出来」。不在人设里逐个角色写，也暂不设覆盖机制，等哪位角色真表现不对时再加。档位描述和感受句都放在「# 制作人」一节。
- **信任不写**：人设本来就是按信任写的（「很信赖制作人」），正常值下提示词和现在一字不差，档位描述只在偏离正常时出现。
- **四档的态度大意**（措辞实现时细磨）：
  - 冷淡：对制作人明显冷淡。话很少，客气而疏远；不主动找话题，不开玩笑也不撒娇；对方关心她也只淡淡回应。仍然礼貌，不说伤人的话。
  - 疏远：有点生气或失望，比平时冷一些。回应偏短，不太主动关心对方，但对方好好说话时会接。
  - 亲近：比平时更放松，更愿意说心里话，更主动关心对方，玩笑多一些。
  - 亲密：非常信赖，会说平时不轻易说的心事和依赖，对制作人的事格外上心。
  - 冷淡和疏远都不写成「讨厌你」：冷淡是关上门，疏远是闹别扭，这样回暖才说得通。
- **边界**：档位描述后统一跟一句：「无论现在关系怎样，人设里的硬性规则照旧；一起经历过的事和你们偶像与制作人的关系都不会改变。」低档时不否认过去、不说伤人的话，对方仍是她的制作人；亲密指的是信赖和心事，不是恋爱，也不越过人设里偶像与制作人的那条线。档位描述不得写成违背硬性规则。
- **她知不知道好感度**：提示词里没有数值、档名，也没有「好感度」这个词，只用自然语言描述关系状态。她可以用自己的方式说出情绪（「ちょっと怒ってるんだからね」）；被问到「你对我好感多少」时按心情回答，不报数。她不提礼物能让她消气这类机制。
- **感受句**：判出加分或减分时附一句，主语一律写「制作人刚才说的话」，不用「他」（制作人可以是女性）。

  | 判断结果 | 感受句 |
  |---|---|
  | 级 0（−5） | 制作人刚才说的话伤到了你。 |
  | 级 1（−2） | 制作人刚才说的话让你有点不舒服。 |
  | 级 3（+1） | 制作人刚才说的话让你有点开心。 |
  | 级 4（+2） | 制作人刚才说的话让你很开心，觉得被在意。 |
  | 不该说的话（−10） | 制作人刚才说的话让你很受伤、很生气；你可以明确表示不能接受。 |

  「操纵」命中时，加分的感受句不加（减分的照常加）。每日上限已到时照常加：她确实开心，上限只是防刷分的机制。判为不变或判断失败时什么都不加。感受句只写这一句，不说「好感度下降了」。
- **跌进冷却的那一回合**：判断在回复前出结果，已经知道这回合会让好感度跌到 0，提示词就再加一句收尾指示：「这句话之后你暂时不想再和制作人说话了。先回应，再用你自己的方式表明你现在不想聊下去。」回合失败、没记入对话时，冷却不会发生，这句话也不会留下，两边一致。通话里要挂断时（因为冷却，或者说了太多不该说的话），挂断前那一回合也带收尾指示，改成「说完这句你就挂断电话」；**什么时候**挂断由「冷却和她自己挂断电话」定。
- **前后不一致**：不回头改任何东西，历史照旧。档位描述写的是「现在」。描述里加一句「如果想不起具体是因为什么，就不要编造原因」，因为不存原因；记忆里有的照记忆说。跨对话被问「你怎么了」，可以按性格含糊带过，但不能编出一件没发生过的事。
- **通话**：情绪判断和语气提示不跟档位挂钩，都依据台词本身；台词已经按档位说了，表情和声音自然跟着变。给情绪判断加档位偏置，反而可能出现台词平静、立绘却在生气的错位。通话里她先开口的回合同样按当前档位说。招呼和开场白只在落地页播，不受影响。
- 没记 ADR：措辞以后改起来不难。术语表「好感度」补了一句：档位影响她对制作人的态度，但不改变人设和一起经历过的事，她不知道也不说出数值和档位。
