# 16: 拍板：应用导航规格里剩下的细节

Type: grilling
Status: resolved
Blocked by: 12, 13

## Question

「原型：应用导航外壳」和「原型：像手机设置那样的一级、二级设置页面」都定了，写 `.scratch/app-navigation/spec.md` 之前还要拍板这几件留下来的事：

- **通话条**：通话提到外壳以后，在礼物页、设置页上收起成的通话条放在哪里（电脑上右栏顶上、第二栏顶上，还是整条横在导航栏右边；手机上 dock 上面还是页首下面）。「原型：礼物页」里暂时把它放在礼物页最上面、整条横在导航栏右边（页首之上），可以拿来比较。
- **没配判断模型时的「礼物」**：好感度和礼物整块关闭时，导航栏和 dock 里还留不留「礼物」这一项（「原型：礼物页」里留着，点进去是「礼物暂时没有开放」）。
- **换一位角色的对话**：通话中打开另一位角色的对话，现在是先问再挂断；通话属于外壳以后还要不要问、要不要挂。
- **离开外壳**：还有哪些地方在外壳外面（后台、隐私政策、使用条款、`/about`），去那里时「挂断并离开」的确认框怎么说。
- **设置的草稿**：现在切标签时面板保持挂载、没保存的档案草稿留着；按路径分页以后换类别就卸载了，要不要留住草稿或离开前提示。
- **分支怎么切**：「把通话从对话页搬进外壳」要不要单独一个分支先做，导航栏和 dock、设置改版各自一个还是合成一个 `feat/` 分支；`DESIGN.md`（Layout、设置页、Conversation list 页首）和一条「通话属于外壳、不属于对话页」的 ADR 放在哪一步。

## Answer

2026-10-12 grilling 定下，六项都按推荐。

- **通话条**：只在不是她对话页的外壳页面上出现（礼物、设置，手机上还有对话列表；电脑上没选中对话的 `/conversations` 也算）。两种屏宽都放在最顶上，横跨导航栏右边整块，在第二栏和页首之上，同「原型：礼物页」的放法：40px，她的 `call.deep` 底，写名字和通话状态，点了回到通话层。手机上在页首之上，不贴 dock。她自己的对话页不加通话条，页首电话键照旧是「回到通话」。
- **没配判断模型时的「礼物」**：导航栏和 dock 里一直留着，点进去是「礼物暂时没有开放」。这样首屏不用等配置，也不会闪；dock 始终是三项。这一条推翻了「拍板：好感度变化由谁判断，哪些话加分、哪些话减分」里「导航里的「礼物」入口一起隐藏」那半句，礼物页里的送礼、抽奖仍然整块关闭。
- **换一位角色的对话**：同一时间只和一位角色说话。在外壳里换页不挂断，包括回列表、去礼物、去设置；打开另一位角色的对话时先问，确认后挂断再打开。从礼物页送完礼点「去对话」去的是另一位角色时也这样。
- **离开外壳**：外壳外面是后台、`/about`、隐私政策、使用条款（登录、同意条款通话中到不了）。设置里「后台」和「关于」那三行，通话中都走同一个确认框：标题照旧「会挂断和{name}的通话」，说明改成「离开这里，正在进行的通话就会挂断。」，按钮照旧「留在这里」「挂断并离开」（挂断红）。换角色也用这个框。`/about`、隐私政策、使用条款照常在本页打开，不改新标签页。「退出登录」「删除我的全部数据」有各自的确认，不再叠挂断确认，确认了就挂断。GitHub 本来就在新标签页打开，不受影响。
- **设置的草稿**：档案草稿提到设置的 layout，在设置各类别之间切换时留着，离开设置就丢（和现在一样，不弹框）。有改动没保存时，一级列表「档案」那行的摘要换成「有修改未保存」。
- **分支**：一个 `feat/app-navigation` 分支，分三张票按顺序做：
  1. 通话和 `DirectoryProvider` 提到外壳，加路由组和通话条，导航还是老样子。这张票附带写 ADR「通话属于外壳、不属于对话页」，并改写 `GLOSSARY.md` 的「通话」和「通话层」：
     - 「通话」：「离开对话页就挂断通话」改成「在对话、礼物、设置之间换页不挂断；打开另一位角色的对话、离开这些页面或关掉页面才挂断，都算用户自己挂断」。
     - 「通话层」：「收起不算离开对话页」改成「收起后在别的页面上显示成通话条」。
  2. 导航栏和 dock，拿掉「…」菜单，免责声明移到「关于」。同时改 `DESIGN.md` 的 Layout 和 Conversation list 页首。
  3. 设置改成一级、二级，记忆搬进来，旧网址跳转。同时整节重写 `DESIGN.md` 的「设置页」。

  三块之间的先后留给「拍板：三份规格的实现顺序和分支衔接」。
