# 14: 原型：礼物页

Type: prototype
Status: resolved
Blocked by: 10, 11, 12

## Question

- 礼物页里有什么：持有的礼物（背包）、抽奖、送礼。电脑上第二栏放什么，右边放什么；手机上怎么分页。
- 抽奖的过程：有没有动画、抽到后怎么展示、次数不够时怎么说明下次什么时候发。
- 送礼：选好礼物再选角色，还是先选角色？选角色时显示她的好感度吗（定图时只说对话列表不显示）？冷却中的角色怎么标出来。
- 送出后怎么反馈，要不要跳到她的对话页看送礼记录。
- 重置卡放在哪里、怎么用：持有几张，用之前确认会把哪几位角色拉回信任，没有角色低于信任时按钮不可用并说明原因；抽到重置卡时怎么展示，和抽到礼物有没有区别。
- 空状态：一件礼物都没有、今天的次数已用完。

原型遵守 `frontend/AGENTS.md` 的 shadcn 纪律和 `DESIGN.md`。

「拍板：送礼的流程和对话里的送礼记录」已定：送礼只在礼物页做，先选礼物、再选角色、确认送出，一次一件、不设每日上限。对话页的入口（冷却时输入栏旁、冷却版结束卡、页首好感度说明末尾）跳到礼物页并预先选好她，原型要做出这种「已选好角色」的进入方式。好感度到顶后照常能送，不提示「已满」。送出那一刻的反馈留给这张原型；送礼记录会写进她最新的那段对话，所以送完跳去她的对话页一定看得到。

「拍板：礼物目录」已定：礼物分吃的、饮品、花草、小物件四类，礼物页按类别筛选；每件礼物一张生成的插画，没有 Lucide 后备。这张原型要先用生图做三四件样图放进页面，定下插画的画风（要在 `DESIGN.md` 加「礼物插画不算界面图标」的例外）。

「拍板：抽奖规则」已定：每天 1 次、最多攒 7 次，制作人当地 0 点到账；每次必出，重置卡 1%，不设保底。留给这张原型的：一次抽一个还是能把攒下的连抽，怎么显示「还有几次、下次什么时候到账」（攒满 7 次时说明不会再多），抽到稀有和重置卡时的样子。

「原型：应用导航外壳」已定（取 B）：礼物是导航栏和 dock 的第二项，网址 `/gifts`；电脑上导航栏右边整块归礼物页，要不要第二栏由这张票定。通话中切到礼物页不挂断，通话收起成通话条，所以要考虑边打电话边送礼时页面上通话条放在哪里。原型 `prototype/app-navigation` 的 `/gifts?variant=D` 是空的占位页，可以在它上面做。

## Answer

2026-10-12 看原型后定下。原型在 `prototype/gifts-page` 分支（接在 `prototype/settings-hierarchy` 上，导航外壳固定用 D），提交 `7473ee6` 是三个变体，`f86d394` 按结论改了重置卡的范围。`/gifts?gv=A|B|C` 切换，右下角原型面板驱动假数据；构建时带 `NEXT_PUBLIC_PROTOTYPE=1` 才显示面板和切换条。截图在 `.scratch/_proto/gifts-*.png`（不提交）。比较过的三个变体：A 背包两栏（第二栏背包列表，右边详情和「送给谁」列表），B 一页网格，C 三栏流程（① 礼物 ② 送给谁 ③ 确认一屏摆开，抽奖收在页首按钮里翻卡）。

- **取 B「一页网格」**：礼物页没有第二栏，导航栏右边整块是一栏（内容最宽 `max-w-3xl`，居中），手机和电脑同一个版式。从上到下：
  - **抽奖台**（`bg-muted` 圆角块）：「抽奖 还有 n 次」，下面 7 个小点（攒了几次亮几个），再下面一句什么时候发：平时「明天 0:00 再发 1 次，最多攒 7 次」，攒满「已攒满 7 次，抽掉之前不会再发」，用完「今天的已经抽了，明天 0:00 再发 1 次」。右边「抽一次」（default，带闪光图标），攒了 2 次以上时旁边多一个「全部抽完」（outline）。次数为 0 时「抽一次」不可用。
  - **重置卡条**（有重置卡时才出现，描边圆角块）：「重置卡 ×n」，下面一句「现在用会把 n 位拉回信任」或「现在没有低于信任的角色，留着以后用。」，右边「使用」（outline，没有可拉回的角色时不可用）。点了弹 `AlertDialog`：标题「使用一张重置卡？」，说明「下面几位会回到信任，冷却中的马上可以说话。她们不会知道发生过什么。」，列出每位的头像、名字、现在的档位 → 信任，按钮「取消」「使用」。
  - **我的礼物**：标题右边是类别筛选（全部、吃的、饮品、花草、小物件，`ToggleGroup`），下面是插画网格（手机 3 列，更宽 4、5 列）：每格是插画方块（`bg-muted` 圆角，持有多于 1 件时右下角「×n」）、礼物名、稀有度。一件都没有时是 `Empty`「还没有礼物」，说明按有没有次数写「抽一次，抽到的礼物会放在这里。」或「明天 0:00 会发一次抽奖……」。
- **抽奖要能连抽，也要有动画**：「抽一次」和「全部抽完」都弹一个居中的 `Dialog`：先是礼物盒图标跳一会儿（约 0.9 秒，`prefers-reduced-motion` 时不跳），再放大淡入抽到的东西。
  - 单抽：大插画、名字、稀有度；稀有的写成 Badge「稀有」，插画角上一个闪光图标。下面「送给谁…」（default，直接打开送礼面板）、「再抽一次（还有 n 次）」（outline，没次数时不出）、「收下」。
  - 抽到重置卡：用 Lucide 的票券图标（重置卡不是礼物，没有插画），名字「重置卡」，Badge「很少见」，下面一句它是什么：「不是礼物，自己用：把所有低于信任的角色拉回信任，冷却中的马上可以说话。能攒，不过期。」没有「送给谁…」。
  - 全部抽完：结果排成 3 列小网格，一件件依次淡入。
- **送礼**：点网格里一件，电脑从右边拉出 `Sheet`，手机从底部拉出 `Drawer`：上面是这件的插画、名字、稀有度和「还有 n 件」，中间「送给谁」是所有角色的头像网格（4 列，头像、名字、档位心形加档名），冷却中的头像淡一些、写「冷却中」，照常能选；选中铺 `bg-muted`。底部按钮「送给{角色名}」，没选人时是不可用的「选一位」。
  - **从对话页跳来**（`/gifts?to=<角色 ID>`）：页首下面一条「给{角色名}挑一件礼物」带 ✕，点哪件礼物，面板里都已选好她、排在第一个。
  - **送出后**：面板收起，页面底部（手机在 dock 上面）出一条深色胶囊提示，8 秒后消失：她的小头像、一句话、「去对话」。这句话就是对话里那个变化胶囊的话（「{角色名}有点开心」「和{角色名}更近了一步：{档名}」「{角色名}愿意和你说话了」）；冷却中送了还没解除时写「{角色名}还没消气，{解除时刻}就会愿意说话了」；没有变化（到顶了）只写「已经送给{角色名}」，不提示已满。不自动跳到她的对话页。
- **礼物页不透露她喜欢什么**：网格、送礼面板、结果提示都不标，和送礼记录一样，让她自己在回复里表现出来。
- **选人时显示每位的档位**（定图时只说对话列表不显示），冷却中的显示沙漏和「冷却中」，Popover 之类的详情不加。
- **重置卡的范围改了**（修订「拍板：好感度对用户有多透明，能不能重置，删除时怎么处理」）：只算低于信任这一档的角色（低于 40：疏远、冷淡、冷却中），仍然拉回 50。40–49 的已经显示信任，用了界面上看不出变化，所以不算；没有低于信任的角色时不能用。词汇表「重置卡」词条已改。
- **插画画风取「柔和平涂」**：柔和的粉彩、轻微的柔和阴影、没有硬描边、圆润的形状，像现代手游的道具图标；透明底、物件居中占画面约 75%、不带文字。样图用的提示词骨架（换主体即可）：「A single <物件和细节>, centered, three-quarter view. Style: soft flat vector illustration, gentle pastel colours, subtle soft shading with no harsh outlines, simple rounded shapes, like a modern mobile game item icon. Transparent background, no text, object fills about 75% of the frame.」样图（布丁、热可可、花束、毛绒玩偶）在原型分支的 `frontend/public/gifts/proto/flat/`，512px webp，每张 20–60 KB。实现时其余 15 件照这个骨架生成，四件样图可以直接用；插画方块的底是 `bg-muted`。
- **没配判断模型时**礼物页是 `Empty`「礼物暂时没有开放」：「这里还没有开放好感度和礼物。已经有的礼物会留着，开放后照常能送。」导航栏和 dock 里要不要藏起「礼物」，留给写规格时定。
- **通话中**：原型把通话条放在礼物页最上面，铺满导航栏右边整块（40px，她的 `call.deep` 底），在页首之上。这只是原型的放法，「原型：应用导航外壳」把通话条在礼物页、设置页上放哪留给了写规格时定。
- **没记 ADR**：都是界面上的决定，写规格时进 `DESIGN.md`（礼物页版式、礼物插画不算界面图标的例外）。
