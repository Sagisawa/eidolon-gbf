# 12: 原型：应用导航外壳（电脑左侧导航栏、手机底部 dock）

Type: prototype
Status: resolved
Blocked by: none

## Question

- 电脑：最左边一条窄导航栏（对话、礼物、设置），第二栏随之切换成对话列表、礼物页的什么内容、设置一级页面，右边是内容区。窄导航栏要不要文字标签、能不能收起，和现在可以拖宽的对话列表怎么共处。
- 手机：底部 dock 放这三项。打开某位角色的对话页时 dock 还在不在（大多数聊天应用会隐藏），通话层肯定盖住它；输入框和键盘弹起时怎么办；首屏不能闪成电脑布局（沿用现在的 `max-md:` 做法）。
- 现在对话列表页首的 GitHub、公告、「…」菜单（记忆、设置），以及后台入口，搬到哪里：dock、设置一级页面，还是留在原处？
- 路由怎么组织（现在对话在 `(app)/(conversations)`，设置在 `(app)/settings`）。
- 用不用已经装好但还没用的 `components/ui/sidebar.tsx`。

原型遵守 `frontend/AGENTS.md` 的 shadcn 纪律和 `DESIGN.md`，可以调用 impeccable 和 shadcn 两个 skill。

## Answer

2026-10-12 看原型后定下。原型在 `prototype/app-navigation` 分支（提交 `0f6eb6d`），`?variant=D` 是定稿的组合，A、B、C 是比较过的三个方案：A 只有图标的 64px 窄栏，B 图标下带字的 72px 窄栏、手机 dock 常在，C 可收起的 shadcn Sidebar。构建时带 `NEXT_PUBLIC_PROTOTYPE=1` 才显示切换条，截图在 `.scratch/_proto/nav-*.png`（不提交）。

- **电脑（取 B）**：最左一条 72px 的导航栏，右边一条 `border-r` 细线。从上到下依次是对话、礼物、设置，每项图标在上、字在下。当前项的图标外面铺一层中性的 `bg-muted` 圆角底，字用 foreground 加 medium；其余是 muted。GitHub 是最底下的 ghost 图标键（新标签页打开）。导航栏不能收起，不用 `components/ui/sidebar.tsx`：那是后台的页框，带字的窄栏用不上它的展开、收起。
  - 第二栏跟着切换：对话是现在的对话列表，仍然可以拖宽（240–480px），夹在导航栏和内容之间；设置是一级列表，右边是二级内容（细节留给「原型：像手机设置那样的一级、二级设置页面」）；礼物页放什么留给「原型：礼物页」。
- **手机（取 B）**：底部 dock 三项：对话、礼物、设置。图标在上、字在下，实底，上沿一条 `border-t`，留出 safe-area。
  - **进了她的对话页 dock 也在**，在输入栏下面；只有输入框拿到焦点（键盘弹起）时藏起来，收起键盘后回来。
  - 通话层盖住 dock。
  - 首屏不闪：导航栏和 dock 都靠 CSS 断点（`max-md:hidden`、`md:hidden`）分宽窄，原型核对过，手机首屏（不跑脚本）直接是单栏加 dock。
- **页首的东西搬到哪里（公告照 A）**：
  - 公告铃铛留在对话列表页首，两种屏宽一样；不进导航栏，也不进 dock。
  - GitHub：电脑在导航栏底部，手机进设置的「关于」。
  - 「…」菜单拿掉：设置进了导航栏，记忆在设置里。后台入口照旧在「登录与数据」里。
  - 列表底部那行免责声明拿掉，搬进设置的「关于」。PRODUCT.md 要求明确声明「非官方粉丝作品、角色由 AI 扮演」，落地页首屏和页脚、登录页页脚都还有，应用里留在「关于」这一处。
- **通话中换页不挂断**：通话从对话页提到导航外壳里，切到礼物、设置时通话照常进行，在别的页面上收起成通话条，点了回到通话层。这样「通话中从别处送礼，下一个通话回合回应」（「拍板：送礼的流程和对话里的送礼记录」）在同一个标签页里也成立。现在离开对话这一块前先问「挂断并离开」的确认框，只在真的离开导航外壳时还需要（比如去记忆页、后台）。通话条在礼物页、设置页上放在哪里，换一位角色的对话时通话断不断（现在是先问再挂断），记忆页要不要搬进外壳，留给写规格时定；写规格时把「通话属于外壳、不属于对话页」记一条 ADR。
- **路由**：对话、礼物、设置放进同一个路由组（原型里叫 `(nav)`），共用一个带导航栏和 dock 的 layout，网址不变（`/conversations`、`/conversation/[id]`、`/gifts`、`/settings`）。角色和摘要（`DirectoryProvider`）跟通话一起提到这一层，礼物页、设置页也拿得到。记忆、后台、隐私政策、使用条款不在外壳里。
- **术语**：电脑上叫「导航栏」，手机上叫「dock」，都是同一组去处；写进 `DESIGN.md` 的 Layout，不进 `GLOSSARY.md`（界面布局，不是领域概念）。
