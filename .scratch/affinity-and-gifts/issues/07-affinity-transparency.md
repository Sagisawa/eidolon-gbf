# 07: 拍板：好感度对用户有多透明，能不能重置，删除时怎么处理

Type: grilling
Status: resolved
Blocked by: none

## Question

词汇表写着「角色知道的关于用户的一切，都来自用户能看到并删除的记忆和制作人档案」。好感度是第三种会影响她怎么对待用户的东西，要决定：

- 这条原则怎么改：好感度算不算「她知道的关于用户的事」？用户能看到它（页首标识），那能不能清掉或重置？重置后回到正常值，还是不允许重置（否则冷却可以一键解除）？
- 用户能不能看到每次变化的原因（「因为你说了……」），还是只看到升降？
- 删除用户时好感度、礼物、抽奖次数随之删除（属于用户数据）。删除某段对话、删除记忆，会不会影响好感度？
- 管理者在后台能不能看、能不能改某位用户的好感度（词汇表规定后台看不到对话、记忆和制作人档案的内容）。
- 这项决定如果改写了词汇表的那条原则，要不要记一条 ADR。

「页首的好感度标识和变化提示」已定：用户在页首看到档位，点开有说明（说明里讲了低于信任时会慢慢恢复）。每个回合的升降以胶囊的形式记在她那条回复后面，翻历史可见。不存原因，也不显示原因。删除对话时，这些标记随消息一起没了，但好感度本身怎么处理在这里定。

## Answer

2026-10-12 的 grilling 定下：

- **原则不改**：「角色知道的关于用户的一切，都来自用户能看到并删除的记忆和制作人档案」这句不动。好感度是她的感受，不是她知道的关于用户的事：她不知道数值、档位和原因（原因不存，见「页首的好感度标识和变化提示」）。这条边界写进了词汇表的「好感度」词条。
- **用户自己不能重置**，也不能删除。正常的途径只有删除用户（和其他用户数据一起删）。
- **重置卡**（借用 Codex 的 banked reset，即「重置卡」）是唯一的重置办法：
  - 一张卡把所有低于正常值的角色一次拉回 50，冷却中的随之解除；高于 50 的不变。只有至少一位角色低于 50 时才能用、才会扣掉，否则按钮不可用。
    - 2026-10-12 被「原型：礼物页」修订：只算低于信任这一档的角色（低于 40，疏远、冷淡、冷却中），仍拉回 50；40–49 的已经显示信任，用了界面上看不出变化，所以不算。只有至少一位低于信任时才能用。
  - 它不是礼物：用户自己用，不送给角色，不生成送礼记录，也不留任何对话事件。她回到信任档，提示词和现在一样，不会知道发生过什么；以前「她挂断了电话」这类对话事件仍然留在记录里。
  - 来源：抽奖时极低概率抽到（概率交给「拍板：抽奖规则」定）；管理者在后台一键发给所有现有用户，每人一张，之后注册的用户拿不到。管理者不能单独发给某一位用户。
  - 能攒，不过期（Codex 设过期是为了控成本，这里用不用都不花部署者的钱）。
- **删除记忆**（一条或清空全部）不影响好感度：她可能想不起为什么，但态度还在。对话事件不受影响。现在没有删除对话的功能；以后要是加了，同样不改变好感度，只是那些胶囊随消息一起消失。
- **后台**：管理者看不到、也改不了某位用户的好感度和冷却，用户详情页里不出现这些。冷却最长 24 小时，页面上写着解除时刻，会自己恢复；判断模型误判要靠调整题目解决，不靠人工改。整体统计（冷却次数、误判多不多）留在地图「后台可调」那块迷雾里。
- **变化原因**：已经在「页首的好感度标识和变化提示」里定了，不存，也不显示。
- **没记 ADR**：原则没改，重置卡以后调整也不难。词汇表更新了「好感度」「冷却」「抽奖」「后台」四个词条，新加了「重置卡」。
