# 07: 她在通话里挂断

**What to build:** 通话里有一个回合让她跌进冷却，或者这一通里第 2 次说了不该说的话，她说完这一句就挂断：挂断音照常，结束卡写「{角色名}挂断了电话。」，对话里留下一条「挂断了电话」的对话事件，她之后也知道自己挂过电话。因为冷却挂断的结束卡多一行解除时刻、只有「回到对话」；因为不该说的话挂断的结束卡主按钮仍是「重拨」。见规格「她挂断电话」。

**Blocked by:** 05（冷却）、06（对话事件）

**Status:** ready-for-agent

- [ ] 两种条件都在回合开始、判断出结果时定下：这一回合会跌到 0；这一通里第 2 次命中不该说的话（计数只在这一通里）
- [ ] 定下要挂断的回合带通话版收尾指示（「说完这句你就挂断电话」的说法）
- [ ] 回合记下后沿用通话结果模块「说完当前回复再挂」的机制：已经送去合成的话说完，再发 `ended`；最后一句被打断也照样挂断
- [ ] 用户补充了话时按合并后重新判断的结果来，重新判断后不再命中就不挂断
- [ ] 同一回合撞上时长或回合数上限时以她挂断为准（回合之间先问是否挂断，再问是否到了上限）
- [ ] 定下要挂断的回合失败、没记入对话时不挂断，这一回合命中的不该说的话也不计数
- [ ] 不加别的挂断条件；挂断本身不额外扣好感度；好感度不可用时不会因此挂断
- [ ] `ended.reason` 新增 `out_of_line` 和 `cooldown`，后者带 `cooldown_until`
- [ ] 挂断时立刻把「挂断了电话」写进这通电话所在的对话，不等结束卡关掉
- [ ] 这通电话照常计入限额、结果记为成功；运行记录的通话结束原因新增「角色挂断」，两种挂断不区分
- [ ] 结束卡标题「{角色名}挂断了电话。」；`out_of_line` 没有说明，主按钮「重拨」、副按钮「回到对话」；`cooldown` 多一行「她现在不想说话，{时刻} 以后可以再找她。」，只有「回到对话」；两版都照常显示「计入每小时的限额」
- [ ] 通话测试（浏览器测试替身）：这一通里跌进冷却，那一回合带通话版收尾指示，说完后收到 `ended`（`cooldown`，带解除时刻），对话记录里有「挂断了电话」，运行记录的结束原因是「角色挂断」、结果成功；第一次不该说的话不挂断、第 2 次挂断（`out_of_line`），下一通从零开始；撞上回合上限的同一回合以她挂断为准；回合失败时不挂断、那句不计数；补充后重新判断、最后一句被打断如果这个接缝驱动不了，退到通话回合那一层
- [ ] 前端纯模块的 vitest：`out_of_line`、`cooldown` 两种结束卡的内容
- [ ] 本地构建版上用 Playwright 验收：按 `docs/agents/local-acceptance.md` 拦下 `/api/offer` 造出两种结束卡，核对标题、说明和按钮；回到对话后记录里有分隔线
- [ ] 人工验收留给用户：挂断前那一句她怎么说，要真打一通电话看
