# 08: 在别处进了冷却，挂断这边的通话

**What to build:** 用户在另一段对话或另一台设备上让她进了冷却时，这边正在进行的通话立刻被她挂断，不等用户开口：她正在说的那句说完就挂，不再生成告别；空闲着就直接挂；挂断前用户说的话不再被回答。结束原因和因冷却挂断的一样，这边的对话里同样留一条「挂断了电话」。见规格「她挂断电话」里「冷却从通话外开始」。

**Blocked by:** 07（她在通话里挂断）

**Status:** ready-for-agent

- [ ] 回合记下时发现这回合让她进了冷却，就通知这位用户和这位角色之间其他进行中的通话
- [ ] 收到通知的通话：已经送去合成的话播完就挂，空闲就直接挂；不再生成告别，挂断前用户说的话不再回答
- [ ] `ended.reason` 是 `cooldown`、带 `cooldown_until`；这边的对话里写入「挂断了电话」；运行记录的结束原因是「角色挂断」；照常计入限额
- [ ] 只通知同一位用户和同一位角色的通话，别的角色、别的用户的通话不受影响
- [ ] 通话测试（浏览器测试替身）：在另一段对话里让她进了冷却，这边空闲着的通话不等用户开口就被挂断，结束原因同冷却，这边的对话里有「挂断了电话」；和另一位角色的通话不受影响
