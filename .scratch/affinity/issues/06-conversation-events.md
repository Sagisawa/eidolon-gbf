# 06: 对话事件

**What to build:** 对话记录里除了制作人和她说的话，还能有「对话事件」：整行一条细分隔线，中间是图标、一句话和时间，把前后的消息分成两组，参加跨天的日期条判断；对话列表里她的「最后一句」可以是一条对话事件。她下一回合从一行旁白知道发生过这件事；记忆和判断模型都看不到它。这个分支只有一种「{角色名}挂断了电话」，由 07 写入，这张票用测试直接放一条进库来验。见规格「对话事件」。

**Blocked by:** None (can start immediately)；按顺序放在 05 之后做，避免和 02、05 同时改对话页

**Status:** ready-for-agent

- [ ] 扩展存储（给消息加一种「事件」或另建按对话存的事件表，选哪种由实现定，理由写进 `## Answer`）：属于某段对话、带时间、和回合按时间排在一起；有类型和旁白所需的内容；能挂一份好感度变化、记下她有没有回应过（礼物分支用）
- [ ] 存法照顾礼物分支：她的回复正在生成时写入的事件排在这个回合（制作人的话和她的回复）后面，不插在中间、不排到前面；写一条测试钉住这个顺序
- [ ] 登记为用户数据，删除用户时随对话一起删；删除记忆不碰它
- [ ] 它不是回合：不判断、不计入限额、不写运行记录、不触发记忆提炼
- [ ] 拼提示词时写成一行旁白，接在它后面那条用户消息的开头，后面还没有用户消息时接在这一回合用户说的话前面；挂断事件的旁白是「（你挂断了制作人的电话。）」，不带「回应一次」的指示；跟着那条用户消息一起滑出最近 N 个回合；存下的用户原话不变
- [ ] 记忆提炼、找记忆、判断模型的输入里都没有对话事件和旁白
- [ ] 读对话记录的接口里对话事件和消息按时间混在一起返回，带类型、给用户看的文字所需的字段和时间；对话列表的「最近一条」可能是对话事件（类型、原文、时间），这一行的时间就是排序用的「最近往来」
- [ ] 分隔线：两边 `h-px bg-foreground/15`，中间 `PhoneOff` 图标、「{角色名}挂断了电话」、时间（Meta 字号、等宽数字），正文 0.875rem、muted、`my-3`，不用她的颜色；前后消息不算一组，各自重新出头像、名字和时间；按它的时间参加跨天判断
- [ ] 对话列表「最后一句」是对话事件时：14px muted 图标加原文，不加「你：」，时间写事件的时间；通话中仍显示「通话中 mm:ss」
- [ ] 好感度关着时挂断事件照常显示、照常进提示词历史
- [ ] 改 `DESIGN.md`：Layout 的「消息区」加对话事件的分隔线；Conversation list 的「最后一句」加图标加原文的写法
- [ ] 走接口的测试：在记录里和消息按时间排在一起；下一回合的提示词里旁白接在用户消息开头；记忆提炼和判断模型收到的输入里没有旁白；对话列表的「最近一条」是它、时间是它的、排序跟着它；删除用户后没了
- [ ] 前端纯模块的 vitest：对话事件打断气泡分组、参加日期条；列表「最后一句」遇到对话事件时的描述、时间和排序
- [ ] 本地构建版上用 Playwright 验收：库里放一条挂断事件后，记录里的分隔线、前后分组、日期条，对话列表那一行
