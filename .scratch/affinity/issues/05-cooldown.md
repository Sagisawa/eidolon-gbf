# 05: 冷却

**What to build:** 好感度跌到 0 时她暂时不想说话：跌进冷却的那一回合她先回应、再用自己的方式表明不想聊下去；之后对话页的输入栏换成一行说明，写出精确的解除时刻，电话键禁用，页首换成沙漏加时刻，到点页面自己恢复。从别的标签页、别的设备发出的回合和新通话被 409 挡下，不计入限额、不写运行记录，页面收到 409 就切成冷却状态，拨号被挡下也不出结束卡。这个分支里不放任何送礼入口。见规格「冷却拦截与 409」「冷却中的对话页」，以及「提示词」里的收尾指示。

**Blocked by:** 02（说的话改变好感度，她的回复后面出现胶囊）

**Status:** resolved

- [x] 冷却中拒绝发起回合（包括重试失败的回合）和新通话的 offer（通话里的重新协商不拦），返回 409，带 `detail` 和 `cooldown_until`（ISO 时间）
- [x] 判断冷却放在取用限额、检查「必须自带 LLM」和打开运行记录之前；冷却和缺自带 LLM 同时成立时是 409
- [x] 好感度不可用时不拦，哪怕存着的状态还在冷却中；关着期间到期的冷却再打开时已解除
- [x] 冷却只针对这一位角色
- [x] 文字回合里按判断结果这回合会跌到 0 时，提示词加收尾指示（「这句话之后你暂时不想再和制作人说话了。先回应，再用你自己的方式表明你现在不想聊下去。」）；预测和实际对不上的竞态接受
- [x] 前端接口错误类型认出 409 冷却，和 429 超限、403 必须自带 LLM 分开
- [x] 冷却中的对话页：输入栏换成「{角色名}现在不想说话。{时刻} 以后可以再找她」，时刻按制作人的时区写成「今天 HH:MM」或「明天 HH:MM」；电话键禁用；页首标识换成 `Hourglass` 加时刻（muted）；到了解除时刻页面自己恢复成可以输入；新开的对话同样显示冷却状态，选角色的地方不加标记
- [x] 收到 409（回合或拨号）时页面切成冷却状态；拨号被 409 时不出结束卡
- [x] 不放「送她一件礼物」按钮，Popover 里送礼那半句和链接都不出现
- [x] 走接口的测试：跌到 0 的那一回合带收尾指示、变化标为进入冷却；之后回合和新通话得到 409 带 `cooldown_until`；不计入限额（限额只剩一次的用户解除后仍能用那一次）、不写运行记录；同时缺自带 LLM 时是 409；拨到解除时刻后可以照常发起、解除后是冷淡；解除后再扣到 0 又进冷却；开关关着时不拦
- [x] 前端纯模块的 vitest：解除时刻的写法（今天 / 明天，按给定时区）；offer 得到 409 时进入冷却状态、不出结束卡
- [x] 本地构建版上用 Playwright 验收：390px 宽的屏上冷却状态页首不重叠；输入栏说明、电话键禁用、沙漏；拦下回合请求回 409 时页面切成冷却；拦下 `/api/offer` 回 409 时切成冷却、不出结束卡；把解除时刻放到一分钟后，到点恢复成可以输入
