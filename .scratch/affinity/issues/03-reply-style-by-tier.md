# 03: 她按档位说话，知道这句话让她开心还是不舒服

**What to build:** 低于信任时她冷淡或闹别扭，高于信任时更放松、更愿意说心事，按她自己的性格表现；判出加分或减分时，她这一回合的回复就知道制作人这句话让她开心或不舒服；说了不该说的话时她可以明确表示不能接受。信任档、好感度不可用时，提示词和现在一字不差。见规格「提示词」。

**Blocked by:** 02（说的话改变好感度，她的回复后面出现胶囊）

**Status:** ready-for-agent

- [ ] 只改提示词的「# 制作人」一节，文字回合和通话里的回合走同一条路径；每回合开始时读一次补算后的好感度，回复按变化**之前**的档位说话
- [ ] 冷淡、疏远、亲近、亲密各一段通用描述，所有角色共用，末尾跟「按你自己的性格和口吻表现出来」；不出现数值、档名和「好感度」这个词；冷淡和疏远都不写成「讨厌你」；亲密是信赖和心事，不是恋爱
- [ ] 有档位描述时后面跟两句：人设硬性规则、一起经历过的事和偶像与制作人的关系都不变；想不起原因就不要编造
- [ ] 信任档、没配判断模型、开关关着时什么都不加
- [ ] 感受句按规格的表；命中不该说的话用「很受伤、很生气；你可以明确表示不能接受」那句；命中操纵时加分的感受句不加、减分的照常；每日上限已到照常加；判为不变或判断失败时不加；感受句里不出现「他」
- [ ] 情绪判断和语气提示不跟档位挂钩
- [ ] 走接口的测试（假的扮演角色模型记下收到的提示词，只断言关键句在不在）：信任档没有档位描述；各档描述的标志语；各级的感受句；不该说的话的感受句；操纵时没有开心的感受句；判断失败没有感受句；开关关着时没有
- [ ] 人工验收留给用户：各档她说话的样子、感受句的效果，要在文字对话和通话里实际看一遍
