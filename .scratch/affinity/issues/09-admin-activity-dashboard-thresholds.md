# 09: 后台：运行记录、看板的「好感度」和判断阈值卡

**What to build:** 管理者在看板上看到「好感度」一节：进入冷却的次数和人数、「不该说的话」和「操纵」的命中次数、5 级打分的分布、一张按角色的表；通话的「结束原因」里多出「角色挂断」。统计都不落到任何一位用户。管理者还能在「判断模型的阈值」卡里调两道是非题的阈值。见规格「运行记录与看板」，以及「判断题」里的阈值。

**Blocked by:** 02（说的话改变好感度，她的回复后面出现胶囊）、07（她在通话里挂断）

**Status:** ready-for-agent

- [ ] 每个回合的运行记录多记判断结果：打分的级（0–4，没判断或失败为空）、「不该说的话」有没有命中、「操纵」有没有命中、有没有因此进入冷却；不含任何对话内容
- [ ] 看板「好感度」一节跟着看板的时间范围；好感度不生效时后端返回空、前端不画
- [ ] 整体合计：进入冷却的次数和人数、「不该说的话」命中次数、「操纵」命中次数、5 级打分的分布（样子同「回合结果」那张分布卡）
- [ ] 按角色的表：判断过的回合数（只算判断成功、记入了对话的回合，也是减分占比的分母）、减分占比（级 0、级 1 占多少）、进入冷却、不该说的话、操纵、角色挂断次数；按减分占比从高到低，判断过的回合不到 20 的排最后、占比「—」；手机上变成列表，每行末尾「减分 {x}% · 冷却 {n}」；不并进现有的「按角色」表；不按天画趋势
- [ ] 「结束原因」里多出「角色挂断」，不另加卡
- [ ] 用户详情页不出现好感度和冷却，看板不出现任何用户的标识
- [ ] 「判断模型的阈值」卡加「不该说的话」「操纵」两项，和检索、情绪的阈值一样跟判断模型绑定（换了别家的模型就清掉）、能恢复默认
- [ ] 走接口的测试：看板好感度一节的合计、5 级分布、按角色的表（排序、不到 20 的排最后）；好感度关着时这一节为空；不出现用户标识；阈值能改、能恢复默认、换了别家的模型就清掉
- [ ] 前端纯模块的 vitest：好感度一节的数据整理（排序、「—」、手机上的那一行）
- [ ] 本地构建版上用 Playwright 验收：两种屏宽上的看板一节，阈值卡的两项
