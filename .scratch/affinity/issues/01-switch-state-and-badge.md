# 01: 开关、读当前状态和页首标识

**What to build:** 部署者配了判断模型时，管理者能在后台配置页的「好感度和礼物」卡里打开好感度；打开后，用户在对话页页首「…」左边看到一个心形键，写着现在的档名（没有任何回合时是「信任」），点开有说明。关掉或没配判断模型时，心形不出现。这张票还不判断、不改变好感度，只把「按用户 × 角色存的好感度」、读取时补算的自然恢复、读状态接口和页首标识打通。见规格「数值」「数据模型」「读当前状态」「页首标识」「开关」「词汇表」。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 好感度模块：五档（冷淡 0–19、疏远 20–39、信任 40–64、亲近 65–84、亲密 85–100）、正常值 50、解冻线 10、低于 50 时每天 +10 按时间均匀恢复到 50、高于 50 不回落；档位和冷却都按小数判断，不取整；数值只在代码里
- [x] 新表每位用户对每位角色一行（值、更新时间、是否在冷却、当日累计和它属于哪一天），没有行当作 50、不在冷却；读取时按经过的时间补算，冷却中补算到 10 就当作已解除，解除时刻算得出来；登记进数据库模块的用户数据清单，删除用户时一起删，删除记忆不碰它
- [x] 开关照「必须自带 LLM」的做法：`.env` 新布尔变量设默认（这个分支默认关），实时配置里单独一项，后台优先、能恢复成 `.env` 的设置；没配判断模型时这一项不可用，后台写明原因；好感度生效 = 判断模型在且开关开着
- [x] 后台配置页新卡「好感度和礼物」，这个分支里只放开关，写法跟着配置页现有的卡

## Comments

- 环境变量叫 `EIDOLON_AFFINITY_AND_GIFTS`（`1` 打开，不填或 `0` 关闭）；实时配置里的一项叫 `affinity`，字段 `enabled`。写进配置文档和环境变量示例归票 10。
- 读状态接口是 `GET /api/characters/{character_id}/affinity`，返回 `{"tier": "cold|distant|trust|close|intimate", "cooldown_until": ISO 或 null}`，好感度不可用时是 `null`。
- 页首冷却状态的解除时刻暂时按浏览器报的时区写；按档案时区（`effective_timezone` 的规则）写归票 05，它接冷却中的输入栏时一起换。
