# 02: 说的话改变好感度，她的回复后面出现胶囊

**What to build:** 好感度开着时，每个记入对话的回合（打字或通话里的），部署者的判断模型在回复之前判断制作人这句话对她的影响，回合记下的那一刻好感度按映射升降。有实际变化时，她那条回复后面插一行居中的小胶囊（「凛世有点开心」「和凛世更近了一步：亲近」），翻历史还在；页首心形跳一下、带升降小箭头；通话层名字下面的状态行暂时换成同一句话。这张票不改提示词（03），也不拦冷却（05）：跌到 0 时只把状态标为冷却、变化标为进入冷却。见规格「判断题」「生效时机」「变化提示要跟回复一起存」「变化胶囊和通话里的提示」。

**Blocked by:** 01（开关、读当前状态和页首标识）

**Status:** ready-for-agent

- [ ] 三道题：5 级打分题（`score`，每级写成情境、从低到高排，取概率最高的一级，两级并列判 2）、「不该说的话」是非题、「操纵」是非题；情境描述按规格的边界写
- [ ] 检索开着时三道题并进检索判断那一次请求，用量照旧记在那一次服务调用上；检索关着而判断模型在时单独发一次请求、和这回合别的请求并发，用量单独记一次服务调用；两种情况都在回复之前出结果
- [ ] 判断输入：角色名、上文（只作参考）、制作人这一回合说的话，用户的话明确标成「要评判的内容」；不看她的回复、不看当前档位
- [ ] 两道是非题的阈值按 Jev、Clef、Clef-flash 各一套，进判断模型模块的阈值表，先放占位值（04 回填）
- [ ] 映射：级 0–4 对应 −5、−2、0、+1、+2；命中不该说的话按 −10、盖过打分；命中操纵加分变 0、减分照常；加分受当日剩余额度（+6，按制作人的「今天」，`effective_timezone` 同一规则）限制、不够时加到上限为止，减分不受；结果卡在 0..100，到 0 进入冷却
- [ ] 什么时候判断：好感度生效、这一回合有制作人说的话；冷却中不判断；每日上限到了照常判断；每个回合开始时读一次开关，改了从下一个回合起生效（包括进行中的通话）
- [ ] 判断失败时这回合好感度不变、回合照常；检索题一起失败时检索照旧按「失败时照常检索」处理
- [ ] 回合记下时生效：读出补算后的值，算出新值，和回复一起写入；失败、被拒绝、用户在她说完前离开的回合不改变好感度（通话里同样）；通话里被打断的回合照常算，有补充时按合并后的整段话重新判断、原来那次作废
- [ ] 每个改变了好感度的回合在她那条回复上存一份变化：方向、有没有跨档、变化后的档位、是否因此进入冷却；不存原因和变化量；没有实际变化时不存；变化的形状不绑死在回复上（礼物分支的送礼记录要挂同样的）
- [ ] 文字回合流的 `done` 事件、通话服务器消息的 `done` 都带上这份变化和变化后的状态（档位、冷却中的解除时刻）；读对话记录的接口里她的每条回复带上存下的变化
- [ ] 前端：胶囊文字按规格里原型的 `cueText`（冷却优先，其次跨档）；样子和日期条一样（`bg-foreground/10`、Meta 字号、muted）、带升降小箭头、不用她的颜色；心形跳一下带箭头约 2.6 秒（「升」用 `--her-button` 底配 `--her-button-fg`，「降」用中性前景色）；通话层状态行约 2.6 秒后换回计时，有没有立绘、开没开「只看文字」都在同一位置；通话层收起时对话页上同样出胶囊和跳动
- [ ] 好感度不可用时，记录里存下的变化不生成胶囊
- [ ] 走接口的测试（扩展假判断模型，能为每回合指定打分概率、两道是非题的答案、模拟失败）：各级对应的变化；并列判不变；判断失败不变、回合完成；不该说的话 −10；操纵吃掉加分、减分照算；一天加到 +6 后不再加、剩余不够时加到上限、减分照算、按档案时区过当地 0 点重新累计（服务器 UTC 还是前一天的那一刻）；失败、被拒绝的回合不变；跨档、同档变化和回复一起存下、读记录时还在，没有实际变化时没有；检索关着时单独请求照样生效；开关关着时假判断模型没被问好感度的题
- [ ] 前端纯模块的 vitest：胶囊文字；对话记录里变化挂在对应的回复后面；好感度不可用时不出胶囊
- [ ] 本地构建版上用 Playwright 验收：拦下回合的流、`done` 带变化时胶囊出现在回复后面、心形跳动；刷新后胶囊仍在；关掉开关后历史里的胶囊不显示
