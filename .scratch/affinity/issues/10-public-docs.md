# 10: 对外文档

**What to build:** 隐私政策、使用条款、落地页、README 和配置文档跟着好感度改：用户和访客知道自己的话会影响她们的态度、保存了什么、判断模型看到什么；部署者知道怎么打开开关、它需要判断模型。这个分支只写好感度和冷却，礼物的部分归礼物分支。见规格「对外文档（归这个分支的部分）」。

**Blocked by:** 05（冷却）、07（她在通话里挂断）

**Status:** ready-for-agent

- [ ] 隐私政策：「我们保存哪些数据」加「好感度」；「对话」补上「她挂断了电话」这样的记录、不进记忆；「运行记录」补上判断结果、不含对话内容；「交给哪些第三方」把判断那一句改成单独一条「判断模型」（点名 Jev 或 Cloudflare，说的话用来判断检索和好感度，通话中她的回复也会发过去判断情绪，始终由部署者提供）；「管理者能看到什么」补上看不到好感度和冷却、只看合起来的统计
- [ ] 使用条款：「玩法」里好感度、冷却、角色挂断电话的部分（AI 判断、可能误判、冷却自动解除、不是封禁或限额、管理者不人工调整）
- [ ] 两份文件末尾加「最后更新：{日期}」，不加同意版本号
- [ ] 落地页第 6 幕「使用须知」加一行，文案照抄：「你的话语会影响她们对你的态度，切勿过于冒犯……」；改完重新生成落地页的字体子集
- [ ] README 中、英、日三份：功能列表「和她说话」那组加好感度的半句；「部署和运营」的后台那条补上「好感度可以单独关掉」、需要判断模型；截图不重拍
- [ ] 开关的环境变量写进三种语言的配置文档和环境变量示例文件；部署文档里引用隐私政策的地方跟着核对
- [ ] 本地构建版上看一遍落地页那一行的字形没有缺字
