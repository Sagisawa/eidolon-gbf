# 23: 判断那道题的评测和阈值

**What to build:** 「是不是在要照片」这道题有评测集，阈值按 Jev、Clef、Clef-flash 三个模型族各校一个，宁可漏判、不要误判。以后换判断模型时也能重跑。规格见 `../spec.md`「判断模型」一节，依据是 `04-trigger-and-prompt.md` 的 Answer。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] **评测集**：加一类照片用例，要照片的和不算要照片的都有，带几句历史。
  - 算的：「发张照片」「自拍一张」「让我看看你今天的衣服」「拍给我看看」「拍一下你的便当」。
  - 不算的：「你在干嘛」「你今天穿什么」「好想见你」，以及聊到照片、却不是在要照片的话（「上次那张照片好可爱」）。
  - 每条都标注预期，并说明为什么这样标。
- [ ] 评测命令能跑这一类，报告里有漏判和误判。
- [ ] **阈值**：用评测结果给三个模型族各定一个 `photo` 阈值，误判优先压到最低，结果和取舍写进本票 `## Comments`。
  - 跑评测要调用真的判断模型。哪个模型这台机器上调不了，就列进人工验证清单交给用户。
- [ ] 加载评测集的测试照旧通过（先例是 `test_judge_eval.py`、`test_judge_thresholds.py`）。
- [ ] `uv run pytest`、`uv run pyright` 全部通过。
