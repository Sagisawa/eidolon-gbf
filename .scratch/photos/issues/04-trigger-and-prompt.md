# 04: 拍板：怎么触发、谁来写提示词

Type: grilling
Status: open
Blocked by: 01

## Question

- 谁认出「制作人明确要她发照片」：判断模型每个回合多答一道是非题，还是给扮演角色的 LLM 一个发照片的工具，由它决定调不调？两者在误触发、她能不能拒绝、自带 LLM 的兼容性、通话里的延迟上各有什么代价。
- 她能不能拒绝：好感度低的时候、要求越界的时候、刚发过一张的时候。拒绝是她嘴上说的话，不生成。
- 提示词谁来写：扮演角色的 LLM 写情境（自然语言还是直接写 tag），再和这位角色固定的外貌描述拼起来？还是另外调后台模型把情境翻成 NovelAI 的 tag？情境里能有什么（场景、服装、动作、表情、镜头），不能有什么。
- 照片和这个回合的关系：一个回合最多一张？她的话和照片谁先谁后？她之后的回复怎么知道自己发过什么（记录里留一段照片的描述？）。
- 用户说的是「发张照片」还是「你现在在干嘛」这种模糊的话，边界划在哪。
