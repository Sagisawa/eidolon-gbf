# 04: 限额、单次通话上限、历史轮数

**What to build:** 管理者在后台的「配置」页修改全站的限额（每小时回合数、每小时通话次数）、单次通话的时长和回合上限、带上的历史轮数。保存后下一个回合或下一次通话就按新数字执行，进行中的通话仍用接通时的上限。见 `../spec.md` 的「配置覆盖」一节。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 这五项接入生效配置：可覆盖、可恢复成 `.env` 的值，界面显示 `.env` 的值和当前生效的值。
- [ ] 取值规则和 `.env` 相同（限额 0 表示不限；不接受负数和非整数），不合法时说明原因、不保存。这几项不需要「保存前先试」。
- [ ] 限额按每次 `take` 时的生效值判断；429 的文案和 `retry_at` 用当时的数字。
- [ ] 单次通话上限在接通时取快照；历史轮数在回合开始时取快照。
- [ ] 测试（HTTP API + `FakeClock`）：把每小时回合数从 60 改成 2 后，第 3 个回合被拒绝且文案是「每小时 2 次」；改回不限后不再拒绝；通话中改了时长上限，这通电话仍按旧上限结束，下一通按新上限；历史轮数改了以后下一个回合带上的轮数随之变化；不合法的值被拒绝。
