# 10: 花费：预设单价与估算

**What to build:** 看板显示所选时间段内部署者的 key 大约花了多少钱，按服务和币种分开，明确标注「按单价估算、不扣免费额度」。目前支持的模型都预设好单价并注明整理日期；管理者可以在「配置」页修改或补充单价。自带密钥的用量只显示数量、不换算成钱。见 `../spec.md` 的「看板与单价」一节。

**Blocked by:** 02, 08

**Status:** ready-for-agent

- [x] 调研：查官方价格页，整理目前支持的每个模型的单价、计费单位和币种，至少覆盖：扮演角色和提炼记忆的 LLM（`.env.example` 和 README 里推荐的那些）、Fish Audio 各模型、Soniox、阿里云百炼的语音识别、Jev（经 OpenRouter）、Cloudflare Clef / Clef-flash、硅基流动和 Gemini 的向量化、硅基流动的重排。每一项记下出处链接和整理日期，写进 `../research.md`。
- [x] 预设单价以「提供方 + 模型 + 计费单位」为键写在代码里，每项有单价、币种和整理日期。
- [x] 单价覆盖存进数据库，优先于预设；可以修改、新增、恢复成预设。
- [x] 花费 = 部署者调用的计费用量 × 单价，按币种分开合计，不做汇率换算；计费用量未知的调用单独计数；没有单价的模型显示用量和「未设单价」。
- [x] 看板的花费一节：按服务、按币种的合计和趋势；标注「估算、不扣免费额度、价格整理于某日」。
- [x] 「配置」页的单价一节：列出所有预设和覆盖，可编辑。
- [x] 计算和格式化逻辑写在后端，前端的显示规则在 `lib/` 里有单元测试。
- [x] 测试（HTTP API）：给定一组运行记录，花费按单价和币种算对；自带密钥的用量不算钱；覆盖优先于预设；没有单价的模型显示「未设单价」；计费用量未知的调用不计入金额但被计数。
