## Comments

**第三波留给文档的事**（2026-10-07）：
- 06：封禁名单的哈希用 `EIDOLON_SECRET_KEY` 派生的密钥。部署者更换这个密钥（包括从没有到有）后，已写进名单的哈希对不上，被删除的封禁用户可以重新注册。`docs/deploy.md` 里写明。
- 设置页自删的提示（`zh.ts` 的 `hint`）和隐私政策里删除数据一段还写着「会话和用量记录」，GLOSSARY 要求避开「用量记录」（与「运行记录」相混），「会话」也在「对话」「通话」的避免列表里。后台删除用户的提示已改成「登录状态和限额的计数」，这两处随隐私政策一起改。
- 03：通话里每个回合的检索用的判断模型、重排阈值和历史回合数按回合取当时的生效值，不是接通时的快照（只有判断情绪、语音合成、语音识别和单次通话上限按通话固定）。spec「配置覆盖」一节说各种阈值都按接通时的快照，文档按实际行为写。
