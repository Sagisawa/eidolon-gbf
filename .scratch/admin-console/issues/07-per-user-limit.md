# 07: 单独限额

**What to build:** 管理者可以给某位用户单独设定每小时的回合数和通话次数（正整数、不限，或 0 即只能用自带密钥），附一句备注，也可以随时取消，回到全站默认。这位用户撞上限额时，提示里的数字是他实际适用的数字。见 `../spec.md` 的「用户管理」一节和 GLOSSARY「限额」。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 新增按用户的限额覆盖表（每小时回合数、每小时通话次数、备注、更新时间），登记为用户数据：删除用户时一并删除。两项可以只设其中一项，另一项跟随全站。
- [ ] `UsageLimiter.take` 先查这位用户的覆盖，再用全站值；429 文案和 `retry_at` 用实际适用的数字。0 时：用了自带密钥、免计入的回合和通话照常放行，其余全部拒绝，文案说明「只能用自带密钥」。
- [ ] 后台接口：设置、取消某位用户的单独限额。用户列表和详情显示是否有单独限额及数值。
- [ ] 前端：用户详情里的「单独限额」编辑（数字 / 不限 / 0、备注、取消）。
- [ ] 单次通话的上限不能单独设。
- [ ] 测试（HTTP API + `FakeClock`）：设为 1 后第 2 个回合被拒绝且文案是「每小时 1 次」；设为不限后超过全站值也不拒绝；设为 0 时用部署者 key 的回合被拒绝、自带 LLM 的回合照常；只设回合数时通话次数跟随全站；取消后回到全站值；删除用户时覆盖一并删除。
