# 11: 用户详情里的近期用量

**What to build:** 管理者打开某位用户的详情，能看到他最近 24 小时、7 天、30 天的回合数、通话数和撞上限额的次数（区分用部署者 key 和自带密钥的），用来判断他是不是在刷；用户列表里也显示最近 24 小时的回合数和通话数，并能按它排序。数据来自运行记录。见 `../spec.md` 的「用户管理」一节。

**Blocked by:** 05, 08

**Status:** resolved

- [x] 用户详情接口加上近期用量：24 小时、7 天、30 天的回合数、通话数、被拒绝的次数，按部署者 key / 自带密钥分开。
- [x] 用户列表接口加上最近 24 小时的回合数和通话数，支持按它排序。
- [x] 前端：详情里的用量一节；列表里的用量列和排序。
- [x] `eidolon user usage` 继续可用（仍读 `usage` 表），说明里注明更长的历史在后台看。
- [x] 测试（HTTP API + `FakeClock`）：驱动若干回合、通话和撞限额后，三个时间段的数字正确；自带密钥分开计；按用量排序；不含任何内容数据。
