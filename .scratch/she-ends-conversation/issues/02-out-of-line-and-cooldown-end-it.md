# 02: 不该说的话和跌进冷却也会结束对话

**What to build:** 最近 8 个文字回合里不该说的话说到第 2 次，或者这一轮把她扣进冷却，这个对话也结束；因冷却结束的（或结束后处在冷却中的），结束卡上再写冷却到什么时候，加「送她一件礼物」。对话结束后才记下的回合、对话里还开着的通话，都按「已结束的对话不再添任何记录」处理。见 `../spec.md`「规则」「已结束的对话」和 Implementation Decisions。

**Blocked by:** 01

**Status:** done

### 后端

- [x] 文字回合接上另外两种原因：不该说的话按最近 8 个文字回合（含这一轮）计，第 2 次结束；这一轮跌进冷却结束。三种原因的告别都是「不想聊下去」那句
- [x] 跌进冷却而结束时 `done` 照旧带冷却到什么时候，同时带「对话已结束」
- [x] 在通话里或别的对话里跌进冷却，不结束任何对话；冷却结束后没被结束的对话照常能聊
- [x] 回合进行到一半，对话被别处结束了：记下时不记入，按被拒绝处理，告诉用户「她已经结束了对话」
- [x] 对话结束时这个对话里还有通话：她挂断那通电话，原因按她挂断计
- [x] 运行记录记下原因是不该说的话还是冷却
- [x] 重置卡、冷却结束都不让已结束的对话重新开放
