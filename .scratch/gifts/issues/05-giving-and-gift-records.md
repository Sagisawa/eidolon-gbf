# 05: 在礼物页送礼和送礼记录

**What to build:** 在礼物页点一件礼物，拉出送礼面板（电脑从右边，手机从底部），从所有角色里选一位送出。她的好感度按礼物的稀有度和她喜不喜欢加分，冷却中每件最多 +3。面板收起后页面底部出一条提示，写着她的反应和「去对话」，礼物页不跳走。对话里留下一条「你送给{角色名}一份{礼物名}」的送礼记录，下面跟着变化胶囊；对话列表里她那一行的最后一句变成这条记录。抽奖结果上的「送给谁…」也接上。她下一回合怎么回应由 06 做，对话页上的入口和预选由 07 做。见规格「送礼」、「存储」的送礼记录、「接口约定」的送礼、「礼物页（前端）」的送礼面板和送出后，以及「打开好感度藏起的送礼入口」最后两条（分隔线、对话列表）。

**Blocked by:** 02、04

**Status:** resolved

- [x] 好感度模块加一个送礼加分的操作：先按经过的时间补算自然恢复，再加分，总值卡在 0..100，回到解冻线 10 时解除冷却；拿回加分前后的档位和冷却状态。和回合一样，靠「记下」的回调保证送礼记录写失败时什么都不变
- [x] 送礼接口：参数是礼物 `id`、角色 id，以及可选的「从哪段对话来」。前提是已经开放、这件礼物件数大于 0、角色存在，任何一条不满足就拒绝，件数和好感度都不变；没开放时返回带「没开放」原因的 409。冷却中照常能送：不受冷却的 409 拦，不计入限额，也不受「必须自带 LLM」影响。下架的礼物照常能送
- [x] 同一个事务里：件数减 1。加分是这一档的分，她喜欢的再加 3，冷却中每件最多 +3。变化的种类：冷却中、加完仍在冷却时没有胶囊，解除时刻按新值提前；冷却中、加完解除时是「愿意和你说话了」；不在冷却、值没变（已经到顶）时没有胶囊；跨档；同档开心。送礼是一次一件，不设每日上限
- [x] 选放进哪段对话：带了来源对话、而且那段是这位用户和这位角色的，就放那段；否则放她最新创建的那段；她一段对话都没有时新建一段，里面只有这条记录
- [x] 对话事件加一种「送礼」：带礼物 `id`、送出时刻、送出那一刻是不是她喜欢的（存下来，以后改了喜好也不变）、这次的变化（存法和回复后面的变化胶囊一样）。她的回复正在生成时送的礼，按对话事件现有的存法排在这一回合后面
- [x] 送礼不是回合：不调判断模型、不计入限额、不写运行记录、不生成回复、不触发记忆提炼
- [x] 接口返回：放进的是哪段对话、变化的种类和拼文字要用的档名、她现在的档位、是否冷却和解除时刻、这件还剩几件。两个标签页同时送同一件的最后一份时，只有一边送得出去，另一边被拒（「已经没有了」）
- [x] 送礼面板：电脑用从右边拉出的 `Sheet`，手机用从底部拉出的 `Drawer`。上面是这件的插画、名字、稀有度和「还有 n 件」。中间「送给谁」是所有角色的头像网格（4 列），顺序和对话列表一样：头像、名字、档位心形加档名（五档心形和页首标识同一套，中性色）。冷却中的头像淡一些，写沙漏和「冷却中」，照常能选；选中的铺 `bg-muted`。不标她喜欢什么，也不加 Popover。底部按钮选了人时是「送给{角色名}」，没选人时是不可用的「选一位」。重置卡从不出现在这里
- [x] 抽奖单抽结果里接上「送给谁…」（default），点了直接打开这件的送礼面板；抽到重置卡时没有这个按钮
- [x] 送出后面板收起，页面底部（手机在 dock 上面）出一条深色胶囊提示，8 秒后消失：她的小头像、一句话、「去对话」。这句话按变化的种类：「{角色名}有点开心」「和{角色名}更近了一步：{档名}」「{角色名}愿意和你说话了」；冷却中送了还没解除时写「{角色名}还没消气，{解除时刻}就会愿意说话了」，解除时刻的写法和对话页冷却说明一致；到顶了只写「已经送给{角色名}」。不自动跳转，可以接着送下一件
- [x] 「去对话」去接口返回的那段对话；通话中要去的是另一位角色时，走导航外壳已有的「会挂断和{name}的通话」确认框
- [x] 送礼记录的分隔线：对话事件分隔线加送礼这一种，图标是 Lucide `Gift`，文字「你送给{角色名}一份{礼物名}」加时间；变化胶囊居中放在线下面，样子沿用页首标识那张票；没有变化时只有分隔线。重新打开对话页就能看到新的送礼记录、变化胶囊和提前了的解除时刻；送礼后页首心形不跳，别的标签页也不实时刷新
- [x] 对话列表：最后一条是送礼记录时，显示 `Gift` 图标（14px，muted）加原文，不加「你：」，时间写事件的时间，也按这个时间排序；只有一条送礼记录的对话也这样显示，最上面同样有日期条
- [x] 提示那句话怎么拼放进礼物纯模块
- [x] `DESIGN.md`：「礼物页」一节补上送礼面板和底部提示；Layout 的「消息区」补上送礼分隔线和它下面的变化胶囊；Conversation list 的「最后一句」补上 `Gift` 加原文
- [x] 走接口的测试：件数减 1；普通、少见、稀有、她喜欢的各带来对的变化（跨档或同档，看档位和胶囊种类）；从 0 开始在冷却中连送 4 件普通礼物，前 3 件没有胶囊、解除时刻一件比一件早，第 4 件解除，胶囊是「愿意和你说话了」；到顶后照常能送、没有胶囊；件数为 0 时被拒；冷却中照常能送；不计入限额、不写运行记录；带了来源对话就放那段，带的是别人的或别的角色的对话时不放那段，没带时放她最新创建的那段，她没有对话时新建一段，对话列表的最后一句就是这条记录；回合进行中送的礼排在这一回合后面（用假模型把回复卡住）；没开放时被拒
