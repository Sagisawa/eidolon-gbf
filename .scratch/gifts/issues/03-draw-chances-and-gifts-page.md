# 03: 抽奖次数和礼物页骨架

**What to build:** 导航栏和 dock 的第二项是「礼物」。礼物页最上面是抽奖台，显示「抽奖 还有 n 次」、7 个小点和一句说明。次数按制作人当地 0 点每天发 1 次，最多攒 7 次，读取时补发，关着的日子不补。抽奖按钮在这张票里还不能用（04 才接上）。背包是空的，「我的礼物」显示「还没有礼物」。好感度和礼物没开放时，整页显示「礼物暂时没有开放」。见规格「礼物模块」「存储」「抽奖次数的发放」「接口约定」的读礼物状态，以及「礼物页（前端）」的位置、抽奖台、我的礼物空状态、没开放时、纯函数。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 新建礼物模块，作为抽奖次数、背包、抽奖、送礼和重置卡的唯一入口（这张票只做次数和读状态），依赖好感度模块、礼物目录和时钟；「开放」沿用好感度模块已有的判断：配了判断模型并且开关开着
- [ ] 加一张表存抽奖次数和重置卡，每位用户一行：现有次数、上次发放的当地日期、重置卡张数。登记进 `USER_DATA`，删除用户时一起删
- [ ] 「开放时刻」存成一行不属于任何用户的状态，登记进 `NOT_USER_DATA` 并改写那段文档字符串。两种情况写入当时的时刻：服务启动时发现从「没配判断模型」变成已配好；后台把开关从关改成开
- [ ] 读取时补发，不用定时任务：用 `producer.effective_timezone` 和 `producer.local_date` 算制作人当地的今天（设备时区从 `X-Timezone` 请求头来）。没有行时建一行，次数 1（注册当天就有 1 次，已有用户升级后同样处理）。今天晚于上次发放日期时，次数加上相隔天数，最多到 7。今天不晚于上次发放日期（时区往回改过）时什么都不变。开放时刻的当地日期晚于上次发放日期时，从开放那天的前一天开始算相隔天数。没开放时不补，上次发放日期也不动
- [ ] 读礼物状态接口（已登录、已同意条款，带 `X-Timezone`）返回：是否开放；次数和上限 7；背包（这张票里总是空的）；重置卡张数；所有角色现在的档位、是否冷却、解除时刻（送礼面板选人用）。没开放时照样返回已有的数据，外加「没开放」标记
- [ ] 导航栏和 dock 的第二项「礼物」（对话、礼物、设置），图标是 Lucide `Gift`，经 theme 图标出口的语义别名导出。没开放时也一直留在导航里
- [ ] `/gifts` 在导航外壳里，没有第二栏，导航栏右边整块是一栏，内容最宽 `max-w-3xl`、居中，手机和电脑是同一个版式；通话中照外壳的规矩，通话条出现在最顶上，切过来通话不断
- [ ] 抽奖台（`bg-muted` 圆角块）：「抽奖 还有 n 次」，下面 7 个小点（攒了几次亮几个），再下面一句说明：平时「明天 0:00 再发 1 次，最多攒 7 次」，攒满「已攒满 7 次，抽掉之前不会再发」，用完「今天的已经抽了，明天 0:00 再发 1 次」。右边「抽一次」（default，带闪光图标），攒了 2 次以上时旁边多一个「全部抽完」（outline）；次数为 0 时「抽一次」不可用。这张票里两个按钮先占位，04 再接上抽奖。读屏能读出次数
- [ ] 「我的礼物」标题，下面是 `Empty`「还没有礼物」，说明按有没有次数二选一：「抽一次，抽到的礼物会放在这里。」或「明天 0:00 会发一次抽奖……」
- [ ] 没开放时整页是 `Empty`「礼物暂时没有开放」，说明「这里还没有开放好感度和礼物。已经有的礼物会留着，开放后照常能送。」
- [ ] 文案全部放进前端文案表，新开「礼物」一节；抽奖台那句话怎么拼放进前端一个不依赖 React 的礼物纯模块
- [ ] `DESIGN.md`：Layout 里导航栏和 dock 加「礼物」；新加「礼物页」一节，先写版式、抽奖台、空状态和未开放（网格、抽奖弹窗、送礼面板、底部提示、重置卡条由后面的票补）；Icons 补上 `Gift` 和闪光图标的语义别名
- [ ] 走接口的测试：新用户当天 1 次；拨过 3 天补 3 次；拨过 10 天封顶 7；东京已过 0 点、服务器还在前一天时按东京算；档案时区优先于设备时区；把时区往回改不会多发；关掉的日子不补，重新开放那天发 1 次；没开放时返回「没开放」并保留已有次数；删除用户后这一行没了，开放时刻还在；现有的「每张表都登记过」检查对新表照样通过
- [ ] 礼物纯模块的 vitest：抽奖台那句话在平时、攒满、用完三种情况下各是什么
- [ ] 本地构建版上用 Playwright 验收（先读 `docs/agents/local-acceptance.md`）：390px 和电脑宽度下的导航「礼物」、抽奖台、空状态；关掉开关后的未开放页；通话中切到礼物页，通话条还在、通话不断
