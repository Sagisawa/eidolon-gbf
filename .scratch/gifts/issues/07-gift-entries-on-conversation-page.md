# 07: 对话页的送礼入口

**What to build:** 好感度分支藏起来的三处送礼入口在开放时出现：冷却时输入栏旁边的「送她一件礼物」、页首好感度标识说明末尾的送礼链接（冷却说明的后半句也一起出现）、冷却版结束卡的主按钮。点了跳到礼物页，页首下面写着「给{角色名}挑一件礼物」，点哪件礼物她都已经选好、排在第一个；送礼记录放回刚才那段对话。见规格「打开好感度藏起的送礼入口」前四条，以及「礼物页（前端）」的从对话页跳来。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 冷却时，输入栏右边有一个 outline 按钮「送她一件礼物」（Lucide `Gift`）
- [ ] 页首好感度标识的 Popover 末尾有「送她一件礼物」链接，不在冷却时也有；冷却中那句说明完整显示为「{时刻} 以后可以再找她。送她一件礼物，她会消气得快一些。」
- [ ] 冷却版结束卡的主按钮从普通的关闭换成白底的「送她一件礼物」
- [ ] 三处都跳到 `/gifts`，地址带上她的角色 id（`?to=<角色 ID>`）和这段对话的 id；没开放时三处都不显示，那半句说明也不显示
- [ ] 礼物页带着 `to` 打开时，页首下面一条「给{角色名}挑一件礼物」带 ✕；点哪件礼物，送礼面板里都已经选好她、排在第一个；点 ✕ 取消预选，面板恢复原来的顺序、不预选。`to` 指向不存在的角色时当作没有预选
- [ ] 送礼时把带来的对话 id 交给送礼接口，记录放回那段对话；「去对话」也去那段
- [ ] 结束卡在通话层里：点主按钮后通话层收起，再去礼物页，和关闭按钮的去向一致
- [ ] 本地构建版上用 Playwright 验收（结束卡照 `docs/agents/local-acceptance.md` 拦 `/api/offer` 造出冷却版）：三处入口都在、跳过去时她已预选、✕ 能取消、送完记录在原来那段对话里；关掉开关后三处都不见；390px 和电脑宽度
