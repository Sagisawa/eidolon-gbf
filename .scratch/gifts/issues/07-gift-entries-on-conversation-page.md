# 07: 对话页的送礼入口

**What to build:** 好感度分支藏起来的三处送礼入口在开放时出现：冷却时输入栏旁边的「送她一件礼物」、页首好感度标识说明末尾的送礼链接（冷却说明的后半句也一起出现）、冷却版结束卡的主按钮。点了跳到礼物页，页首下面写着「给{角色名}挑一件礼物」，点哪件礼物她都已经选好、排在第一个；送礼记录放回刚才那段对话。见规格「打开好感度藏起的送礼入口」前四条，以及「礼物页（前端）」的从对话页跳来。

**Blocked by:** 05

**Status:** resolved

- [x] 冷却时，输入栏右边有一个 outline 按钮「送她一件礼物」（Lucide `Gift`）
- [x] 页首好感度标识的 Popover 末尾有「送她一件礼物」链接，不在冷却时也有；冷却中那句说明完整显示为「{时刻} 以后可以再找她。送她一件礼物，她会消气得快一些。」
- [x] 冷却版结束卡的主按钮从普通的关闭换成白底的「送她一件礼物」
- [x] 三处都跳到 `/gifts`，地址带上她的角色 id（`?to=<角色 ID>`）和这段对话的 id；没开放时三处都不显示，那半句说明也不显示
- [x] 礼物页带着 `to` 打开时，页首下面一条「给{角色名}挑一件礼物」带 ✕；点哪件礼物，送礼面板里都已经选好她、排在第一个；点 ✕ 取消预选，面板恢复原来的顺序、不预选。`to` 指向不存在的角色时当作没有预选
- [x] 送礼时把带来的对话 id 交给送礼接口，记录放回那段对话；「去对话」也去那段
- [x] 结束卡在通话层里：点主按钮后通话层收起，再去礼物页，和关闭按钮的去向一致
- [x] 本地构建版上用 Playwright 验收（结束卡照 `docs/agents/local-acceptance.md` 拦 `/api/offer` 造出冷却版）：三处入口都在、跳过去时她已预选、✕ 能取消、送完记录在原来那段对话里；关掉开关后三处都不见；390px 和电脑宽度

## Comments

票 05 交接：
- 礼物页送礼时 `giveGift(to, giftId, null)`（`GiftsPage.send`）第三个参数就是来源对话 id，现在固定传 null；预选的她放进 `Giving.to`（`startGiving` 里现在是 null），排第一要改 `recipients` 的顺序。
- 后端已经按来源对话放记录（是这位用户和这位角色的才放），不用改。

**待决定（要用户定）**：「去对话」现在去 `/conversation/<角色 id>`，对话页只会打开她最新的那段（`LiveConversation` 取 `listConversations` 的第一段），没有办法打开指定的一段。票 05 里两者一定相同；这张票带来源对话以后，来源可能不是最新的那段（例如中途在别的标签页新开了一段）。二选一：对话页支持打开指定对话（地址带对话 id），或者规格接受「去她最新的那段」。动手前先问。

**已决定（用户，2026-10-13）**：接受「去她最新的那段」。「去对话」照旧去 `/conversation/<角色 id>`，对话页不加按对话 id 打开。来源对话不是最新那段时（中途在别的标签页开了新对话），记录留在来源对话里，「去对话」打开的是最新的那段，这种少见情况不另处理。
