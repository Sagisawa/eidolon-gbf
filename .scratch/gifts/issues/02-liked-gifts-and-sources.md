# 02: 角色喜欢的礼物和出处

**What to build:** 每位角色在自己的角色配置里有 1–3 件喜欢的礼物，至少一件是普通或少见；每一条在她的出处文件里都写明对应的资料和剧情位置，不收推断出来的条目。配错了应用起不来。这张票只把喜好写进配置并校验；送礼时多加的 +3 和她的反应由 05、06 用。见规格「礼物目录和喜好」的喜欢的礼物、出处的标准和那张配法表，以及 Further Notes 里对应得比较松的几条。

## Answer

28 位、65 条逐条回剧情库核对过，每一条都找到了原文，没有换替补，`liked_gifts` 和规格表一致。下面几条原文比规格表写得弱，按「出处的标准」暂时都收下，在出处文件里如实写了；要不要换，请用户定：

- 緋田美琴的音乐 CD：【ROUNDLY】/ display 里她一本本挑的是杂志，CD 只是说「まだCDのフロアも回ってないし……」，动机是看昔日同伴的作品。不收的话她只剩蜂蜜热饮；替补线索是偶像名鉴的兴趣「作詞作曲」（不是礼物）。
- 桑山千雪的糖果、和果子：糖果是小时候憧憬メープルキャンディ（「糖蜜キャンディ」是制作人说的，没写吃过）；和果子是她在一家老店「お菓子をいただいてると」，「昔ながらの和菓子屋さん」是制作人说的，没直接说喜欢和果子。这两条规格的 Further Notes 里没列。
- 斑鳩ルカ的冰淇淋（规格已列为松的）：原文是二选一时凭直觉选「マンゴーシャーベット」，没吃没点，还拒绝了同去。

规格表里引句的位置或说话人有出入、但礼物本身成立的，出处文件里已按原文改正：

- 白瀬咲耶的红茶：「平时是红茶派」不在 ファン感謝祭編 / ──うん、アンティーカ（那里只是她提议改泡红茶）；改引【記憶が降る街】200601702 她自己点的红茶，另附节日剧情 490110023 和【紺碧のボーダーライン】里制作人说的「紅茶派じゃなかったか？」。
- 幽谷霧子的肉包：「肉まん……熱いね……！」在 2.あちちがおー，不在 1.あついの（1 里是点单「わたしも……肉まん……」）。
- 市川雛菜的蛋糕：「やっぱりケーキとかのほうがいい！」在【S!GNATURE】/ PR♡DUCE，不在 take the cake!（那里是「いちごのケーキがいい」）。
- 有栖川夏葉的红茶：「私自身も紅茶が好きだから」在镜像 301301602，【’19Xmas】紅茶 里是收到礼物时的反应。
- 鈴木羽那的冰淇淋：「……食べちゃう？　ソフトクリーム」是はるき说的，改引她自己的「食べよう──！」和她点的单。
- 三峰結華的咖啡、風野灯織「平静的曲子」那句：只在选项分支里，已注明。
- 斑鳩ルカ资料里的「芒果冰沙」原文是シャーベット，facts 和出处都改成「芒果雪葩」。

## Comments

- 角色配置的字段叫 `liked_gifts`（`Character.liked_gifts`），对目录的校验在 `gift_catalog.check_liked_gifts`，后端启动时（`assembly`）跑：没配、不在目录里、超过 3 件、重复、全是稀有都起不来。CLI 只读角色配置的命令不跑这一步。
- 出处文件的小节标题是「## 喜欢的礼物」，每条写成「- 礼物名（id）：种类。位置（原文）。对应说明」；仓库检查测试按这个格式核对每位角色列的 id 和 `liked_gifts` 一致（顺序也一样）。
- 测试用的角色配置（`CharacterConfig.add`）默认 `liked_gifts = ["cake"]`。
- 配置文档三语在「角色」一节加了 `liked_gifts` 一条（新增角色时不配后端起不来）；礼物的其他对外文字留给票 10。
