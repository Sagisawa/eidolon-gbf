# 02: 角色喜欢的礼物和出处

**What to build:** 每位角色在自己的角色配置里有 1–3 件喜欢的礼物，至少一件是普通或少见；每一条在她的出处文件里都写明对应的资料和剧情位置，不收推断出来的条目。配错了应用起不来。这张票只把喜好写进配置并校验；送礼时多加的 +3 和她的反应由 05、06 用。见规格「礼物目录和喜好」的喜欢的礼物、出处的标准和那张配法表，以及 Further Notes 里对应得比较松的几条。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 角色配置给每位角色加一项喜欢的礼物，内容是礼物 `id` 列表，按规格表配（27 位）
- [ ] 启动时校验：每一条都是目录里的 `id`；每位 1–3 件；不能全是稀有。不满足应用就起不来
- [ ] 每位角色的出处文件加一小节「喜欢的礼物」，逐条写明对应的资料和剧情位置，还要如实写出是哪一种（点单、吃过、收到礼物时的反应、自己说喜欢……）。从具体的东西对应到通用礼物的（レモンティー→红茶、ホットチョコレート→热可可、ソーダアイス→冰淇淋、ねりあめ→糖果等），要写明是怎么对应的
- [ ] 出处文件里已经有的引用直接引过去；没有的先从剧情库补上：芹沢あさひ的布丁（【Howling】/ 何もないところへ），白瀬咲耶红茶那条更直接的台词（节日剧情 490110023 或【記憶が降る街】200601702）
- [ ] 查不到原文的条目不能硬配：只要某一条和规格表对不上，先停下来，在票的 `## Answer` 里写明是哪一条、哪里不对，问用户，不要自己换替补
- [ ] 核对规格那条约束：每件礼物至少有一位角色喜欢；布丁、肉包、盆栽、音乐 CD 都有人用
- [ ] 读目录接口和前端拿到的东西都不变，仍然不带喜好
- [ ] 测试：仓库里真实的角色配置能起来，每位角色都有喜欢的礼物，每件礼物至少有一位角色喜欢；测试用的角色配置写错时（喜欢的礼物不存在、喜欢 4 件、全是稀有）应用起不来
