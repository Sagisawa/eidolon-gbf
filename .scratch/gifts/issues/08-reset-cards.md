# 08: 重置卡

**What to build:** 有重置卡时，礼物页上有一条「重置卡 ×n」，写着现在用会拉回几位。点「使用」先看确认框，里面列出会回到信任的每一位和她们现在的档位；确认后所有低于信任的角色回到正常值 50，冷却中的马上可以说话，信任及以上的不受影响。她们不知道发生过什么，对话里不留记录。见规格「重置卡」、「接口约定」的用重置卡，以及「礼物页（前端）」的重置卡条。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 好感度模块加一个操作：先补算自然恢复，把这一刻低于信任（值低于 40，也就是疏远、冷淡、冷却中）的角色拉回 50，冷却随之解除；信任及以上的（包括 40–49）不变；返回被拉回的角色
- [ ] 用重置卡接口：在同一个事务里扣 1 张、执行拉回。以确认那一刻为准：确认框打开期间有人自然回到信任，就不拉她；一个都不剩时拒绝，不扣卡。没有卡时拒绝；没开放时返回带「没开放」原因的 409
- [ ] 不留痕迹：不生成送礼记录，不留任何对话事件，提示词里也不提；她回到信任档后，提示词和平时一样；以前的对话事件（她挂断了电话）照旧留着
- [ ] 读礼物状态返回重置卡张数，以及现在会拉回的角色（id、现在的档位、是否冷却）
- [ ] 重置卡条（有卡时才出现，描边圆角块）：「重置卡 ×n」，下面一句「现在用会把 n 位拉回信任」或「现在没有低于信任的角色，留着以后用。」；右边「使用」（outline，没有可拉回的角色时不可用）
- [ ] 点「使用」弹 `AlertDialog`：标题「使用一张重置卡？」，说明「下面几位会回到信任，冷却中的马上可以说话。她们不会知道发生过什么。」，列出每位的头像、名字、现在的档位 → 信任，按钮「取消」「使用」。用完后刷新抽奖台、重置卡条和送礼面板里的档位
- [ ] 重置卡条那句话怎么拼放进礼物纯模块
- [ ] `DESIGN.md` 的「礼物页」一节补上重置卡条和确认框
- [ ] 走接口的测试（重置卡用假随机来源抽出来）：没有卡时被拒、不扣卡；没有低于信任的角色时被拒、不扣卡；有卡时疏远、冷淡、冷却中的都回到信任，冷却中的可以马上发起回合；40–49 的和信任以上的不变；不留对话事件，下一回合的提示词里没有提到；以前的挂断事件还在；没开放时被拒
- [ ] 礼物纯模块的 vitest：重置卡条那句话
- [ ] 本地构建版上用 Playwright 验收：有可拉回的和没有可拉回的两种重置卡条、确认框、用完后对话页能马上说话
