# 02: 开场白：配置、合成、接口，接在现有的来电上

**What to build:** 真乃有一句开场白（GLOSSARY「开场白」）：原文「あっ、もしもし……真乃です。えっと、今、お電話だいじょうぶですか？」（带一个合她人设的语气提示），字幕「啊，喂……我是真乃。那个，现在方便接电话吗？」。它写在角色配置里，`eidolon greeting upload` 用她的音色和读音合成、上传到存储桶，角色接口给出原文、字幕和音频地址。落地页**现有的**第 4 幕在访客接听后改用它：响接通音，然后她说这一句（声音开关没关、有音频时出声，否则只有字幕），立绘在她说话时动嘴，字幕和原文显示在现在显示那句话的地方。文案目录里原来那句写死的话删掉。

这张票不动第 4 幕的版式，做完就能在现有页面上听到开场白；3D 手机和新的来电界面是 03、04 的事。ADR-0003 补一条修订，说明开场白音频（以及之后的卡图）属于对访客公开、放在存储桶、清空即下线的那一类。

详见 `.scratch/landing-call-phone/spec.md`「Implementation Decisions」的「开场白」和「来电界面和交互」里开场白那一条。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 角色配置能配开场白的原文和字幕；缺一样、或去掉语气提示后什么都不剩时启动报错，说法和招呼一致；没配的角色照常加载
- [x] `eidolon greeting upload` 合成并上传开场白，地址按原文（含语气提示）、音色和读音哈希，和招呼的地址分开、互不覆盖；已有的不重复合成；旧地址的开场白会被删掉
- [x] 角色接口给出开场白的原文（不含语气提示）、字幕和音频地址；没配存储桶地址时没有音频地址
- [x] 落地页接听后：接通音，然后开场白；声音开关关着时只有字幕；音频放不出来时退成字幕，不报错；真的出了声时声音开关出现
- [ ] 她说话时立绘动嘴，说完停下；挂断、离开这一幕时开场白停下
- [x] 打来电话的那位没有开场白时，接通后只有立绘和计时
- [x] 交互 reducer 的测试覆盖开场白的这几种情况；后端测试覆盖配置、上传、接口
- [x] ADR-0003 补了修订
- [x] 后端、前端的全部测试和类型检查通过
