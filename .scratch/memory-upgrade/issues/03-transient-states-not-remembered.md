# 03: 提炼标准：当天就过去的状态不记

**What to build:** 用户说「今天好累」「有点困」「心情不好」时，记忆页上不再多出一条；说生病了、要考试、要面试、要搬家、要出差这类会持续几天、过后会被问起的事，照样记下。背景见 `../spec.md`「提炼标准：短期状态」一节和 `GLOSSARY.md` 里「记忆」的定义。

**Blocked by:** 01（记忆评测和基线）、02（取代：改的是同一段提炼指示，排在后面可以避免冲突，评测结果也能单独归因）

**Status:** ready-for-agent

## 已定的设计（详见 spec）

- 提炼指示里「要记的」和「不要记的」改成以「过后仍有意义」为界：会持续几天、朋友过后会问起的近况要记；当天就会过去的状态和一时的情绪不记。
- 只改提炼指示，不改输出格式、取代规则和其他参数。

## 验收

- [ ] 记忆模块的测试：背景模型收到的指示里写明了这条界线（断言关键的说法，不逐字比对整段提示词）。
- [ ] 评测用例里短期状态类同时有「该记」（生病、考试……）和「不该记」（累、困……）两种，不够的话补上，标 `reviewed = false`，交给用户校对。
- [ ] `backend/` 下 `pytest` 全部通过，`ruff` 和 `pyright` 没有新的报错。
- [ ] **人工验收（留给用户）**：
  - 校对新补的用例；
  - 用真模型跑 `eidolon eval memory`：短期状态类的通过数多于基线（或者多于 02 之后的结果），其他类最多少 1 个用例；更新提交的结果，在 Comments 里记下对比；
  - 本地起服务说「今天好累」，记忆页没有新增；说「下周六要考试」，记忆页新增一条带具体日期的。
