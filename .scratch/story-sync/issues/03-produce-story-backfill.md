# 03: 培育剧情补齐

**What to build:** 同步时根据各偶像游戏内相册的数据，补齐 SCTranslationData 没收录的培育剧情（W.I.N.G.、感谢祭、G.R.A.D.、Landing Point、S.T.E.P.，以及早间、应援、试镜等培育中的交流），出处和标题取自相册。失败结局照常由现有规则排除。同步结束时，列出本次导入的培育剧情中标题带「敗」「失敗」、但没有被失败结局规则排除的剧情，供管理员人工核对。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 从各偶像的相册数据取得培育剧情的剧本编号、分组和标题，拉取剧情库中缺失的剧情
- [ ] 相册分类与剧本类型的对应沿用镜像站的规则（例如 character/season/unit/concert_event → produce_events）
- [ ] 失败结局照常排除（相册里标为「失敗」「敗退」「敗北」的编号，以及标题看不出、但现有规则认得的 W.I.N.G. 落败结局）
- [ ] 同步结束时打印失败嫌疑清单：标题带「敗」「失敗」但未被排除的培育剧情
- [ ] 相册数据没有变化时不重新下载
- [ ] 测试（切入点 B）：假相册中包含成功剧情、已知失败结局和一个标题带「敗」但规则认不出的剧情，覆盖补齐、排除和嫌疑清单
