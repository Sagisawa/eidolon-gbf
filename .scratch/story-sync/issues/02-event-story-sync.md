# 02: 活动剧情同步

**What to build:** 同步时也拉取活动剧情。活动剧情没有目录，按剧本编号的规律（`4001` + 三位活动编号 + 两位话数）推算：先补齐已知范围内剧情库缺失的活动（例如 SCTranslationData 缺的 002、056、077 等），再从已知最大的活动编号往后试探几个；找到的活动逐话拉取，直到 404。活动名来自管理员维护的「活动编号 → 正式活动名」对照表，没填的活动出处为「活动剧情 NNN」、标题为「第N話」；修改对照表后，下一次同步就更新剧情目录里的名称。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 补齐已知活动编号范围内剧情库缺失的活动剧情
- [ ] 从最大的已知活动编号往后试探几个编号（先试第 01 话），找到的活动逐话拉取直到 404；没有新活动时只多出少量 404 请求
- [ ] 新增活动名对照表（仓库里只有示例文件），填了的活动以正式活动名为出处，标题为「第N話」
- [ ] 没填对照表的活动用「活动剧情 NNN」和「第N話」占位，不编造名称
- [ ] 修改对照表后重新同步，剧情目录中该活动的名称随之更新，剧情不重复
- [ ] 汉化版到位后取代原文活动剧情（沿用 01 的规则）
- [ ] 测试（切入点 B）：假镜像中包含缺口活动、最新活动之后的新活动和不存在的编号，覆盖补齐、试探、对照表和占位名
