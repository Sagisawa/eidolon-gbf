# 04: 运行记录不再记自带 LLM 的服务地址和模型名

**What to build:** 服务器的运行记录里，自带 LLM 的服务调用不再记下服务地址的主机名和模型名，改记一个固定的通用值。上线时，数据库迁移把已有记录里属于自带 LLM 的这两列也改成这个通用值。这样服务器不会知道用户用的是哪一家、哪个中转。逻辑上这张票跟其他票无关，排在 01 后面只是因为两者改的是同一个模块。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 自带 LLM 的服务调用记录里，主机名和模型名是一个固定的通用值；部署者的调用照旧记真实的主机名和模型名。
- [ ] 数据库迁移把已有的、属于自带 LLM 的调用记录的这两列改成通用值，部署者的记录不动。迁移可以重复执行。
- [ ] 看板的健康统计（按「服务 + 是不是自带」分组）、后台用户页的用量拆分、费用估算的结果都不变。
- [ ] 后台单价页列出「最近用过的模型」时，不会把这个通用值当成一个未设单价的模型列出来。
- [ ] 测试：一个回合用了自带 LLM 后，运行记录里查不到它的主机名和模型名；迁移把旧记录改掉；单价页不列出通用值。
