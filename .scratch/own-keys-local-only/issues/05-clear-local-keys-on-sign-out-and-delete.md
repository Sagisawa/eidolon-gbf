# 05: 登出、删账号时清掉浏览器里的 key，浏览器存不了时如实告诉用户

**What to build:** 在共用电脑上，用户主动登出或删除账号以后，这个浏览器里就不再留有他的自带密钥。如果用户的浏览器存不了（隐私模式、本地存储被禁用），设置页直接告诉他，而不是看起来存上了、刷新一下就没了。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 单设备登出、在同意页拒绝后登出、删除账号成功后，都清掉当前用户在本地的自带密钥，其他用户的不动。
- [ ] 「在所有设备上登出」也清掉当前浏览器里的，确认时说明「其他设备上的自带密钥不会被清除」。
- [ ] `localStorage` 不可用（读写时抛错）时，本地存储模块报告不可用、不抛出异常；设置页的自带密钥一节显示「这个浏览器无法保存自带密钥」，表单禁用；发请求时不带 key。不退而存在内存里。
- [ ] 测试：前端测本地存储模块在不可用时的行为，以及登出、删除账号之后本地的 key 被清空。
