# 05: 登出、删账号时清掉浏览器里的 key，浏览器存不了时如实告诉用户

**What to build:** 在共用电脑上，用户主动登出或删除账号以后，这个浏览器里就不再留有他的自带密钥。如果用户的浏览器存不了（隐私模式、本地存储被禁用），设置页直接告诉他，而不是看起来存上了、刷新一下就没了。

**Blocked by:** 02

**Status:** done

- [x] 单设备登出、在同意页拒绝后登出、删除账号成功后，都清掉当前用户在本地的自带密钥，其他用户的不动。
- [x] 「在所有设备上登出」也清掉当前浏览器里的，确认时说明「其他设备上的自带密钥不会被清除」。
- [x] `localStorage` 不可用（读写时抛错）时，本地存储模块报告不可用、不抛出异常；设置页的自带密钥一节显示「这个浏览器无法保存自带密钥」，表单禁用；发请求时不带 key。不退而存在内存里。
- [x] 测试：前端测本地存储模块在不可用时的行为，以及登出、删除账号之后本地的 key 被清空。

## Comments

### 实现（2026-10-10）

- `api.ts`：`logout(userId?)`、`logoutEverywhere(userId?)`、`deleteAccount(userId)` 在服务器回成功之后清掉这位用户在本地的 key（`forgetOwnKeys`），其他用户的不动；服务器没成功时不清。设置页登出从已经拿到的 `account.id` 传进去；删除账号在确认那一下先问 `getAccount` 拿 ID。
- 同意页拒绝后登出调的是不带 ID 的 `logout()`：用户还没同意时 `/api/account` 拿不到 ID（会被送去同意页），而且同意以前用不了设置页和校验接口、一直没法存 key（同意不会被撤回），所以那里没有要清的。
- 「退出所有设备」加了确认框，说明「这个浏览器里的自带密钥会一并清除；其他设备上的自带密钥不会被清除」。
- `localOwnKeys.ts` 加 `canKeepOwnKeys()`：试写一个探测键再删掉，写不进或连 `localStorage` 都碰不到时报告不能存，不抛错。设置页存不了时在自带密钥一节开头显示「这个浏览器无法保存自带密钥……」，三项的「填写/修改」按钮停用。读不到时 `localOwnKeys` 返回空，发回合和通话都不带 key；不退而存在内存里。
- 测试：`localOwnKeys.test.ts` 测写入抛错、整个存储碰不到、存储正常三种情况；`api.test.ts` 测登出、退出所有设备、删除账号之后本地这位用户的 key 清空、别人的还在，服务器回 500 时不清。
- 代码评审后：设置页的「退出登录」「退出所有设备」在拿到账号之前是停用的，免得退出了却不知道该清谁的 key。
- 跟 spec 字面不一致的一处：同意页拒绝后的登出不清 key，理由见上（同意以前存不了 key，同意也不会被撤回）。

### 人工验证

用构建版前端（`next build` + `next start`）和本地后端：

1. 填好三项自带密钥，再用 dev 登录另一个用户也填一项；回到第一个用户，设置页点「退出登录」：Local Storage 里 `eidolon.ownKeys.<第一个用户 ID>` 没了，第二个用户的还在。
2. 重新登录第一个用户，填一项，点「退出所有设备」：先弹出确认框，写着其他设备上的自带密钥不会被清除；点取消什么都不发生；确认后退出，本地这一项没了。
3. 填一项后「删除我的全部数据」→ 确认：本地这位用户的那一项没了。
4. 用浏览器的隐私窗口（或在开发者工具里禁用站点数据，Chrome：设置 → 隐私 → 第三方 Cookie / 网站数据「不允许网站保存数据」）打开设置页：自带密钥一节开头显示「这个浏览器无法保存自带密钥……」，「填写」按钮是灰的；去对话页发回合，请求体里没有 `own_llm`。（Chrome 隐私窗口其实能写 localStorage，只是关窗就清，这种情况不会显示提示，属正常。）
