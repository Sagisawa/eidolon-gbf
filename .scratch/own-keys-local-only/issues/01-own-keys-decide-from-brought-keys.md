# 01: 先重构：自带密钥模块按「这次带来的 key」做决定

**What to build:** 为后面两张票铺路，这张票不改变任何行为。自带密钥模块决定一个回合或一次通话用谁的服务、免不免计入限额时，不再自己按用户去数据库查，而是接收一个「这次请求带来的自带密钥」值对象（llm、tts、stt 三项都可以没有，字段见 spec）。调用方暂时仍从数据库读出 key、解密，组装成这个值对象传进去。这样 02、03 只需要把值对象的来源换成请求体。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 有一个表示「这次请求带来的自带密钥」的值对象，llm、tts、stt 三项都可以为空，stt 包含服务商和（百炼的）地域。
- [ ] 回合和通话决定用谁的服务、是否免计入，只看这个值对象和部署者的 key，不再访问数据库。
- [ ] 从数据库读 key、解密、组装值对象是单独的一步，由回合和通话的准入调用。「解不开」的失败照旧在这一步抛出，回合 409 和通话预检 409 的行为不变。
- [ ] 自带密钥模块的测试改成按「带来了哪几项」来写：只带 llm、三项全带、只带语音、部署者没有某项而用户带了、百炼带地域、自带的失败了不回退到部署者的。
- [ ] 后端全部测试和类型检查都通过，HTTP 层的现有测试不用改。
