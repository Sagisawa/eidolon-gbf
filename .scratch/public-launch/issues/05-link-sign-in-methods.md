# 05: 绑定登录方式与退出所有设备

**What to build:** 已经登录的用户可以在设置页看到自己绑定了哪些登录方式，可以再绑定另一种，这样无论用 Google 还是 GitHub 登录，看到的都是同一份记忆。也可以解绑某种登录方式，但不能解绑最后一种。设置页还提供「退出登录」和「退出所有设备」。

**Blocked by:** 02, 03

**Status:** done

- [x] 绑定流程和登录流程共用同一个 OAuth 回调，靠 state 区分是登录还是绑定；绑定时要求当前已经登录
- [x] 要绑定的身份已经属于另一位用户时拒绝，提示「请先用这个身份登录，删除那位用户后再绑定」；已经绑在自己名下的，什么都不做
- [x] 绑定时同样检查 GitHub 账号注册满一年、Google 邮箱已验证
- [x] 解绑最后一种登录方式时拒绝
- [x] 「退出所有设备」会删除这位用户的全部会话，包括当前这个
- [x] 设置页显示已经绑定的登录方式：提供方、显示名、邮箱
- [x] 测试覆盖：绑定成功后，用任一身份登录都是同一位用户；绑定别人的身份被拒；解绑最后一种被拒；退出所有设备后，其他设备的会话也失效

## Comments

代码审查后确认保留（2026-09-27）：每个提供方最多绑定一个身份，已经绑定了 GitHub 身份时再绑另一个 GitHub 身份会被拒绝（already_linked），解绑按提供方进行。`CONTEXT.md` 的「登录方式」已同步修改。
