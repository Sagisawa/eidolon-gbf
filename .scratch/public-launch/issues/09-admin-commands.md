# 09: 管理员命令行

**What to build:** 管理员在服务器上可以列出所有用户（绑定了哪些登录方式、什么时候创建的、是否已封禁），可以封禁或解封某位用户，也可以查看某位用户最近的用量。封禁会让这位用户立刻在所有设备上退出登录，之后也无法再登录。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] `eidolon user list`：列出每位用户的 ID、名字、登录方式（提供方和显示名）、创建时间、是否已封禁
- [ ] `eidolon user ban <id>`：标记封禁，并删除这位用户的所有会话；正在进行的通话一并挂断
- [ ] `eidolon user unban <id>`：解除封禁
- [ ] `eidolon user usage <id>`：显示最近 24 小时按小时统计的文字回合数和通话次数，以及有多少不计入限额
- [ ] 被封禁的用户，已有会话的请求返回 403；用他的身份登录也会被拒，并提示已被封禁
- [ ] 删掉 `eidolon user create`，用户只能通过登录产生（开发环境用开发登录）
- [ ] 测试覆盖：封禁后，原来的会话被拒；封禁后登录被拒；解封后可以重新登录；列表和用量的输出
