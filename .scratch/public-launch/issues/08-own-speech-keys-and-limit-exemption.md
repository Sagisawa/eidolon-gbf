# 08: 自带语音合成与语音识别密钥，以及限额豁免

**What to build:** 用户可以在设置页填入自己的 Fish Audio key 和 Soniox key，之后通话里的语音合成和语音识别都改用自己的额度。自带密钥满足条件时，不计入每小时限额：文字回合只要用了用户自己的 LLM 就不计入；通话要 LLM、语音合成、语音识别三项都用用户自己的 key，才不计入。单次通话的时长和回合数上限对所有人都一样。

**Blocked by:** 07

**Status:** done

- [x] 自带密钥表支持 Fish Audio 和 Soniox 两种服务，只需要填 key；保存前先试调一次
- [x] 通话开始时，按用户解析出要用的语音合成和语音识别服务；音色 ID 照旧取自角色配置（音色都是公开的，见 ADR-0003 的修订）
- [x] 通话中自带密钥调用失败时，按现有规则结束通话或让这个回合失败，并提示是哪一项密钥出了问题，不会改用部署者的 key
- [x] 限额豁免：文字回合用了自带 LLM 就不计入；通话要 LLM、语音合成、语音识别都是自带的才不计入。不满足豁免条件的，按原规则计数
- [x] 单次通话的时长和回合数上限不变，对所有人都一样
- [x] 设置页新增语音合成和语音识别两栏，显示方式和 LLM 一栏相同；另外显示「当前是否不计入限额」
- [x] `FakeSpeech` 记录每次调用用的是哪个 key；测试覆盖：通话用的是用户的 key；调用失败时没有改用部署者的 key；只自带 LLM 时，文字回合不计入限额而通话照常计入；三项都自带时通话不计入；通话的时长上限对所有人都生效

## Comments

代码审查后确认保留（2026-09-27）：部署者没有配置语音合成或语音识别的密钥时，自带了这一项密钥的用户仍然可以通话；两项都缺时才不能通话。
