# 04: 登录页、隐私政策、使用条款与首次同意

**What to build:** 没登录的访客打开网站，只能看到登录页。登录页上有系统介绍、角色展示、「用 GitHub 登录」「用 Google 登录」两个按钮，以及隐私政策和使用条款的链接。第一次登录的用户会先看到同意页，勾选同意条款并声明年满 13 岁之后，才能开始使用。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 登录页：不需要登录就能看到角色的名字、简介和头像；只显示已经配置好的登录方式
- [ ] 隐私政策页（静态页面，不需要登录）：
  - 存了哪些数据：登录方式、对话、记忆、制作人档案、自带密钥（加密保存）
  - 交给了哪些第三方处理：LLM、Fish Audio、Soniox、向量化和重排服务商、Google 或 GitHub 登录
  - 自带密钥时，内容会发到用户自己选的服务商
  - 怎样删除全部数据
- [ ] 使用条款页（静态页面）：写明这是非官方的粉丝作品、角色由 AI 扮演、不保证服务一直可用、需要年满 13 岁
- [ ] 用户没有同意条款前，除「同意」「退出登录」「删除数据」外的所有接口都返回一个专门的状态码；前端收到后跳到同意页
- [ ] 同意接口会记下同意的时间
- [ ] 01 里临时的开发登录页换成正式的登录页；开发登录开关打开时，登录页上额外显示开发登录入口
- [ ] 测试覆盖：没同意条款时，调用对话接口被拒；同意之后能正常对话；没同意条款也能退出登录
