# 01: 用会话取代访问密钥

**What to build:** 访问密钥整个去掉，登录状态改成保存在后端的会话里，浏览器通过 httpOnly cookie 保持登录。在还没有接入 OAuth 之前，本地可以用开发登录开关直接以某位用户登录，然后完整走一遍文字对话、通话、记忆管理和制作人档案，行为和以前一样，只是凭证从 Bearer 密钥变成了 cookie。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 删除访问密钥表，以及 `key issue`、`key list`、`key revoke` 命令；新增会话表，只存令牌的哈希、最后活跃时间和过期时间
- [ ] 用户表的 `name` 去掉唯一约束；新增「已同意条款」和「已封禁」字段，本 ticket 只建字段、不加业务逻辑
- [ ] 会话 cookie 设为 httpOnly、SameSite=Lax；配置了 `EIDOLON_DOMAIN` 时再加 Secure
- [ ] 会话有效期 30 天，只要在用就续期；过期的或不存在的会话返回 401
- [ ] 所有会改动数据的请求都校验 Origin，不同源的请求被拒绝
- [ ] 「解析当前用户」的依赖改为按会话鉴权；语音信令（offer）同样按会话鉴权，原有的「通话连接属于该用户」校验保留
- [ ] 新增退出登录接口：删除当前会话，清掉 cookie
- [ ] `EIDOLON_DEV_LOGIN=1` 时，开放一个开发登录接口，按名字登录，用户不存在就创建；如果同时配置了 `EIDOLON_DOMAIN`，后端拒绝启动，并说明原因
- [ ] Next 代理层转发 Cookie 请求头和 Set-Cookie 响应头；前端去掉 localStorage 里的访问密钥和设置页里填密钥的输入框，请求返回 401 时跳到一个临时的开发登录页（04 会把它换成正式的登录页）
- [ ] 数据库打开 WAL 模式
- [ ] 测试夹具从「带访问密钥」改为「带会话」；原来的访问密钥测试改写成会话测试，覆盖这几种情况：没有会话、会话无效、会话过期、会话续期、退出登录、跨源请求被拒、开发登录开关与生产环境互斥
