# 02: GitHub 登录

**What to build:** 访客点击「用 GitHub 登录」，授权后回到网站，就已经登录好了。第一次用某个 GitHub 身份登录时，自动创建一位新用户，名字取自 GitHub 的显示名或用户名；之后再用同一个身份登录，就是同一位用户。GitHub 账号注册不满一年的，登录会被拒绝，并看到明确的原因。

**Blocked by:** 01

**Status:** done

- [x] 新增 `IdentityProvider` 接口：生成授权跳转地址（带 state），用回调里的授权码换取身份。身份包括提供方、提供方内的唯一 ID、显示名、邮箱、邮箱是否已验证、账号创建时间。由装配根注入
- [x] 实现 GitHub 提供方，读取 `GITHUB_CLIENT_ID` 和 `GITHUB_CLIENT_SECRET`；回调地址根据 `EIDOLON_DOMAIN` 拼出，开发环境用 localhost。没配置 GitHub 时，不显示也不开放这种登录方式
- [x] 新增「登录方式」表：用户、提供方、提供方内 ID，后两者联合唯一
- [x] 回调时校验 state，不匹配就拒绝；账号创建时间不满一年的拒绝登录；被封禁用户的身份拒绝登录（封禁命令在 09 实现，这里先按字段判断）
- [x] 登录成功后创建会话、设置 cookie，然后跳回首页；失败时跳到一个页面，上面写着失败原因
- [x] 测试夹具新增 `FakeIdentityProvider`，由测试指定它返回的身份；新增「以某个身份登录」的辅助函数
- [x] 测试覆盖：首次登录创建用户；再次登录还是同一位用户；两个不同的身份是两位用户；账号不满一年被拒；state 不匹配被拒；被封禁的用户被拒
