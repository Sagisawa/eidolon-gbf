# 06: 删除我的全部数据

**What to build:** 用户在设置页点「删除我的全部数据」，再确认一次之后，这位用户的记忆、对话、制作人档案、登录方式、自带密钥、会话和用量记录都被彻底删除，所有设备上都会退出登录。之后再用同一个身份登录，得到的是一位全新的用户。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 删除接口要求请求里带一个确认字段，防止误触
- [ ] 在一个事务里删除这位用户的所有数据，包括记忆向量；做完的是物理删除，不是标记删除
- [ ] 这位用户正在通话时，挂断通话
- [ ] 自带密钥表（07）和其他后来新增的、属于用户的表都要纳入删除范围；在这个 ticket 里留一个统一的删除入口，后面的 ticket 往里加
- [ ] 设置页新增「删除我的全部数据」，点击后弹出二次确认，删除完成后跳到登录页
- [ ] 测试覆盖：删除后，数据库里查不到这位用户的任何数据；原来的会话失效；用同一个身份登录，得到一位没有记忆、没有对话的新用户；其他用户的数据不受影响
