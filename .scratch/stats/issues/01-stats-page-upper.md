# 01: 设置里的「统计」和上半部分

**What to build:** 用户在设置第一组的记忆后面看到「统计」，一级列表上写「已认识 N 天」。点进去是统计页的上半部分：
- 注册以来的天数；
- 当前和最长的连续来访；
- 一句话画像（常在哪个时段来）；
- 过去 52 周的热力图。

整页都没有数据时，只显示一句话和一个去对话列表的按钮。所有数都按制作人档案的时区算，删掉一段历史对话后不再算它。

这张票同时立起统计接口和前端的统计逻辑模块，后面几张票往里加。见 `../spec.md` Solution 第 1、2、4、5 条，Implementation Decisions「统计接口」「口径」「设置页」「图表」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 设置第一组变成［档案、记忆、统计］，`/settings/stats` 能打开、能刷新；一级列表的摘要写「已认识 N 天」；DESIGN.md 设置页那一节（几类、几组、网址清单）跟着改
- [ ] `GET /api/stats` 要求登录，只返回自己的数；上半部分带注册天数、当前和最长连续来访、全部时间的 24 小时分布、过去 52 周的每日计数（回合 + 送礼）
- [ ] 时区：档案设了时区按档案，没设按 `X-Timezone`；跨午夜的回合落在用户本地的那一天、那个钟点
- [ ] 连续来访：只送了礼的那天也算来过；今天还没来、昨天来过时，当前连续不断
- [ ] 删掉一段历史对话后，热力图、连续来访、24 小时分布都少了它；注册天数不变
- [ ] 一句话画像按 0–6、6–12、12–18、18–24 四段里来得最多的那段说一句，不报钟点；并列的规则在逻辑模块里定下并有测试
- [ ] 热力图：周一开头，52 个整周加本周已过的几天，单色深浅分级；宽度随容器变化，手写 SVG，不引入图表库
- [ ] 哪一块没数据就不显示；整页为空时显示一句话和去对话列表的按钮
- [ ] DESIGN.md 补统计页一节，加一条例外：属于某位角色的图形用她的印象色，其余图表仍然单色
- [ ] 后端测试走统计接口（先例 `test_past_conversations.py`、`test_delete_past_conversations.py`、`test_gift_giving.py`）；前端统计逻辑模块有单元测试（热力图分级、画像时段、空状态）
- [ ] 本地构建版 Playwright 验收（宽屏、手机）：设置入口和摘要、有数据和全空两种页面、删一段历史对话后数变少
- [ ] 后端完整测试、前端类型检查和测试、前端纪律检查都通过
