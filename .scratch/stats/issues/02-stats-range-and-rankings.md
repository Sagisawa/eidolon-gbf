# 02: 下半部分：时间跨度、总数、聊得最多、分时段和礼物

**What to build:** 统计页的下半部分，顶上是一个分段选择「近 30 天 / 近一年 / 全部」，默认「全部」，下面的内容跟着选择变：
- 总数里的回合数和送出的礼物数；
- 「聊得最多」前 5 位，用她的印象色画条，每行写回合数和「认识 N 天」；
- 0–23 点的分时段图；
- 礼物：送得最多的是哪一位，以及她喜欢的礼物送了几次。

见 `../spec.md` Solution 第 3、4 条，Implementation Decisions「统计接口」「口径」「图表」。

**Blocked by:** 01（设置里的「统计」和上半部分）

**Status:** ready-for-agent

- [ ] 统计接口接受 `range=30d|1y|all`（默认 `all`），下半部分随它变，上半部分不变；「近 30 天」是含今天的 30 个本地日，「近一年」是 365 个本地日
- [ ] 下半部分带：回合总数、送礼总数、按角色的回合数和认识天数、这段跨度里的 24 小时分布、按角色的送礼数、她喜欢的礼物送了几次
- [ ] 认识天数从和她还留着的对话里最早的一条消息或对话事件算起；删掉最早那段后变短
- [ ] 「聊得最多」只列回合数大于 0 的前 5 位，条用她的印象色，浅色和深色下都看得清；被隐藏的角色照常出现
- [ ] 「送得最多」并列时取偶像顺序靠前的那位
- [ ] 分时段图 24 根柱子，单色，手写 SVG，宽度随容器变化
- [ ] 切换跨度时重新请求，切换过程中页面不跳动、不闪空
- [ ] 后端测试走统计接口：三种跨度的边界、时区、删历史对话、认识天数、送礼并列；前端逻辑模块测试：排行取前 5、只取大于 0 的、哪块不显示
- [ ] 本地构建版 Playwright 验收（宽屏、手机）：切换三种跨度、排行条的印象色
- [ ] 后端完整测试、前端类型检查和测试、前端纪律检查都通过
