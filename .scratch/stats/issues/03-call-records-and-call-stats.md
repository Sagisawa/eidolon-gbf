# 03: 通话记录和通话统计

**What to build:** 从这张票上线起，每通接通了的通话都在它所在的对话下面记一条，内容只有接通那一刻的时间和接通时长。统计页的总数里因此多了通话次数和通话时长（「X 小时 Y 分」），下半部分多了「通话最久」前 5 位，都跟着时间跨度变。

通话记录不在对话记录里显示，她不知道，删对话、删用户时一起删掉。隐私政策补一句说明它。

见 ADR-0021，`../spec.md` Implementation Decisions「通话记录」「隐私政策」。

**Blocked by:** 02（下半部分：时间跨度、总数、聊得最多、分时段和礼物）

**Status:** ready-for-agent

- [ ] 接通过的通话结束时（不论谁挂断、因为什么结束）写一条记录：所属对话、接通那一刻（UTC）、接通时长；没能接通的不写。时长和运行记录里这通的接通时长一致
- [ ] 新表登记进数据库的用户数据名单和随对话删除的名单；删一段历史对话、删用户后都没有它的通话记录
- [ ] 通话记录不是对话事件：对话记录里看不到，她之后的回复和判断模型都不知道；「新对话」能不能点、历史面板列不列，都和以前一样
- [ ] 通话期间对话在别处被结束了，这通照样记下
- [ ] 统计接口下半部分带通话次数、通话总时长、按角色的接通时长；总数显示通话次数和「X 小时 Y 分」；「通话最久」只列时长大于 0 的前 5 位，条用她的印象色
- [ ] 一通电话都没打过的用户，看不到「通话最久」这一块；总数里通话两项照写 0
- [ ] 隐私政策「我们存了什么」里补一句：每通接通的通话会在对话下记下开始时间和时长，不含内容，随对话删除
- [ ] 后端测试走通话夹具和统计接口（先例 `test_voice_call.py`、`test_call_records.py`）：接通的进、没接通的不进、她挂断的也进、随对话和用户删除、跨度边界
- [ ] 本地构建版 Playwright 验收：打一通电话（假麦克风）挂断后，统计里通话次数加一、时长变化
- [ ] 后端完整测试、前端类型检查和测试、前端纪律检查都通过
