# 04: 好感度分组，以及关掉好感度和礼物时

**What to build:** 统计页上半部分多一块「好感度」：按冷淡、疏远、信任、亲近、亲密五档列出每档里的角色头像，头像用她的印象色；同一档里按原作偶像顺序排，看不出谁高谁低。

部署者关掉好感度和礼物时，统计里不出现以下内容：
- 好感度分组；
- 礼物那一块；
- 总数里的「送出的礼物」。

见 `../spec.md` Solution 第 2、6 条，Further Notes 最后一条。

**Blocked by:** 01（设置里的「统计」和上半部分）

**Status:** ready-for-agent

- [ ] 统计接口上半部分带好感度分组：每档的角色，只有档位、没有数值，每档内按偶像顺序排；冷却中的照样在冷淡那一档
- [ ] 好感度和礼物关掉时，好感度分组和礼物相关字段为 null；前端见 null 就隐藏好感度分组、礼物那一块和「送出的礼物」（02 已经做了礼物那一块的话，一并处理）
- [ ] 没有角色的档不显示；头像用她的印象色，浅色和深色下都看得清；被隐藏的角色照常出现
- [ ] 后端测试走统计接口：分组和顺序、接口里没有数值、关掉时为 null（先例 `test_affinity.py`）；前端逻辑模块测试：关掉时哪几块不显示
