# 统计：用户自己看和她们往来的汇总，并能导出分享图

Status: ready-for-agent

术语以 `GLOSSARY.md` 为准（新增「统计」「分享图」）。通话为什么另记在对话下面、不读运行记录，见 ADR-0021。界面文案要少、简明，不加解释口径的小字。

## Problem Statement

- 后台有给管理者看的看板，用户自己却看不到任何汇总：和谁聊得最多、通话打了多久、多久来一次、和她们现在关系怎样，都只能靠翻对话记录去猜。
- 用户想把和她们的往来晒出去，只能自己截图；截出来的东西又长又乱，也没有指回这个网站的东西，看到的人不知道这是哪里。
- 通话本身不在对话数据里：每通打了多久只在运行记录里，运行记录只有管理者能看，只留 90 天，也挂不到某段对话上。

## Solution

1. **入口**：设置的第一组变成［档案、记忆、统计］。一级列表上「统计」的摘要写「已认识 N 天」（N 从注册那天算起）。
2. **页面分上下两部分**。上半部分不受时间跨度影响：
   - **认识天数**：从注册那天算起。
   - **连续来访**：当前连续几天、最长连续几天。某一天至少有一个回合或送过一次礼才算来过，打开页面不算；今天还没来、昨天来过的，当前连续不断。
   - **一句话画像**：按全部时间里哪个时段来得最多，说一句，比如「常在深夜来」。时段分 0–6、6–12、12–18、18–24 四段，不报具体钟点。
   - **热力图**：过去 52 周，每天一格，按当天的回合数加送礼次数决定深浅，单色。
   - **好感度分组**：按冷淡、疏远、信任、亲近、亲密五档，列出每档里的角色头像。头像用她的印象色，同一档里按原作的偶像顺序排，不排先后。
3. **下半部分**：顶上一个分段选择「近 30 天 / 近一年 / 全部」，默认「全部」。下面这些跟着选择变：
   - **总数**：回合、通话次数、通话时长（显示成「X 小时 Y 分」）、送出的礼物。
   - **聊得最多**：按回合数排前 5 位，每行写回合数和「认识 N 天」。这里的 N 从和她还留着的对话里最早的一条记录算起。
   - **通话最久**：按接通时长排前 5 位。
   - **分时段图**：0 到 23 点 24 根柱子，单色。
   - **礼物**：送得最多的是哪一位，以及她喜欢的礼物送了几次。

   排行只列数值大于 0 的角色，条用她的印象色。
4. **口径**：
   - 只用对话里还在的东西算，删掉的历史对话不再算进统计。
   - 日期和钟点按制作人档案的时区算。
   - 被隐藏的角色照常出现。
   - 通话次数只算接通了的。时长从接通算到挂断，从这项功能上线起才有，页面上不写明从哪天开始。
5. **没有数据时**：哪一块没数据就整块不显示。整页都没有数据时，只显示一句「还没有和她们说过话」和一个去对话列表的按钮。
6. **好感度和礼物关掉时**：好感度分组、礼物那一块、总数里的「送出的礼物」都不显示。
7. **分享图**：
   - **入口和下载**：统计页右上角一个「分享」按钮（图标加字），点了直接下载一张 PNG，不调用系统分享面板，免得在 Windows 上弹出系统分享窗口。
   - **尺寸和主角**：固定 1080×1350。以当前时间跨度里聊得最多的那位为主角，放她的头像和名字，整张以她的印象色为基调。
   - **内容**：用户在制作人档案里设了的称呼（没设写「制作人」）、一句话画像、四个总数、聊得最多的前 3 位、小号热力图，底部是网站名、网址和指向落地页的小二维码。
   - **跟着时间跨度走**：卡上用一个小标签写明跨度。
   - **不放的东西**：好感度、任何登录方式的信息、「非官方粉丝作品」字样。
   - **什么时候不能导出**：当前跨度里一个回合都没有时，按钮隐藏。前 3 位不满三人的有几位列几位；某项为 0 照写 0。
   - **视觉方向**：先出几个不同风格的方向稿，由用户选定一个，再按它实现。

## User Stories

1. 作为用户，我想在设置里找到「统计」，这样我不用翻对话记录也能看到自己和她们的往来。
2. 作为用户，我想在设置的一级列表上直接看到「已认识 N 天」，这样不点进去也有个念想。
3. 作为用户，我想看到我注册以来过了多少天，这样我知道自己陪了她们多久。
4. 作为用户，我想看到我现在连续来了几天、最长连续过几天，这样我有动力每天来。
5. 作为每天只来送礼的用户，我想让送礼那天也算来过，这样连续来访不会因为那天没说话就断掉。
6. 作为用户，我想在今天还没来时看到连续天数照样保留，这样不会一早打开就看到「0 天」。
7. 作为用户，我想读到一句关于我常在什么时段来的话，这样页面有一点像她们在说我。
8. 作为用户，我想看到过去一年每天来没来、来得多不多的热力图，这样一眼就看得出自己的习惯和起伏。
9. 作为用户，我想看到每位角色现在在哪一档好感度，这样我知道和谁亲近、和谁疏远了。
10. 作为用户，我想在好感度分组里看不出同一档谁高谁低，这样统计页不会泄露她心里的分数。
11. 作为用户，我想在统计里照样看到被我在列表里隐藏的角色，这样统计说的是真实发生过的事。
12. 作为用户，我想选「近 30 天 / 近一年 / 全部」，这样我能看最近的情况，也能看全部的累计。
13. 作为用户，我想看到一共多少个回合、打了几通电话、通话一共多长、送出多少礼物，这样我对自己的往来有个总数。
14. 作为用户，我想看到和谁聊得最多的前 5 位，以及我和她们各认识了多久，这样我知道自己最常找谁。
15. 作为常打电话的用户，我想看到和谁通话最久的前 5 位，这样只打电话不打字也有我的排行。
16. 作为用户，我想看到我通常在一天里几点来，这样我知道自己是早起型还是夜猫子。
17. 作为用户，我想看到我送礼最多的是谁、送了几次她喜欢的，这样我知道自己的心意都给了谁。
18. 作为用户，我想在排行里看到每位角色用她的印象色，这样不读名字也认得出是谁。
19. 作为用户，我想删掉一段历史对话以后，统计里也不再算它，这样「删了就彻底没了」是真的。
20. 作为用户，我想统计按我档案里的时区划天和钟点，这样「深夜」就是我这里的深夜。
21. 作为刚注册、还没说过话的用户，我想看到一句话和一个去对话列表的按钮，而不是一页空图表，这样我知道该从哪开始。
22. 作为用户，我想在某一块没有数据时不看到它（比如还没打过电话），这样页面上没有空的框。
23. 作为部署者关掉了好感度和礼物的部署里的用户，我想统计里不出现好感度和礼物，这样不会看到别处根本没有的东西。
24. 作为用户，我想点「分享」就下载一张排版好的图，这样我能直接发到社交平台。
25. 作为用户，我想分享图以我聊得最多的那位为主角、用她的颜色，这样每个人的图都不一样，也更像是「我和她」的。
26. 作为用户，我想分享图上写着我设的称呼，这样看的人知道这是我的。
27. 作为没设称呼的用户，我想分享图上写「制作人」，这样不会出现空白或我的登录名。
28. 作为用户，我想分享图上不出现好感度和我的登录信息，这样晒出去的东西不会让我难堪或暴露身份。
29. 作为用户，我想分享图跟着我选的时间跨度、并写明是哪个跨度，这样我能晒「近 30 天」也能晒「全部」。
30. 作为用户，我想在 Windows 上点「分享」不弹出系统的分享窗口，这样我只是拿到一张图片文件。
31. 作为看到分享图的人，我想扫二维码或看网址就能找到这个网站，这样我也能来试试。
32. 作为用户，我想在所选跨度里没有回合时看不到「分享」按钮，这样不会导出一张没有主角的空图。
33. 作为维护者，我想让分享图的视觉风格先出几个方向再挑，这样传播出去的图是精心选过的样子。
34. 作为用户，我想统计里的通话时长不包含没接通的通话，这样它说的是我们真正聊了多久。
35. 作为部署者，我想让通话记录不含任何内容、跟着对话和用户一起删，这样隐私政策的承诺不变。
36. 作为用户，我想在隐私政策里看到统计用到的通话记录，这样我知道系统存了什么。
37. 作为管理者，我想看板照旧只看运行记录，统计不改动看板，这样两者各管各的。

## Implementation Decisions

- **统计接口**：`GET /api/stats?range=30d|1y|all`，默认 `all`，要求登录。
  - **时区**：按制作人档案的时区；没设的用请求头 `X-Timezone`；都没有用默认时区。和回合里判断「今天」的规则同一个。
  - **返回**：一次带回上下两部分，切换跨度时重新请求整份。上半部分不随跨度变：注册日起的天数、当前和最长连续来访、全部时间的 24 小时分布（供一句话画像用）、过去 52 周的每日计数、好感度分组。下半部分随跨度变：四个总数、按角色的回合数、接通时长和认识天数、24 小时分布、礼物。
  - **好感度关掉时**：好感度分组、礼物相关字段为 null，和现在 `/api/characters/{id}/affinity` 关掉时返回 null 一样；前端见 null 就隐藏对应那块。
  - **只给数，不定样子**：排行取前几、哪块不显示、画像落在哪个时段，都由前端定。
  - **数据形状**：在 01 里定下，02、03、04 往里加字段。
- **口径**（都在后端的用户时区里算）：
  - **一个回合**算一条用户消息，时间取那条消息的时间。
  - **送礼**算一条 `gift` 对话事件。
  - **热力图、连续来访、24 小时分布**：数的都是「回合 + 送礼」。
  - **注册天数**：从用户的创建时间算，删对话不影响。
  - **认识她多久**：从和她还留着的对话里最早的一条消息或对话事件的时间算。
  - **跨度**：「近 30 天」指含今天在内的 30 个本地日；「近一年」指 365 个本地日。
  - **热力图**：以周一为一周开始，铺满 52 个整周外加当前这周已过的几天。
  - **连续来访**：「当前连续」从今天往回数；今天没来，就从昨天往回数。
  - **送得最多的是谁**：送礼次数最多的那位。并列时按偶像顺序取第一位。
  - **她喜欢的送了几次**：所有送礼事件里 `liked` 为真的数量。
- **通话记录**（ADR-0021）：
  - **存在哪**：新表，按对话存每通接通了的通话：所属对话、开始时间（接通那一刻，UTC）、接通时长。不含任何内容。
  - **什么时候写**：通话结束、判定为接通过（结果不是「没能接通」）时，写一条到这通所属的对话。在通话的结局判定那一处取时长，口径和运行记录里的接通时长相同。
  - **删除**：表登记进数据库的用户数据名单和「挂在对话下面、随对话删除」的名单，删对话、删用户时一起删掉。
  - **它不是什么**：
    - 它不是对话事件，不显示在对话记录里。她不知道这条记录，判断模型也不知道。
    - 它不算对话的「一条记录」：「新对话」能不能点、历史面板列不列，都和现在一样。
    - 通话期间对话在别处被结束了，这通照样记下。
  - **旧数据**：不补上线前的通话。
- **设置页**：新增一类 `stats`，放进第一组记忆的后面。要同步改的有：分类的图标、面板、文案，一级列表的摘要（「已认识 N 天」，数据取统计接口或已有的账户信息，实现时看哪个现成），以及 DESIGN.md 设置页那一节「几类分几组」和网址清单。
- **图表**：
  - 手写 SVG，宽度随容器变化，和后台的图表同样画法（DESIGN.md「Charts」）。不引入图表库，也不用 shadcn 的 chart。
  - 热力图和分时段图只用 `--foreground` 一种颜色。
  - 排行条和好感度分组的头像用她的印象色。DESIGN.md 加一条例外：属于某位角色的图形用她的印象色。
  - 印象色的深浅、对比要照现有的印象色规则处理，保证在浅色和深色下都看得清。
- **分享图**：
  - **怎么生成**：在浏览器里把一个专门的分享图组件转成 PNG。新增一个把页面元素转成图片的库（候选 modern-screenshot，实现时定），再新增一个二维码库。二维码指向当前站点的落地页（用页面的 origin，不写死域名）。
  - **字体**：用户的称呼可以是任何字，生成的图必须不缺字。不缺字的标准是：应用字体里没有的字，由浏览器的系统字体补上。
  - **CSP**：要允许生成过程中用到的 `data:`、`blob:` 图片。
  - **下载**：文件名带日期，例如 `eidolon-stats-2026-10-16.png`。
  - **设计**：视觉方向由单独的一张票先定下，不在这份 spec 里规定排版。
- **隐私政策**：「我们存了什么」里补一句，说明每通接通的通话会在对话下记下开始时间和时长，不含内容，随对话删除。
- **前端规矩**：按前端的 shadcn 纪律写，文案进中文文案表。统计页和分享图在 DESIGN.md 各补一节。

## Testing Decisions

- 好的测试只测对外的行为：接口返回什么、页面逻辑给出什么，不测表结构和内部怎么算。
- **后端**：都从统计接口上看，不另立切入点。先例是 `test_past_conversations.py`、`test_delete_past_conversations.py`、`test_gift_giving.py`、`test_call_records.py` 和 `test_voice_call.py` 里的通话夹具。要测的有：
  - 各数在时区边界上落在哪一天、哪个钟点：档案时区优先于 `X-Timezone`。
  - 三种跨度的边界。
  - 连续来访：只送礼的那天也算；今天没来时从昨天数起。
  - 删掉一段历史对话后，各数都少了它，但注册天数不变。
  - 认识天数取还留着的最早记录。
  - 接通了的通话进次数和时长，没接通的不进。
  - 通话记录随对话、随用户删除。
  - 好感度关掉时对应字段为 null。
  - 一个用户看不到别人的数。
- **前端**：统计页逻辑模块的单元测试。先例是 `lib/dashboard.test.ts`、`lib/conversationList.test.ts`。要测的有：
  - 热力图格子和深浅分级；
  - 24 小时分布落到哪个时段（含并列）；
  - 排行取前 5、只取大于 0 的；
  - 哪块不显示、整页为空；
  - 分享按钮何时隐藏；
  - 分享图的内容：主角、前 3、称呼或「制作人」、跨度标签。

  组件不写测试。
- **验收**：按 `docs/agents/local-acceptance.md` 在本地构建版上用 Playwright，宽屏和手机都看：
  - 设置入口和摘要；
  - 有数据和全空两种页面；
  - 切换跨度；
  - 删一段历史对话后数变少；
  - 打一通电话后通话数变化；
  - 关掉好感度和礼物后那几块消失；
  - 下载的分享图：尺寸、内容、无缺字、二维码能扫出落地页地址。

## Out of Scope

- token、花费等任何用量（运行记录维持只有管理者能看）。
- 用运行记录补回上线前的通话。
- 在对话记录里显示「通话 12:34」这样的行。
- 最长的一次通话；被她挂断、被她结束对话的次数；记忆条数。
- 好感度随时间的变化曲线、抽奖次数（这两样都没有历史数据）。
- 「近 7 天」跨度、自定义日期范围、按年份翻看热力图。
- 趋势折线图。
- 调用系统分享面板，以及直接分享到某个平台。
- 分享图上的「非官方粉丝作品」字样、用户的登录头像或登录名。
- 管理者在后台看某位用户的统计。

## Further Notes

- 分享图的视觉方向由一张单独的票先定：用 magpie-image 生几张风格差异大的方向稿，只看气质和构图，不当真用里面的字和数；再用原型技能，在一个原型分支上用真实数据和字体做 2 到 3 个方案，由用户选定后再实现。
- 好感度只露档位（GLOSSARY「好感度」）：接口只给档位，不给数值，同一档里也不给出能看出高低的先后。
