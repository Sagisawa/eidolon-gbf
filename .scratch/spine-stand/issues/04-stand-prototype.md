# 04: 原型：通话层里的立绘

Type: prototype
Status: resolved
Blocked by: 01, 03

## Question

在通话层里真的放一套 stand，立绘应该怎么放、怎么动才对：构图（半身还是全身、手机全屏与电脑右栏下怎么裁）、与背景图和字幕的层次、轨道叠加后的待机、切换情绪时的过渡、口型大致效果。做一个可以手动切情绪和「在说话」状态的粗糙原型，给人看。

## Answer

2026-09-30 用户在浏览器里亲自操作原型后定下。原型提交在分支 `prototype/spine-stand`（`ed867bb`，一次性代码，不合并；2026-10-01 分支已删除）：用开发环境打开 `/prototype/stand`，`?variant=A|B|C&device=phone|desktop&idol=1|4`。

**构图**：
- **手机用 C「大立绘」**：立绘从底部升起，镜头到膝，名字、计时和字幕在上方，底部压一层她的深色渐变，让按钮看得清。
- **电脑用 A「全身居中」**：立绘占掉原来头像的位置，整张立绘都放得下，名字和字幕在脚下。
- B「半身 ADV」（立绘铺满、字幕放在底部对话框里）没选上。
- stand 素材本身只画到大腿，所以「全身」就是整张立绘。

**动作**（用户确认没问题）：情绪切换的 0.3 秒过渡；带 `loop_start` 的动作开头播一次、之后停在尾段循环；`relay` 离开时先放下手臂；点头播一次后清掉轨道；你开口时看向你（`eye_front`），停下时点一次头，用户认为够了。

**原型里踩到、spec 必须写进去的坑**：
1. **spine-ts 3.6 的剪裁 bug**：渲染器遇到没有附件的插槽直接 `continue`，跳过 `clipEndWithSlot`。剪裁的结束插槽当下没有附件时，剪裁永远不结束，后面画的东西全被裁进眼睛里（一只眼睛、睫毛、眉毛消失，手臂残缺）。2215 套里 2135 套用到了剪裁，304 套在初始姿势下就会触发，动画中途把结束插槽清空时也会触发。runtime 不能改（ADR-0009），所以在自己的代码里每帧把剪裁结束插槽改成「范围内最后一个真的会画出来的插槽」，范围内什么都不画时这一帧摘掉剪裁附件。用「花風Smiley」验证过。
2. **停嘴要冻结说话口型的第 0 帧，不能用 `lip_*_s`**：身体动作（`wait`、`smile1`、`shy1` 等）自己也会让嘴动（嘴部网格变形、换嘴部附件），`lip_*_s` 不控制网格变形，停了嘴还在微微动。冻结时要用 `animationEnd = 0`，不能用 `timeScale = 0`：3.6 的混合进度是 `mixTime += delta * timeScale`，timeScale 为 0 时混合永远走不完，上一段说话口型会一直在底下播。用户确认修好了，浏览器里取数也确认停嘴后嘴部状态不再变化。
3. **贴图预乘 alpha**：上传前 `UNPACK_PREMULTIPLY_ALPHA_WEBGL`，绘制时 `premultipliedAlpha = true`。
4. **React 开发模式下 effect 执行两次**：引擎销毁时不能 `loseContext()`，因为同一块画布重建引擎拿到的是同一个 context。
5. **`spine-webgl.js` 的换行符**：提交时 Git 会做 LF/CRLF 转换，改变校验和。vendor 目录要在 `.gitattributes` 里标成 `-text`。
6. 表情缺失时退到 `blank`，口型逐级找替代（真乃没有 `lip_wait`，退到 `lip_smile`），这些替代规则都按调研实现，工作正常。

**修订（2026-09-30）**：用户改主意，**电脑用 B「半身 ADV」**，不用 A：立绘铺满通话层做底，镜头从头到腰，名字、计时和字幕放在底部一个半透明的对话框里，底部同样压一层她的深色渐变。手机仍用 C「大立绘」。上面「电脑用 A」一条作废。
