# 19: 用户在对话页换衣装

**What to build:** 用户在对话页页首点「换衣装」，就能从这位角色的全部衣装里挑一套：按卡片浏览，在私服和演出服之间切换，看会动的大预览，点「穿这套」后保存在这台设备上，下次打电话她就穿这套。同时，浏览器会在空闲时把当前衣装预取好。规则见 `../spec.md`「衣装与换衣装」一节；依据见「拍板：衣装在哪里选、怎么选」和「拍板：立绘在加载中、加载失败和减少动态效果时怎么表现」（`09-outfit-picker.md`、`12-stand-degraded-states.md`）。

参考：原型分支 `prototype/spine-stand` 的 `/prototype/stand?screen=picker`，里面有衣装面板的实现。

**Blocked by:** 14, 18

**Status:** ready-for-agent

- [ ] **入口**：对话页页首、打电话键旁边加一个「换衣装」图标按钮（Lucide `Shirt`），只在角色有 `stand` 时显示。宽屏（≥ 768px，和对话页用同一个断点）打开弹窗，窄屏打开底部面板。通话层里没有这个入口。
- [ ] **列表**：读取衣装清单，按卡片排列，顺序照清单。
  - 每张卡显示缩略图和卡名，下面一个铺满卡片宽度的「私服 / 演出」切换。
  - 只有一套的卡，显示一个灰掉的「只有一套」。
  - 所有卡片一样高；标题固定占两行，超出截断，悬停时显示全名。
- [ ] **预览**：弹窗左侧、底部面板上方，放一张会动的全身大预览，配卡名、「私服/演出 · 稀有度 · 正在穿」和「穿这套」按钮。
  - 点卡片只是预览，点「穿这套」才保存。
  - 手机上预览随列表一起滚动。
  - 预览同样遵守减少动态效果。
  - 换预览时释放旧衣装的素材：从 `AssetManager` 里连条目一起删掉，旧贴图也从 `ManagedWebGLRenderingContext.restorables` 里移除。通话中的立绘引擎换衣装时，也照这样做。
- [ ] **保存**：按角色各存一套，存在本机，照现有通话偏好设置的写法，防御性地读写。读到坏数据，或者清单里已经没有这套衣装时，用默认衣装。
- [ ] **退回顺序**：打电话时，先加载选中的衣装，不行就换默认衣装，再不行就只显示背景图。加载失败时，不清掉本机保存的选择。
- [ ] **预取**：进入对话页后，浏览器空闲时，把 runtime 和当前衣装预取进缓存；开了省流量（`navigator.connection.saveData`）就不预取，等按下打电话键再下载。
- [ ] 遵守 AGENTS.md 的 Astryx 规则：卡片列表、弹窗、底部面板都用对应的 Astryx 组件。
- [ ] **测试**：
  - 本机保存（照通话偏好设置的测试）：按角色分开存；坏数据时用默认衣装；清单里没有这套时用默认衣装。
  - 退回顺序和预取的判断逻辑，如果写成了纯函数，也要测。
- [ ] **人工验证**：宽屏弹窗和窄屏底部面板都走一遍：换一套、打电话、确认她穿着新衣装；刷新后还记得；把选中的那套从存储桶删掉后，退回默认衣装。在 Comments 里附截图。
- [ ] `npm test`、`npm run typecheck` 全部通过。
