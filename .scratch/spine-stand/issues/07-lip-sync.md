# 07: 拍板：口型跟什么走

Type: grilling
Status: resolved
Blocked by: 01, 04

## Question

口型由角色语音的实时音量驱动，还是只要在播放就循环张合；前端能不能拿到 pipecat 播放的音频做分析；开口时间怎么和 TTS 播放对齐；「只看文字」时怎么处理（不动嘴，还是字幕出现时短暂动一下）；被打断时怎么收。

## Context（2026-09-30 补充）

阻塞已经解除。调研和原型已经回答了大半：页游的口型不看音量，说话时循环 `lip_<情绪>`，停嘴时把说话口型冻结在第 0 帧（`animationEnd = 0`，见「原型：通话层里的立绘」）。这张剩下要定的：「开始说话」「停止说话」由什么事件触发（pipecat 的 bot 开始/停止说话事件，还是按每段音频的播放），「只看文字」时怎么处理，被打断时怎么收。

## Answer

2026-09-30 与用户 grilling 定下：

1. **嘴的开关**：pipecat 的「开始说话」事件（`BotStartedSpeaking`，前端经 RTVI 收到）一到，就循环 `lip_<当前情绪>`；「停止说话」事件一到，就冻结在第 0 帧（闭嘴，`animationEnd = 0`，见「原型：通话层里的立绘」）。段与段之间停顿得够久时，嘴自然合上。不按音量驱动：和页游一致，立绘的口型动画也只有张合循环和闭嘴两种。
2. **情绪切换的时机**：一段的情绪和点头/摇头，在**这段声音开始播放**时切换，不在字幕出现时，因为字幕是边生成边推的，比声音早。Jev 的结果晚于声音时，这段还在说就到了再换，已经说完就丢掉。前端要知道「现在播到第几段」，由后端在每段开始播放时告诉前端，机制见「调研：pipecat 怎么知道每段语音什么时候开始播放」。
3. **只看文字**：嘴始终闭着；情绪和点头在每段字幕出现时切换（只看文字时，第一句出现就算开口）。
4. **打断**：声音一停，嘴立刻冻结闭上，同时和用户开口时一样看向用户（`eye_front`）；心情保持不变。补充发生在她开口前，立绘上什么都不会发生。
5. **收起通话层**：暂停渲染；轨道状态（心情、是否在说话）照常更新，展开时从当前状态接着画。
