# 04: 气泡、文案和无障碍

**What to build:** 第 5 幕里每个人说的话出现在她头顶：制作人的一句是深蓝气泡，真乃先冒出「思考中…」再说「我记住了」，果穗、冬优子、雾子收到时柱子上冒出「想起 1 条记忆 · 来自真乃」、然后各说一句；最后全景下面是「她们会记住你的事情，然后在所有人之间传开。」读屏器按顺序读得到这些话，页内查找找得到。

包括：
- 文案目录：制作人、四个人的台词（日语原文和中文字幕成对，照 spec「演员和文案」）、思考气泡、「想起 1 条记忆 · 来自{名字}」、最后一句；标题和正文不变。重新生成落地页字体子集。
- 落地页模型：每个气泡和标签的锚点（世界坐标，跟着说话的人的头顶或记忆柱）和不透明度（只在它的节拍里），最后一句的不透明度；竖屏取景保证气泡在画面里。
- DOM 气泡按模型的投影摆：制作人的深蓝底白字；她们的白底，日语原文在上（`lang="ja"`）、中文字幕小一号在下；标签是半透明深色胶囊，左边一个真乃颜色的小方块。
- 无障碍：画布对读屏器隐藏；标题、正文、几句话（按出现顺序）、最后一句一直在无障碍树上；页内查找沿用跟着滚动淡入淡出的文字的机制（查找时藏成 until-found，找到时滚到它显示出来的幕内进度）。

详见 spec「演员和文案」「无障碍和查找」。
