# 03: 一件事传开

**What to build:** 运动档里，第 5 幕讲完整的一件事：天上制作人的手机亮起，一条消息落到真乃头顶，她举手接住，消息变成她颜色的发光方块，收进她身边的记忆柱；镜头拉远，转台转过 90° 接上桥，一份副本沿桥走到果穗、收进她的柱子；两段台阶一级级升起，两份副本跳着传给冬优子和雾子；最后全景里四根柱顶都是真乃颜色的方块，几根光线把它们连起来。往回滚一切倒着走。（气泡和文字是 04 的事。）

包括：
- 落地页模型：节拍（照 spec 里原型的节拍表）；消息的位置和从气泡变成方块的进度；转台转角；每级台阶升起的程度；几份副本的位置和是否可见；每个人收进记忆柱的时刻；每个人的跳动、举手、朝向（收到时一跳一压，真乃接住时微微后仰，传话时转向对方）；连线的不透明度。路线和布景常量（转台、台阶、记忆柱的位置）照原型。
- 3D 层：天上的手机、制作人的消息（深蓝气泡，变成方块）、记忆柱（三层圆盘、一排小灯，收进时闪成真乃的颜色）、转台（把手）、台阶、副本、走过时亮起的桥面、连线。记忆方块、柱灯、桥面、连线一律用真乃的印象色。
- 演员缺一位时，传给她的那一份不出现，其他照常。

详见 spec「落地页模型」「演员和文案」「场景内容」。
