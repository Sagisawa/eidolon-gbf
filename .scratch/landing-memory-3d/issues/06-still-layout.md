# 06: 静止版式和降级

**What to build:** 不播放动画的访客也看得懂第 5 幕：定格档、静态档里，这一幕是一张事先渲染好的终局全景图（四个人、四块真乃颜色的方块、连线），下面是标题、正文，按顺序列出制作人和四个人说的话（原文加字幕）和最后一句。运动档里 3D 画布丢了上下文或建不起来时，也换成这张图，落地页不降档。

包括：
- 维护者脚本：在无头浏览器里用和页面同一套场景代码渲染终局全景，输出一张 WebP；放存储桶 `landing-memory/still.webp`（部署文档、存储桶结构表补上；交给部署者上传，或经同意后用存储桶密钥上传）。
- 静止版式的第 5 幕：不钉住，图加文字；图加载不到时只有文字。静态档不加载任何脚本。
- 运动档：画布丢上下文、建不起来时显示这张图。
- 地址按存储桶地址拼出（后端给，规则同来电卡图；或前端按已有的存储桶地址拼，实现时选和来电卡图一致的那种）。

详见 spec「静止图和静止版式」。

## Comments

- 04 留下的（2026-10-16）：静止版式里第 5 幕已经不钉住、竖着排下来：标题、正文，按顺序的几句话（`Memory.tsx` 的 `.lp-lines`，气泡样子不变，「思考中」不排），最后一句（`landing.css` 里 `html:not([data-lp-layout="motion"]) .lp-act5` 那几段）。06 在这里加静止图，排法可以照图改。
- 运动档里画布丢了上下文、建不起来时，DOM 上的几句话照样按模型摆、淡入淡出（只看模型，不看画布在不在），会浮在没有场景的夜色上。换成静止图时要一起处理：收起这些气泡，或者让它们照静止版式排在图下面。
- 05 留下的（2026-10-16）：渲染静止图时用和页面同一套场景代码，画质按完整档（`qualityOf("full", false)`：有阴影和泛光、粒子全量）。布景里会动的东西（花瓣、上飘的 token、云、石碑和小方块的起伏、拱门里滚的 token）都只看 `render` 的 `time`，随机数是固定种子，给一个固定的 `time` 出图就每次一样。星图上真乃那颗点（`EMBEDDING_STAR`）在终局全景里电脑在右上的天空、竖屏在右边，亮度是模型的 `embedding`，终局是 1。
- 06 做完（2026-10-16）：静止图的地址由后端给，新接口 `GET /api/landing` 的 `memory_still_url`（规则同来电卡图，不查存储桶）。`frontend/scripts/landing-memory-still.mjs` 出图（1920×1200，约 68 KB），已经用 `.env` 的存储桶密钥上传到 `landing-memory/still.webp`。静止版式里图在标题上面，竖屏往右伸到画面边；运动档画布收起时 `.lp-root` 加 `lp-memory-lost`，图摆在画面正中、跟着 `--lp-memory` 淡入淡出，气泡收起（不透明度 0，仍在无障碍树上），标题正文和最后一句照旧。`landing-check.mjs` 已加上这几项，本地构建版上全部通过。
