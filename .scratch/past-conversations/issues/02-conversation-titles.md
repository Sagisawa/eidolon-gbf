# 02: 对话标题：第 3 个回合后由后台模型起一次

**What to build:** 用户和她聊到第 3 个回合（打字和通话都算）以后，这段对话在历史面板里有了一句中文短标题，说的是这几轮聊了什么；标题只起一次，以后不变。用自带后台模型的用户，标题由他自己的模型起。没满 3 个回合、标题没起成、上线前的旧对话，照旧只显示日期和最后一句。她不知道标题，管理者也看不到。见 `../spec.md` Solution 第 7 条和 Implementation Decisions「对话标题」；提示词和上下文的取舍见 `../research.md`。

**Blocked by:** 01（历史对话面板）

**Status:** ready-for-agent

- [ ] 第 3 个回合记下以后，这段对话有了标题；第 2 个回合之后还没有，第 4 个回合之后也不变；通话里的回合也算进 3 个
- [ ] 起标题不让她的回复变慢；记忆功能关着也照样起标题；她在第 3 个回合结束了对话，照样起标题
- [ ] 标题是中文，概括这几轮聊了什么，不是寒暄；不超过 16 字，没有引号、书名号和结尾标点
- [ ] 后台模型出错或返回空的时，这段对话没有标题、以后也不再试，用户看不到任何报错；日志里只有长度，没有内容
- [ ] 用自带后台模型的回合，标题由自带的模型起；自带密钥在这一回合的后台任务都做完之前留在服务器内存里，照旧不落盘（ADR-0017 跟着改）
- [ ] 标题用后台模型那一档思考强度；花费记在后台模型名下；看板和设置里「提炼记忆的 LLM」改叫「后台模型」
- [ ] 标题不出现在她的提示词、记忆、判断模型、看板、运行记录和日志里
- [ ] 历史面板里有标题的行，第一行是标题、右边是日期和标记，第二行是最后一句；没有标题的同 01；DESIGN.md 跟着补上
- [ ] 后端测试（走对外接口，伪造后台模型）覆盖上面所有后端行为，包括喂进去的有对话事件、没有记忆
- [ ] 本地构建版 Playwright 验收（宽屏、手机）：有标题和没标题的行
- [ ] 后端完整测试、前端类型检查和测试、前端纪律检查都通过
