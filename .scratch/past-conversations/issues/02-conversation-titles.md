# 02: 对话标题：第 3 个回合后由后台模型起一次

**What to build:** 一段对话的第 3 个回合记下以后，在后台用这一回合的后台模型（自带的就用自带的）起一句中文短标题，只起一次，以后不改。历史面板里有标题的行，第一行写标题，第二行仍是最后一句；没有标题的照旧。她不知道标题，管理者也看不到。见 `../spec.md` Solution 第 7 条和 Implementation Decisions「对话标题」；提示词和上下文的取舍见 `../research.md`。

**Blocked by:** 01

**Status:** ready-for-agent

### 后端

- [ ] `conversations` 表加可空的 `title`，旧库启动时补列；列表接口每条带 `title`
- [ ] 回合记下以后，这段对话正好有了第 3 个回合（打字、通话都算）而且没有标题，就起一个 detached 的后台任务，不挡回复，不挂在 `memory.write_down` 里面（记忆关着时也要起）；只试这一次
- [ ] 用这一回合的 `TurnLLMs.memory`，部署者的那份在回合结束后继续持有；思考强度沿用后台模型那一档；服务调用记成 `memory_llm`、不挂在回合的运行记录上
- [ ] 自带密钥持有到这一回合的后台任务（记忆、标题）都做完为止，通话同理；改 ADR-0017 和 `own_keys.py` 开头的说明
- [ ] 喂的内容：到第 3 个回合为止的全部记录，用户的话、她的中文字幕（没有才用日语，去掉语气提示）、对话事件各一行，每条截到约 150 字，加她的名字；不喂记忆和人设
- [ ] 提示词（中文）：概括这几轮聊了什么，忽略寒暄，12 字以内，不加引号和标点，只输出标题
- [ ] 后处理：去掉首尾空白、引号、书名号和结尾标点，截到 16 字；空的算没起成。失败只记 warn 日志，只写长度、不写内容
- [ ] 标题不进她的提示词、记忆、判断模型、看板、运行记录和日志

### 前端

- [ ] `Conversation` 类型带 `title`
- [ ] 历史面板的行：有标题时第一行是标题（截断），右边是日期和标记；第二行是最后一句。没有标题时同 01
- [ ] 看板和设置里「提炼记忆的 LLM」的文案改成「后台模型」
- [ ] DESIGN.md 历史面板一节补上有标题的行

### 测试

- [ ] 后端（伪造后台模型）：第 3 个回合后起一次，第 2、第 4 个回合不起；通话里的回合也算；记忆关着也起；后台模型失败或返回空的就没有标题、回复不受影响；后处理去引号和标点、截到 16 字；喂进去的有事件、没有记忆；她下一回合的提示词里没有标题；自带后台模型的回合用的是自带的那个
- [ ] 本地构建版 Playwright（宽屏、手机）：有标题和没标题的行
- [ ] 后端完整测试、前端类型检查和测试、`sh scripts/check-discipline.sh` 都通过
