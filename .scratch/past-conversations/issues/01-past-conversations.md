# 01: 历史对话面板、只读的历史对话和菜单图标

**What to build:** 用户在对话页的「更多」菜单里点「历史对话」，能看到和她的所有对话（当前对话排第一）。点开一段以前的对话，可以像平时一样往上翻，但只能看：页首写着是哪天的对话，底部的卡片能一下回到当前对话；正在打的电话和正在进行的回复都不受影响。礼物一律记进当前对话；当前对话还是空的时候不能再开新对话；更多菜单和对话列表长按菜单的每一项都带图标。见 `../spec.md` 的 Solution 第 1–6、8 条。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 「更多」菜单依次是「新对话」「历史对话」「换衣装」，每一项前面有图标；对话列表的长按菜单里，置顶/取消置顶、隐藏/显示也各有图标
- [ ] 点「历史对话」：宽屏弹出 Dialog，窄屏拉出 Drawer，都用她的颜色；每次打开都是最新的列表，读取时显示加载中
- [ ] 面板里当前对话在第一行，标着「当前」；历史对话按开始时间从新到旧排，空的不列；每行写日期（北京时间）和最后一句（写法同对话列表），被她结束的有标记；只有当前对话时，下面有一句说明
- [ ] 点一段历史对话，地址变成带 `?c=` 的；刷新或在另一台设备打开同一地址，看到的还是这一段；`c` 无效时回到当前对话，地址也换掉
- [ ] 历史对话里：消息区和平时画法一样，但不能打字；页首名字下面写「{日期}的对话」；电话键禁用，提示要回到当前对话；好感度标识、新对话、历史对话、换衣装照常能用
- [ ] 历史对话底部是只读卡「这是你们以前的对话」（她结束的那段另有说明），带「回到当前对话」按钮；按这个按钮、窄屏页首的返回键、浏览器返回，都回到当前对话
- [ ] 通话中打开历史对话，通话条还在，电话不挂；她正在回复时打开历史对话，回去后那条回复在当前对话里
- [ ] 不论从哪段对话跳去礼物页，礼物都记进当前对话；当前对话已结束就记进一段新开的对话。礼物页地址里不再带对话，旧链接里带着也不出错
- [ ] 当前对话一条记录都没有时，「新对话」禁用；有了一条记录就能用
- [ ] DESIGN.md 补上更多菜单、历史面板、历史对话的页首和只读卡、长按菜单的图标，并改掉「从对话页跳来」那一段
- [ ] 后端测试（走对外接口）：她的对话列表每条带最后一句（跳过结束事件，空对话为空）和是否已结束；送礼的落点不论带不带对话都一样
- [ ] 对话状态测试：当前对话为空时不能开新对话
- [ ] 本地构建版 Playwright 验收（宽屏、手机），覆盖上面所有界面上的行为
- [ ] 后端完整测试、前端类型检查和测试、前端纪律检查都通过
