# 历史对话：开了新对话也能翻看以前的对话

Status: ready-for-agent

术语以 `GLOSSARY.md` 为准（新增「当前对话」「历史对话」，「礼物」随之改过）。界面的样子由原型定下：本地分支 `prototype/past-conversations` 里的方案 A（另有 B、C 两种没选，只留作参考）。

## Problem Statement

- 对话页「更多」菜单里有「新对话」，可开了新对话之后，原来那段对话在前端就再也打不开了：页面只打开她最新的那段，对话列表每位角色一行，也只看得到最新那段。数据都还在后端，只是没有入口。她结束了对话以后用户点「开个新对话」，被结束的那段同样再也看不到。
- 「更多」菜单和对话列表的长按菜单只有字没有图标，扫一眼不好认。

## Solution

1. **历史对话入口**：「更多」菜单在「新对话」下面加一项「历史对话」。点开以后，宽屏是居中的 Dialog，窄屏是底部的 Drawer，都用她的颜色。标题「历史对话」，说明「和{角色名}的所有对话，最新的在上面。」。
2. **面板里的行**：列出和她的所有对话，按开始时间排，最新的在上。当前对话排第一行，标「当前」；历史对话里一条记录都没有的不列。每行两行字：
   - 第一行是最后一次往来的日期（北京时间，「10月15日」，不是今年的带上年份）。当前对话标「当前」小胶囊；已结束的标 `EndedIcon` 加「她结束了」。
   - 第二行是最后一句，写法和对话列表的预览一样：她的日语、「你：…」或对话事件的图标加原文，跳过「她结束了对话」这条事件。超出截断。
   - 正在看的那一段铺 `bg-muted`。
   - 只有当前对话这一行时，下面写一句「开了新对话以后，之前的对话会留在这里。」
3. **打开历史对话**：点一行就关掉面板，去看那段对话；点「当前」那一行回到当前对话。
   - 地址是 `/conversation/<角色>?c=<对话 id>`，能刷新也能分享。`c` 是当前对话、不属于她、或者是空对话时，当作没带。
   - 消息区和平时一样画（壁纸、气泡、对话事件、日期条），只读。
   - 页首在她的名字下面加一行 Meta 字号、muted 的「{日期}的对话」。
   - 电话键禁用，提示「回到当前对话才能打电话」。好感度标识、「新对话」「历史对话」「换衣装」照常能用。
   - 输入栏换成只读卡：左边 muted 的 `PastConversationsIcon` 加「这是你们以前的对话」（已结束的写「这是你们以前的对话，她结束了它」），右边 `lg` 的 outline 按钮「回到当前对话」。一行放不下就折行，样子同结束卡。
   - 窄屏页首的返回键、只读卡的按钮、浏览器的返回键，都回到当前对话。
4. **通话和回复不受影响**：通话中、或者她正在回复时，也能打开历史对话。通话像换页一样缩成通话条，继续打；那条回复照常记进当前对话，回去就看得到。
5. **礼物只记进当前对话**：送礼时记进她的当前对话；当前对话已经结束，就记进一段新开的对话。不论从哪段对话跳去礼物页都一样。
6. **空的当前对话不能再开新对话**：当前对话一条记录都没有时，「新对话」禁用，免得堆出一串空对话。
7. **菜单图标**：两个菜单每一项的文字前面加 16px 图标，跟着菜单文字的颜色，不用她的颜色：
   - 新对话 `SquarePen`、历史对话 `History`、换衣装 `Shirt`；
   - 置顶 `Pin`、取消置顶 `PinOff`、在列表中隐藏 `EyeOff`、在列表中显示 `Eye`。

## User Stories

1. 作为用户，我开了新对话以后，想从「更多」菜单的「历史对话」里找到以前和她的对话，这样那些对话不会凭空消失。
2. 作为用户，我想在历史面板里一眼看出每段对话是哪天的、最后聊到哪句，这样我能找到想看的那段。
3. 作为用户，我想在面板里看到哪段是当前对话，点它就回到当前对话。
4. 作为用户，我想看出哪些对话是被她结束的。
5. 作为用户，我点开一段历史对话，想像平时一样往上翻看整段，包括通话里说的话、她挂断电话和送礼的记录。
6. 作为用户，在历史对话里我想清楚地知道这是以前的对话、只能翻看，并且一下就能回到当前对话。
7. 作为用户，在历史对话里我不想不小心拨出电话，或者把话说进以前的对话。
8. 作为用户，用手机看历史对话时，想按左上角的返回键或系统返回回到当前对话，而不是一下退到对话列表。
9. 作为用户，我想刷新页面或者把地址发给自己的另一台设备，还是停在同一段历史对话上。
10. 作为用户，我在打电话时翻看历史对话，不想因此挂断电话。
11. 作为用户，在历史对话里点「送她一件礼物」时，想让礼物记进当前对话，而不是记进以前的对话。
12. 作为用户，我一句话都没说过时，不想因为连点「新对话」堆出一串空对话，也不想在历史面板里看到空对话。
13. 作为用户，我还没开过新对话时点「历史对话」，想看到一句说明，知道这个功能是做什么的。
14. 作为用户，我想在「更多」菜单和对话列表的长按菜单里，靠图标一眼认出每一项。
15. 作为用户，在历史对话里我想照样能换衣装、看好感度，因为这些跟着她，不跟着哪段对话。

## Implementation Decisions

- **列出她的所有对话**：`GET /api/conversations?character_id=` 每条多带两项：
  - `last_message`：形状和 `/api/conversations/latest` 的同名字段一样，同样跳过「她结束了对话」这条事件；对话是空的就是 null。
  - `ended`：她是否结束了这段对话。

  空的历史对话由前端从列表里去掉。最新开的那段永远是第一条，它就是当前对话；后端不新增概念。
- **历史对话不经过 LiveConversation**：外壳里那一个对话实例管着当前对话的回合、通话和记录，不去切换它，否则正在进行的回复和通话会串到别的对话里。历史对话用一个只读的视图，自己按 id 读记录（`GET /api/conversations/{id}/messages`），用 `conversationLog` 的 `loaded` 转成条目，交给现有的消息区去画。对话页照旧向外壳要她的对话，所以通话层、通话条在历史对话里照常工作。
- **地址里的 `c`**：从面板打开历史对话时 `push` 一条浏览历史。「回到当前对话」这样处理：上一条浏览历史就是这一页的当前对话时，退回去；否则（比如直接打开的链接）换成不带 `c` 的地址。`c` 无效时当作没带，并把地址换掉。
- **面板的数据**：每次打开面板时重新读一次列表（不缓存），读的时候显示 Spinner。日期按北京时间写，和抽奖、好感度用同一个时区；最后一句的写法和对话列表复用同一段代码，不另写一份。
- **送礼的落点**：`store.add_gift` 不再接收「从哪段对话来的」。规则是：她最新的对话没结束就记进去，否则新开一段。连带改动：
  - 礼物页地址 `/gifts?to=&conversation=` 去掉 `conversation`，`giftsHref` 只带角色；旧链接里带着也忽略。
  - 送礼请求体去掉 `conversation_id`。
  - DESIGN.md「从对话页跳来」那段跟着改。

  前后端一起部署。
- **「新对话」何时可用**：在现在的条件（对话已打开、没在回复、没在通话）之外，再加一条：当前对话里至少有一条记录。已结束的对话里一定有结束事件，不受影响。这个判断放在 LiveConversation 的快照里。
- **图标**：从 `theme/icons.ts` 用语义别名导出：
  - 新加 `NewConversationIcon`（`SquarePen`）、`PastConversationsIcon`（`History`）、`UnpinIcon`（`PinOff`）、`HideIcon`（`EyeOff`）、`ShowIcon`（`Eye`）；
  - 沿用已有的 `PinIcon` 和 `OutfitIcon`。

  菜单项里 svg 默认就是 16px，不用另写尺寸。
- **前端规矩**：按 `frontend/AGENTS.md` 的 shadcn 纪律写，文案进 `zh.ts`。DESIGN.md 补上这些内容：更多菜单的三项和图标、历史面板、历史对话的页首和只读卡、对话列表长按菜单的图标。

## Testing Decisions

- 只测对外的行为。
- **后端**：通过对外接口测：
  - 列表接口带出 `last_message`（跳过结束事件、空对话为 null）和 `ended`；
  - 送礼一律记进最新且没结束的对话，最新的已结束时新开一段，请求里带不带对话 id 都一样。
  
  先例是 `test_conversation_events.py` 和送礼的那些测试。
- **前端**：
  - `liveConversation.test.ts`：当前对话是空的时 `canStartNew` 为假，有了一条记录后为真；
  - 面板行的纯逻辑（排除空对话、当前对话排第一、日期写法）如果单独抽成函数，就给它写单测；组件不写测试。
- **验收**：按 `docs/agents/local-acceptance.md` 在本地构建版上用 Playwright，宽屏和手机都看：
  - 菜单图标；
  - 打开面板、点开一段历史对话、页首日期和只读卡、电话键禁用；
  - 返回键和浏览器返回回到当前对话；
  - 刷新后还在同一段；
  - 拨出电话（呼叫中）后打开历史对话，通话条还在；
  - 空的当前对话里「新对话」禁用。

## Out of Scope

- 在历史对话里接着聊，或者把一段历史对话设回当前对话。
- 删除、重命名、搜索历史对话。
- 对话列表长按菜单里的「历史对话」入口。
- 清理库里已有的空对话。
- 她记得历史对话的原文（她只通过记忆接上以前的对话，不变）。
- 历史面板分页：一位角色的对话一次全读出来，以后多了再说。
