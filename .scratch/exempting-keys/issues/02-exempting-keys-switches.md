# 02: 免限额密钥开关

**What to build:** 部署者可以选定带哪几项自带密钥的通话不计入限额。`.env` 用 `EIDOLON_EXEMPTING_LLM`、`EIDOLON_EXEMPTING_TTS`、`EIDOLON_EXEMPTING_STT` 设默认值（不填或 `1` 开，`0` 关，其他值和三项全 `0` 都拒绝启动），管理者可以在后台配置「限额」一节用三个开关改，不能全关，从下一个回合、下一次通话起生效。通话带了的服务包含所有打开的项就不计入限额，运行记录标成不计入；文字回合不看开关，带 LLM 就不计入。通话预检、设置页的豁免查询接口给出的结果和实际一致。`/api/account` 返回当前的免限额密钥列表。默认三项全开，和现在的规则一样。部署文档（三种语言）和 `.env.example` 写明这三个变量。

详见 `.scratch/exempting-keys/spec.md`。
