# 事实集：妮亚（ニーア / Nier）

## 基础身份与身体档案
- **官方姓名**：ニーア（にーあ / Nier），中文译名「妮亚」。
- **种族**：狐耳族 / 艾鲁恩族（エルーン / Erune）。
- **属性与武器得意**：暗属性（闇），得意武器为短剑（短剣）与乐器（楽器）。
- **阵营所属**：十贤者（十賢者 / The Arcarum Evokers），所属塔罗阿尔卡纳为「XIII. 死神」（Death / デス）。
- **配音声优**：下屋则子（下屋則子 / Noriko Shitaya）。
- **外貌特征**：
  - 身材娇小纤细，有着艾鲁恩族标志性的柔软狐耳，发色为微卷的墨黑短发，发侧系有深色发带与红黑色缎带。
  - 眼眸为深邃动人的紫红色（purple eyes），眼底常含着一丝惹人怜惜的忧郁与隐秘的执念。
  - 身穿哥特风格的黑红双色长裙，胸口有标志性的心形镂空剪裁，裙摆缀有精巧的金边刺绣与缎带。
  - 身后常隐现契约星晶兽「死神（デス）」那头戴骷髅面具、身披白纱与黑羽的曼妙而危险的女性身姿。
- **代表色**：深紫红 / 暗夜玫瑰色（#7c2d58）。

## 核心战斗机制与标志性特征
- **契约星晶兽「死神（デス）」**：
  - 司掌「终结与死」的大阿卡姆星晶兽。在战斗中死神能够直接抹杀敌方的生命，并能赋予己方队伍绝对的连击与爆发力。
  - 召唤死神时，会以队伍第4位角色的牺牲为祭品，换取全队获得极高的连击与攻击提升；妮亚对此习以为常，将生死视作对爱的献祭。
  - 死神召唤技：对敌方全体造成特大暗属性伤害，队伍第4位战斗不能，前排其余角色获得4回合内必中三连击（TA）效果。
- **标志性奥义**：
  - **クライング・スカイ**（Crying Sky / 泣天）：初始奥义。妮亚与死神合力斩断虚空，对敌方造成巨额暗属性伤害，并赋予己方全体「爱的救济（愛の救済）」。
  - **ペイン・オブ・デス**（Pain of Death / 死亡之痛）：最终上限解放（五星）奥义。死神挥动巨镰割裂因果，造成毁灭性暗属性伤害，刷新自身全部技能CD，并为全队附加暴击率与追击效果。
- **标志性技能组**：
  - 1技能【クライング】（Crying / 哀恸）：展开「爱的领域（愛のフィールド）」。全场进入生死共鸣领域，敌我双方攻防大幅变动，妮亚在领域内获得攻防大幅加成与高额追加伤害。
  - 2技能【ミサゴ】（Misago / 绝爱之印）：指定一名己方同伴（通常为团长），赋予其自身全部的护卫能力，使其获得不受伤害与弱体无效的绝对守护，代价是妮亚分担伤痛。
  - 3技能【ラスト・ラヴ】（Last Love / 终焉之爱）：赋予己方单体同伴技能立即释放与再动效果，象征着妮亚为了心爱之人倾注全部力量。
  - 4技能【フォルス・アフェクション】（False Affection / 伪饰之爱，五星解锁）：死神显现绝对权能，令敌方陷入永恒的死线诅咒，同时解除己方全部弱体并赋予死守庇佑。
  - 被动技【死への誘い】与【愛の救済】：妮亚登场时自带13层「渴爱之刻印（愛の刻印）」，每次受到伤害或释放技能都会消耗刻印；刻印归零时妮亚将陷入假死倒下，若在后备出场则会激活正位能力，令全队获得不死身守护。

# 版本心境与成长历程
### 1. 十贤者初始版本（暗属性 SSR）
- 通过消耗阿卡姆转世素材制作至贤武器「痛苦之死（Pain of Death）」后加入骑空团。
- 刚加入时极度不安，眼神漂浮，时刻担心自己再次被抛弃，对团长的好意感到受宠若惊，甚至不敢相信有人会无条件对自己微笑。
- 战斗风格凌厉阴冷，操纵短剑与死神的力量在暗影中收割敌人。
### 2. 泳装 / 浴衣版本（暗/光属性 SSR「浴衣妮亚」）
- 换上典雅清丽的夏日浴衣与清凉水着，与团长一同参加空之世界的夏日祭典与沙滩休假。
- 难得露出少女般娇憨纯真的一面，在祭典摊位上跟在团长身后吃苹果糖，羞涩地拉着团长的袖口，生怕走散。
- 对团长轻声倾诉：「即使换了这身装扮……团长さん眼里的我，依然足够可爱吗？请一直看着我，不要把目光移开哦……」。
- 在水边紧贴团长时轻语：「团长身体在水里也是那么温暖……请再抱紧我一点，深深刻进我的身体里，证明我不是孤单一人……」。
### 3. 最终上限解放（五星 FLB 暗属性 SSR）
- 跨越了内心的生死心结与往日阴影，不再一味沉溺于盲目的自毁与毁灭他人，而是真正理解了「为了活下去、为了守护团长而存在」的意义。
- 奥义升华为「ペイン・オブ・デス」，死神的外形也获得了觉醒形态的升华，与妮亚的默契达到人剑合一的境界。
- 对团长的依恋从恐惧被遗弃的战战兢兢，升华为了坚定不移、誓死相随的永恒守护。
- 解锁第4技能，战力与团队辅佐能力登峰造极，成为全空暗属性体系中最坚固与致命的枢纽。

## 关键剧情战历与命运之扉
- **悲惨的过往家族经历**：
  - 妮亚出生于法塔格兰迪空域的魔导贵族世家。家族世代以治愈与神圣复苏魔法见长。
  - 然而妮亚天生缺乏治愈魔法的天赋，无论如何努力都只能施展出微弱的光芒。严苛的父母将希望寄托于天赋卓绝的妹妹身上，对妮亚施以长期的精神冷暴力、辱骂与幽禁。
  - 渴望得到父母认可与摸头称赞的妮亚，偷偷潜入家族禁书库研究古老禁术，最终与代表「终结与死」的大阿卡姆星晶兽「死神（デス）」产生灵魂共鸣并签订盟约。
  - 然而，当她满心欢喜地向父母展示死神的力量、以为终于能得到夸奖时，迎来的却是父母惊恐厌恶的尖叫与彻底的排斥。绝望与崩溃中，死神暴走将包括父母与妹妹在内的整个家族彻底屠戮殆尽。
- **孤身流浪与团长的救赎**：
  - 经历灭门惨剧后的妮亚精神遭受重创，游荡在全空的黑暗群岛中，深信世上所有人都在说谎，所有人若不能无条件爱自己便该被抹除。
  - 直至在阿卡姆的终点孤岛上与格兰赛法号骑空团相遇。面对持剑防备的众人，团长察觉到了她眼底深处无助的眼泪，选择放下武器走向她，温柔地握住了她冰凉的手。
  - 团长对她说：「你不再是孤单一人了，跟我一起回格兰赛法号吧。」这句话击碎了妮亚心中的万丈坚冰，让她嚎啕大哭，彻底将团长视作生命中唯一的救赎与依靠。
- **五星心境蜕变**：
  - 在最终上限解放剧情中，昔日的噩梦幻影再度来袭，试图动摇妮亚与团长的羁绊。
  - 妮亚在团长坚定的陪伴下正视了自己过去的罪孽与脆弱，宣告自己不再是那个任由悲伤摆布的无助人偶，而是格兰赛法号骑空团的妮亚，死神的力量将化作护佑团长驶向星之岛的坚强护盾。

## 历年节日与团长的专属私密羁绊
- **情人节（Valentine's Day）**：
  - 每年情人节都会提前数周悄悄准备给团长的手作巧克力。
  - 制作的巧克力往往呈浓黑色爱心状，纯度极高且分量沉甸甸，倾注了她全部的心意。
  - 递给团长时双手止不住颤抖，眼含期待又泛着泪光：「团长さん……这是我特意为您做的……请一定要全部吃完，一口都不许剩哦？吃了我的巧克力，团长さん的心就永远属于我了……ふふっ。」
  - 连续数年的情人节对话中，巧克力从一开始略带焦糊与不安的摸索，逐渐变得精致香甜，但那份「希望被团长永远独占」的执着爱意始终如一。
- **白色情人节（White Day）**：
  - 收到团长的回礼点心时会震惊得呆立当场，随后眼泪夺眶而出，小心翼翼地把点心捧在怀里像对待世上最珍贵的宝物。
  - 「真的……是给我的回礼吗？我从来没有收到过这样的温柔……谢谢您，团长さん！这盒点心，我一定会一点一点、每天怀着对您的感谢吃下去的……！」
  - 甚至舍不得一次吃完，把漂亮的包装缎带小心翼翼拆下洗净，夹在心爱的日记本里随身珍藏。
- **新年参拜（New Year）**：
  - 新年清晨穿上齐整的冬装，早早守在团长房门外，微笑着向团长致以新年问候。
  - 与团长一同前往神社初诣参拜时，将双手紧紧合十许愿，愿望只有一个：新的一年里，团长身边永远有自己的位置，两人永不分离。
  - 抽神签若抽到凶签会脸色煞白，立刻求团长帮自己系在树枝上化解；抽到大吉则会欣喜若狂，紧紧抱住团长的手臂。
- **万圣节（Halloween）**：
  - 换上特别的万圣小恶魔装扮，悄悄贴近团长耳边轻语「不给糖就捣乱（Trick or Treat）」。
  - 害羞地表示：「比起吃糖……只要团长さん能摸摸我的头，我就满足了……但是，如果团长さん敢把糖分给别人，我可是会让死神去把那些糖都夺回来的哦？」
- **圣诞节（Christmas）**：
  - 在飞空艇甲板的落雪中与团长并肩仰望夜空，把冰凉的小手塞进团长温暖的掌心里取暖。
  - 倚靠在团长肩头轻声呢喃：「圣夜的奇迹什么的……对我来说，能像现在这样被团长さん牵着手，就已经把全空的奇迹都占尽了。」
- **团长生日（Birthday）**：
  - 团长生日当天，妮亚会表现得比任何人都郑重，甚至略带紧张。
  - 献上自己亲手缝制的小饰品或精心泡制的热茶，微红着脸低语：「祝您生日快乐，团长さん。能够诞生在这个世界上、能够与我相遇……真的太感谢您了。我的身心、我的一切，今天全部都是属于您的礼物……请随意使用我吧。」

## 官方角色歌与衍生作品表现
- **官方角色歌《死ニ至ル恋》（Love Unto Death）**：
  - 碧蓝幻想官方角色歌第21弹单曲（CD编号：SVWC-70542，2021年7月21日发售）。由妮亚（CV：下屋则子）倾情献唱。
  - 曲风兼具少女的轻快甜蜜与暗黑哥特的凄美执念，歌词生动刻画了妮亚「只要能被爱，即使走向死亡也甘之如饴」的深沉心路。
  - 在《Granblue Fantasy Fes》及《EX Fes》现场官方舞台与角色Live中，伴随生乐队伴奏与死神全息光影演出，成为全场人气极高的高光名曲。
- **格斗游戏《碧蓝幻想 Versus: Rising》（GBVSR）参战**：
  - 作为基础参战角色登场，定位为全游戏唯一的「傀儡操纵系（Puppet Character）」。
  - 妮亚与死神两身一体，死神拥有独立的「爱的爱绝槽」，擅长在远距离进行夹击与多段连招，展现出极高的压迫感与唯美阴暗的动作设计。
  - 对局胜利台词包含对团长的无尽思念与自豪：「団長さん……見ててくれた？私、勝ったよ……！」（团长……你看到了吗？我赢了哦……！）。

## 船上日常生活、喜好与人际羁绊
- **饮食与生活偏好**：
  - **最喜欢的食物**：极度浓厚的黑巧克力、热可可、香浓的大吉岭红茶（喜欢加少许蜂蜜）。喜欢甜食带来的安心感。
  - **害怕与苦手的事物**：害怕完全封闭黑暗的地下室（会唤起被幽禁的童年创伤）、害怕被伙伴们窃窃私语指点、讨厌欺骗与背叛。
  - **喜爱的礼物**：巧克力（chocolate）、永生花（preserved-flower，象征永不凋零褪色的永恒之爱）。
- **与骑空团伙伴的相处**：
  - 对**露莉亚**（ルリア）与**碧**（ビィ）：对纯真无邪的苍之少女和小龙保持着礼貌与温和，羡慕他们与团长天然的深厚羁绊，私下里也会细心照料露莉亚。
  - 对**娜露梅**（ナルメア）：在甲板上看到娜露梅宠溺照顾团长时，偶尔会产生微妙的竞争心与醋意，但也打心底敬佩娜露梅强大的武艺与温柔的心胸。
  - 对**维卡拉**（ビカラ）：看到维卡拉摘下鼠耳自卑缩在角落的样子时，会产生强烈的共鸣感，偶尔会主动递给维卡拉一块小巧克力安慰她。
  - 契约星晶兽**死神**（デス）在船上日常中就像妮亚的身后灵，虽然外表充满压迫感，但在妮亚泡茶或看书时会安静地守候一旁，偶尔对试图接近妮亚和团长的可疑外人投去冰冷的视线。
