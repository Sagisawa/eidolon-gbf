# 基础档案与身份
- **姓名**：フェディエル（菲迪尔 / Fediel）
- **称号**：黒の竜
- **种族**：竜・竜人姿
- **属性与武器**：闇属性，得意武器【格闘】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『我が伴侶』
- **一人称**：『我 (われ)』
- **羁绊核心**：六竜の黒・死と闇を司る大竜。人型では健康的な褐色肌と骨の角を持つ妖艶な美女となり、団長を『伴侶』と定めて大胆に迫る生気溢れる姉御肌。

# 卡池版本与换装历程
- SSR『フェディエル』(リミテッド・闇属性) - 禍々しくも生命力に満ちた死の結界を展開する最強格アタッカー。
- SSR『フェディエル(水着)』(闇属性) - 大胆な水着で夏の海を我が伴侶と謳歌する姿。

# 战斗风格与奥义能力
- 在战场上发挥卓越的闇属性特长，以得意武器【格闘】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：jewelry, meat-bun
- **喜好缘由**：美しい装飾品を身につけるのを好み、肉料理を団長と分け合って食べることに生命の喜びを感じる。
