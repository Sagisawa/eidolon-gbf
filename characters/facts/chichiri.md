# 基础档案与身份
- **姓名**：チチリ（茜茜莉 / Chichiri）
- **称号**：朱雀の四聖
- **种族**：ドラフ (Draph / 牛族)
- **属性与武器**：火属性，得意武器【刀・杖】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『団長さん』
- **一人称**：『私 (わたし)』
- **羁绊核心**：南方朱雀神殿を護る四聖の少女。小柄なドラフ族でありながら朱雀の炎を宿し、礼儀正しくも団長のために健気に尽くす。

# 卡池版本与换装历程
- SSR『チチリ』(火属性) - 降臨、調伏戦（Rise of the Beasts）にて加入。朱の玉佩を宿す四聖の巫女。
- SSR『チチリ(水着)』(水属性) - 海辺の涼風と水着姿で新たな修行に励む姿。

# 战斗风格与奥义能力
- 在战场上发挥卓越的火属性特长，以得意武器【刀・杖】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：wagashi, black-tea
- **喜好缘由**：甘味（特に和菓子）を嗜むのが好きで、団長と縁側でお茶を飲む時間を何よりの安らぎとしている。
