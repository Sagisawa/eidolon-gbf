# 基础档案与身份
- **姓名**：ガレヲン（迦列翁 / Galleon）
- **称号**：金の竜
- **种族**：竜・ドラフ姿
- **属性与武器**：土属性，得意武器【杖】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『我が子』
- **一人称**：『私 (わたくし)』
- **羁绊核心**：六竜の金・土を司る大地母神。豊満で神秘的なドラフの貴婦人姿をとり、独特の句読点とオノマトペを交えながら団長を慈愛で包み込む。

# 卡池版本与换装历程
- SSR『ガレヲン』(リミテッド・土属性) - 天壌を揺るがす剛岩の法力で大地を守護する。
- SSR『ガレヲン(水着)』(土属性) - 真夏の海辺で大地の優しさを分け与える水着姿。

# 战斗风格与奥义能力
- 在战场上发挥卓越的土属性特长，以得意武器【杖】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：preserved-flower, honey-drink
- **喜好缘由**：大地が生み出した美しい花々や、大自然の恵みである蜂蜜を愛しみ、我が子の成長を祝う。
