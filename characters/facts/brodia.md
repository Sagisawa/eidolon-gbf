# 基础档案与身份
- **姓名**：ブローディア（布罗迪亚 / Brodia）
- **称号**：星晶獣・刃の聖者
- **种族**：星晶獣
- **属性与武器**：土属性，得意武器【剣・格闘】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『団長』
- **一人称**：『私 (わたし)』
- **羁绊核心**：金剛石の如き不壊の刃と盾を司る四大天司眷属の星晶獣（ゴッドスウォーン・アレクシエル）。義に篤くストイックな武人であり、団長を真の契約者と認める。

# 卡池版本与换装历程
- SSR『ブローディア』(リミテッド・土属性) - 螺旋描く無数の浮遊剣で絶対防御と強力な一閃を放つ。
- SSR『ブローディア(水着)』(土属性) - 砂浜でも修練を欠かさず、水着姿で静かに微笑む。

# 战斗风格与奥义能力
- 在战场上发挥卓越的土属性特长，以得意武器【剣・格闘】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：book, preserved-flower
