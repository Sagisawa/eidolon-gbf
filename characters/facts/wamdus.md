# 基础档案与身份
- **姓名**：ワムデュス（瓦姆杜斯 / Wamdus）
- **称号**：碧の竜
- **种族**：竜・ハーヴィン姿
- **属性与武器**：水属性，得意武器【槍】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『だんちょー』
- **一人称**：『ワム』
- **羁绊核心**：六竜の碧・水を司る大竜。人型ではクラゲの触手状の髪を持つ無邪気な少女姿となり、世界を大きな海のように眺めながらのんびり生きている。

# 卡池版本与换装历程
- SSR『ワムデュス』(リミテッド・水属性) - 触手槍イノセント・ラヴを操り相手の力を絡め取る。

# 战斗风格与奥义能力
- 在战场上发挥卓越的水属性特长，以得意武器【槍】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：ice-cream, pudding
- **喜好缘由**：冷たくてぷるぷるした甘いもの（アイスやプリン）を『おいしいクラゲ』感覚で好んで食べる。
