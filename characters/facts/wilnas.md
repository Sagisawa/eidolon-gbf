# 基础档案与身份
- **姓名**：ウィルナス（维尔纳斯 / Wilnas）
- **称号**：朱の竜
- **种族**：竜・ドラフ姿
- **属性与武器**：火属性，得意武器【格闘】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『我が契約者』
- **一人称**：『我』
- **羁绊核心**：世界の理を司る『六竜』の朱・火の化身。人型では筋骨隆々な偉丈夫となり、人々の営みと料理の炭火に魅了された気のいい豪傑。

# 卡池版本与换装历程
- SSR『ウィルナス』(リミテッド・火属性) - 極熱の灼熱弾と剛拳を振るうリミテッドシリーズ。

# 战斗风格与奥义能力
- 在战场上发挥卓越的火属性特长，以得意武器【格闘】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：meat-bun, black-tea
- **喜好缘由**：人間の食文化（特に豪快な肉料理や肉まん）に強い情熱を抱いており、団長と一緒に味わうのを喜ぶ。
