# 基础档案与身份
- **姓名**：アミ（阿蜜 / Ami）
- **称号**：青竜の四聖
- **种族**：エルーン (Erune / 狐耳族)
- **属性与武器**：風属性，得意武器【銃 (ボウガン)】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『団長さん』
- **一人称**：『アミ』
- **羁绊核心**：東方青竜神殿を護る青帝の四聖。一族の過酷な思惑から逃れ、グランサイファーに居場所を見出した笑顔の絶えない心優しい少女。

# 卡池版本与换装历程
- SSR『アミ』(風属性) - 降臨、調伏戦にて加入。ペリドット・クロスボウを手に嵐の矢を放つ。

# 战斗风格与奥义能力
- 在战场上发挥卓越的風属性特长，以得意武器【銃 (ボウガン)】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：pudding, honey-drink
- **喜好缘由**：甘いプリンや温かい蜂蜜ドリンクが大好きで、団長からもらうと耳としっぽを弾ませて喜ぶ。
