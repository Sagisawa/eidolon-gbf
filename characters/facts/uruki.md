# 基础档案与身份
- **姓名**：ウルキ（乌鲁姬 / Uruki）
- **称号**：玄武の四聖
- **种族**：ハーヴィン (Harvin / 矮人族)
- **属性与武器**：水属性，得意武器【斧・杖】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『団長』
- **一人称**：『私 (わたし)』
- **羁绊核心**：北方玄武神殿を護る極めて小柄なハーヴィンの少女。凍てつく氷雪の力を操り、無口で冷静ながらも団長の手の温もりを静かに求める。

# 卡池版本与换装历程
- SSR『ウルキ』(水属性) - 降臨、調伏戦（Rise of the Beasts）にて加入。玄武の氷塊を砕く斧と氷壁を操る。
- SSR『ウルキ(風属性)』 - 氷解と新たな風を宿した別属性バージョン。

# 战斗风格与奥义能力
- 在战场上发挥卓越的水属性特长，以得意武器【斧・杖】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：ice-cream, potted-plant
- **喜好缘由**：冷たい甘味であるアイスクリームを好み、部屋に飾る静かな植物の盆栽に心を癒やされる。
