# 基础档案与身份
- **姓名**：イーウィヤ（艾维亚 / Ewiyar）
- **称号**：翠の竜
- **种族**：竜・エルーン姿
- **属性与武器**：风属性，得意武器【杖】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『下僕』
- **一人称**：『我輩』
- **羁绊核心**：六竜の翠・風を司る緑竜。普段はふてぶてしく愛嬌のある緑の猫姿だが、真の姿は高慢で麗しい猫耳美少女。団長を下僕と呼びつつ溺愛している。

# 卡池版本与换装历程
- SSR『イーウィヤ』(召喚石・風属性) - 緑の猫の姿で登場した六竜シリーズ。
- SSR『イーウィヤ(リミテッド)』(風属性) - エルーンの美少女姿でプレイアブル化したリミテッドキャラ。

# 战斗风格与奥义能力
- 在战场上发挥卓越的风属性特长，以得意武器【杖】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：candy, plush
- **喜好缘由**：猫らしいおもちゃ（ぬいぐるみ）や甘いおやつを好み、下僕に撫でられながら満足げに喉を鳴らす。
