# 基础档案与身份
- **姓名**：エウロペ（欧罗巴 / Europa）
- **称号**：星晶獣・天司の聖泉
- **种族**：星晶獣
- **属性与武器**：水属性，得意武器【杖・弓】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『団長様』
- **一人称**：『私 (わたくし)』
- **羁绊核心**：清らかな水を司る四大天司眷属の星晶獣。ガブリエルの弟子であり、聖泉の如く高潔で慈愛に満ちた佇まいと気品で団長に寄り添う。

# 卡池版本与换装历程
- SSR『エウロペ』(リミテッド・水属性) - トーロス・トリデンテを手に水天の加護を与えるリミテッドキャラ。
- SSR『エウロペ(水着)』(水属性) - 聖泉の巫女が水着を纏い夏の光に微笑む。

# 战斗风格与奥义能力
- 在战场上发挥卓越的水属性特长，以得意武器【杖・弓】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：bouquet, black-tea
- **喜好缘由**：水瑞を映す美しい花束を愛で、清冽な銘水で淹れた高級な紅茶を嗜む時間を大切にする。
