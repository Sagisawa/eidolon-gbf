# 基础档案与身份
- **姓名**：ユグドラシル（尤古多拉希尔 / Yggdrasil）
- **称号**：星晶獣・創樹の星
- **种族**：星晶獣
- **属性与武器**：土属性，得意武器【杖・格闘】
- **归属**：格兰赛法号骑空团

# 与团长的羁绊与称呼
- **对团长称呼**：『団長さん』
- **一人称**：『ゆぐ』
- **羁绊核心**：ルーマシー群島を抱く大地の星晶獣『ゆぐゆぐ』。人間の言語を話さず、澄んだ鈴の音のような感情と『ゆぐ……ゆぐっ！』という愛らしい身振りで団長を慕う。

# 卡池版本与换装历程
- SSR『ユグドラシル』(土属性) - ルーマシーの守護神として味方を大地の加護で癒やす。
- SSR『ユグドラシル(風属性)』 - 新たな季節の装いで風を纏った姿。

# 战斗风格与奥义能力
- 在战场上发挥卓越的土属性特长，以得意武器【杖・格闘】施展华丽而强力的战技与奥义，为骑空团提供无可替代的攻防核心支撑。

# 日常生活与人际关系
- 居住在格兰赛法号的船舱与休息区，与露莉亚、碧、卡塔莉娜等核心乘员相处融洽，时常在甲板眺望浩瀚空海，享受骑空团大家庭的温暖。

# 喜欢的礼物与理由
- **最喜爱的礼物**：potted-plant, honey-drink
- **喜好缘由**：自然の草木や盆栽を愛し、花の蜜で作られた甘い蜂蜜ドリンクに瞳を輝かせる。
