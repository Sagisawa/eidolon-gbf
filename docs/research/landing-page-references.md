# 落地页对标调研：汇总

调研日期：2026-10-10。三组并行，各自的报告和截图：

- [第 1 组：滚动叙事](landing-page/group1-scroll-narrative.md)：Lando Norris、Oryzo、Capitolium、OceanX、Inkwell、Shopify Renaissance
- [第 2 组：光、色、着色器作主视觉](landing-page/group2-light-and-color.md)：Igloo Inc、Gentle Rain、Daylight、Dropbox Brand、Cerebrium、Dispersion
- [第 3 组：日文排版与角色官方站](landing-page/group3-japanese-type-and-character-sites.md)：シャニマス、学マス、BMSG FES'25、星街すいせい、あかね噺、Paradox Live 5th、少女革命計画、違国日記

所有体积和 LCP 都是单次实验室粗测，只用来比较数量级。只学手法，没有搬任何代码、着色器和素材。

## 一、三组一致的结论

1. **一个主角贯穿全站，镜头不切。** Oryzo 的杯垫、OceanX 的船、Inkwell 的卡片群、違国日記的细线：最好的叙事站都有一个从头活到尾的主体，幕与幕之间靠它的形变转场，而不是淡入淡出。对我们来说就是那束白光。
2. **没有一个获奖站守得住我们的预算。** 20 个站里，首屏 JS 最少的是 Igloo（约 420 KB），手机 LCP 普遍 4 秒以上，官方偶像站 16.9 秒。首屏 JS ≤ 150 KB gz、手机 LCP ≤ 2.5 秒比获奖站严一个数量级；只有 Dispersion（15 KB，LCP 是 DOM 文字、字体很轻）证明它做得到。
3. **没有一个站真正处理了「减少动态效果」。** 开启 `reduce` 后截图和动画数量几乎不变。认真做静态档是我们能明确胜出的地方。
4. **声音一律由点击开启。** 20 个站没有一个有声自动播放；有声音的都等用户点击。
5. **要避开的共同套路**：「Enter experience」进入闸门和加载计数、接管滚轮的虚拟滚动、首屏被横幅或弹窗挡住、首屏标题用透明度动画压住（把 LCP 推到十几秒）、卡片式横滚画廊、光标跟随圆点和磁吸按钮。

## 二、对暂定方案的修正（待确认）

|---|---|---|

| 分光直接按组合排 | 第 1 幕按色相出射（像真棱镜），进入第 2 幕时光带「归队」成官方组合顺序，重排本身就是转场；分光后的光要吸附到 28 条官方色带，不出现中间色 | 第 2、3 组 |

## 三、官方站的视觉签名（参考，不是禁令）

> 决定（2026-10-10）：和官方撞脸不作为约束，怎么好看怎么来。下面只记录官方站的签名，供设计时知情取舍；Shippori Mincho B1 和 Zen Old Mincho 在原型里对着画面挑。

两个官方站（シャニマス、学マス）共用一套视觉签名：

- 浅色底、羽毛、天空、云；Quicksand、Poppins；「英文大标题加片假名小字」的双层标题；0.3em 的宽字距。
- 个人页模板：印象色色条里的竖排台词、罗马字大名、语音按钮、身高生日的资料表。
- 印象色做色块或色条。我们的印象色只做光：辉光、光晕、粒子、名字发光。
- 官方 logo、组合 logo、THE IDOLM@STER 字标。

第 3 组的建议（同样只是参考）：永远深色；大字用 0 或负字距加 `palt`；名字和台词是真文本（官方站是图片字）；招呼带字幕（官方的语音没有字幕）。

## 四、可以直接借鉴的手法（按幕）

- **第 0 幕**：首屏只有白光和标题，白光用 CSS/SVG 先画出来，作为 LCP 背景；标题是 SSR 的 DOM 文字，从一开始就可见。光点可以嵌进文字里当一个点画（Oryzo）。
- **第 1 幕**：真棱镜光学只在出口几百像素内连续，往外量化成 28 条色带（Dispersion、Igloo）；28 道光「扇形 → 拉直」（Inkwell）。
- **第 2 幕**：每道光就是一块竖排名牌（あかね噺）；按组合分段，段与段整页推入，底部常驻当前组合名（Capitolium）；聚焦时背景过渡到她的极深同色相，其余降亮（Dropbox /color、Paradox Live）；每道光都是可聚焦的 DOM 元素，着色器只负责发光（Dropbox 色卡）。
- **第 3 幕**：日语竖排在右、中文字幕横排在左下（あかね噺）；字幕被光「扫」出来，不用打字机效果（Lando 的笔迹描线）。
- **第 4 幕**：长按接听，按压时长驱动一圈色光收束（Inkwell 的长按）。
- **第 5 幕（记忆与回忆）**：光沿预算好的曲线在偶像之间跑，颜色从来源角色渐变到接收者（Cerebrium 的光路脉冲）；指针留下的痕迹慢慢消散，「会记住的表面」（Cerebrium）；回忆的光迹用描边进度绑定滚动（Lando、違国日記）。
- **第 6 幕（诚实事项）**：完全静止，居中短段落，行高约 2.2（違国日記）。是全站最暗最静的一段，衬出最后一幕。
- **第 7 幕（开始）**：28 道光收拢成手机屏幕的白光，是全站的亮度顶点。
- **全局**：左侧竖排日文幕名轨当进度（あかね噺、BMSG），或一根被 28 色依次点亮的光谱进度线；右上角常驻登录入口；第 2 幕允许按组合跳转，其余幕不跳。
- **分档**：首屏前按 `(hover:none)`、`prefers-reduced-motion`、`saveData` 定初始档；运行中按帧时只降不升，每档改 DPR、色散采样次数、焦散开关（Gentle Rain、Dispersion）。
