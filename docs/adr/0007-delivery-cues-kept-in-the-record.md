# 语气提示留在对话记录里，但不展示

角色回复的日语里带着给 Fish Audio 看的语气提示（例如 `[shyly]`），存进对话记录时原样保留，只在展示和送去记忆提炼时去掉；因此库里的 `ja` 和界面上看到的日语并不一致，这是有意的。之所以不在存库前就去掉，是因为对话历史会原样喂回扮演角色的模型：历史里看不到自己标过语气提示，模型往往越标越少，最后就不标了。这是 ADR-0001 的延伸：日语台词决定角色像不像本人，语气提示决定这句台词念出来有没有起伏。

## Considered Options

- **存库前去掉**：记录干净、所见即所存，但模型会渐渐不再标语气提示。
- **保留并作为舞台提示展示给用户**：用户能看到角色的情绪，但日语原文不再是干净的台词，只看文字时也会显得啰嗦。
