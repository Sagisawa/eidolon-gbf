# 向量化服务在部署时二选一：硅基流动 Qwen3-Embedding 或 Google Gemini Embedding 2

部署时用 `EMBEDDING_PROVIDER` 在两者之间选一个，剧情库、角色资料和记忆都用它向量化；重排不跟着换，始终在硅基流动。库里任何时候只保留当前模型的向量，换服务、换模型或换维度之后运行 `eidolon reembed`，用库里已有的原文重新向量化，不需要重新下载或导入剧情。存储用的模型标识带上维度（如 `gemini-embedding-2@1536`），所以改维度等同于换模型，同一标识下不会混入不同长度的向量。Gemini 走 Google 原生的 `batchEmbedContents`，因为它的每条文本单独成向量是有文档保证的。

我们允许使用 Gemini 的免费层，尽管免费层的内容会被 Google 用于改进产品，而送去向量化的包括没有许可证的剧情库（ADR-0003）和用户的记忆。这是有意接受的取舍：交给服务商处理不等于分发，ADR-0003 的「不提交、不公开」仍然成立；在意的部署者可以开计费（付费层不用于训练，文本 $0.20/1M tokens）。文档必须把这一点写清楚。

## Considered Options

- **同时保留两套向量，随时免费切换**：要把剧情段落表的主键改成带 `model` 并迁移数据；而切换并不常见，一次全量重新向量化只要几美元。
- **从模型名推断服务商**：少一个配置项，但出错时难以察觉，也没法给出清楚的报错。
- **Google 的 OpenAI 兼容接口 / Vercel AI Gateway**：可以复用现有的 OpenAI 兼容客户端（后者还能复用已有的 key），但都没有说明数组输入会不会被合并成一个向量；前者还在 beta，后者用不了 Google 的免费层。
- **只要求付费层**：隐私更好，但部署者自己的取舍，由文档说明而不是强制。

## Consequences

- 选 Gemini 的部署，服务器不能在中国大陆、香港、澳门：Gemini API 不对这些地区开放。
- 选 Gemini 时仍需 `SILICONFLOW_API_KEY`（重排）。
- `reembed` 期间服务照常运行，剧情检索暂时只查到已完成的部分。
- 两种服务的查询/文档格式不同：Qwen 在查询前加指令，Gemini 用 `task: … | query: …` 和 `title: … | text: …` 前缀；`Embedder` 需要能拿到文档标题。

## 修订（2026-09-27）：公开部署不用 Gemini 免费层

系统对公众开放（ADR-0006）以后，送去向量化的记忆就属于陌生人，而不是部署者自己和朋友；他们没有同意这些内容被 Google 用来改进产品。所以公开部署选 Gemini 时必须开计费，或者改用硅基流动。上面「允许使用免费层」的取舍只适用于私用部署。
