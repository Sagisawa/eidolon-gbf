# 过时的记忆在写入时标为被取代，保留在记忆页上，不改写也不删除

提炼记忆时，背景模型看到的是和这轮对话最相关的那些已有记忆（不再是最近 50 条）。它在写下新记忆的同时，指出这条新记忆取代了哪些旧的。被取代的记忆不再被想起，也不再交给背景模型看，但仍然列在记忆页上，标为「已被取代」，直到用户删除；删掉取代它的那条，它就重新被想起。这样做的理由是：角色知道的关于用户的一切，都必须来自用户看得到、删得掉的东西，所以记忆不能在用户看不到的地方被悄悄改写或删除；而模型判断错了取代关系时，用户可以在记忆页上看出来，删掉错的那条就能纠正。

## Considered Options

- **只在注入时处理（mem0 新版）**：记忆只追加，几条一起被想起时告诉对话模型以日期新的为准。改动最小，但只想起旧的那条时没用，而旧的那条往往措辞更贴近、更容易被想起。
- **让模型改写或删除旧记忆（mem0 旧版、Letta）**：记忆页始终是现状，但模型判断错时用户的记忆会悄悄变样或消失，用户无从察觉，也无从纠正。mem0 自己后来也退回了只追加。
- **后台定期整理**：能处理以前写下的重复和过时记忆，但要新增后台任务和费用，而且同样会在用户看不到的地方改动记忆。先不做，等评测证明写入时处理还不够再说。

## Consequences

- 以后加入的任何派生内容（例如常驻的制作人小档案、对话摘要）都只能由用户看得到的记忆生成，记忆被删除时要跟着重算或清掉。
- 新规则只管以后写进来的记忆，线上已有的重复和过时记忆不做批量清理。
