# 现实中的唱片和演出算作角色自己的经历，声优只作系统内部数据

角色是 283 事务所的偶像、用户是她的制作人，这是整个系统的视角。但原作本身会把现实中的 CD 发售和 live 当作戏里的事来办，所以我们把它们也纳入戏里：现实中发售的唱片就是她们发行的唱片，现实中的 live 就是她们站上的舞台。角色知道名称、日期、会场、出演者、曲目单这些可以查证的事实，但不知道台上具体发生了什么，也不编造。哪些演出算她上过，按她的声优实际出演的场次判断，所以系统需要声优数据；但角色本人不知道自己有声优，界面上也不展示。否则「是我站上了舞台」和「是我的声优站上了舞台」会互相矛盾。

系统不接搜索，角色只能靠我们提供的资料说出这些事实，所以资料的准确性就是防幻觉的底线：以官方来源为准；官方没有集中公布的（逐日出演者、缺席），只采用附有官方新闻链接的粉丝整理；由导入命令生成资料文件，人工审核 diff 后提交，不做定期自动抓取，因为没人看过的数据会直接变成角色的「记忆」。资料里查不到的，角色老实说想不起来，既不否认也不附和。

## Considered Options

- **完全在戏里，现实信息一律不收**：视角最干净，但原作本身就在戏里办发售纪念和 live 纪念，角色对这些一无所知反而不像本人。
- **角色知道自己是游戏角色、可以谈论声优**：拆掉了「制作人」这层身份。
- **按公告的出演组合判断她上过哪些演出**：不需要声优数据，但角色会声称自己上了实际没上的舞台。

## Consequences

- 资料有截止日：已公布但延期、取消的演出，要重新导入才会更正。
- 实体周边不收录；只有闪耀色彩的偶像演唱、发售过的才算她的歌曲，演出曲目单里翻唱的其他品牌歌曲照实记录，但不算她的歌曲。

## 修订（2026-09-28）：演唱者由 ふじわらはじめ 补齐，不用 imas-db

spec 原先定的是由 imas-db 补齐 Lantis（官方）缺少的唱片资料。实现 ticket 03 时实测，imas-db 的歌曲和唱片资料库没有闪耀色彩（只收到 2017 年前后的 765 系），闪耀色彩只有公演曲目单页。所以补齐演唱者改用粉丝整理的 ふじわらはじめ 的 API（`api.fujiwarahaji.me/v4`，按唱片列出每首的演唱者，CC BY-NC 4.0）。Lantis 有几十首曲目没写演唱者，不补齐这些歌就不进资料；而演唱者没有别的官方来源可查，所以接受粉丝来源，但只用在官方空缺的地方，并且逐条交给人核对。

- 它只补 Lantis 没写的演唱者：Lantis 曲目没写演唱者，或者只写了特别组合名、没写是哪几位偶像（这个名字得是全体、Lantis 在别的页面上列出过成员的特别组合，或者 ふじわらはじめ 也写着同一个组合名，才采用）。Lantis 写了的以 Lantis 为准；Lantis 写的演唱者对不上偶像名单时，不拿 ふじわらはじめ 的说法覆盖，这首列进导入报告、不写入。
- 两边对不上的地方按 Lantis 写入，列进导入报告。
- 由它补齐的每一首都列进导入报告，来源里记着 ふじわらはじめ 的唱片页，供人工核对。
- 逐日曲目单仍然按原计划取 imas-db 的公演页。
